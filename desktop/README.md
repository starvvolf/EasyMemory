# Recaller 앱 (Electron 창)

- `Recaller 앱.cmd`를 더블클릭하면 켜져요. 처음 한 번은 Electron을 받고, 바탕화면에 `Recaller` 바로가기를 만들어요.
- 켤 때는 `Recaller 시작`과 같은 일을 해요(코드 받기 · 패키지 · 데이터 받기 · 서버 켜기). 브라우저 대신 이 창에 `/study`를 띄워요.
- 창을 닫으면 `Recaller 끝내기`와 같은 일을 해요(서버 끄기 · 이 컴퓨터 데이터 올리기).
- 창 안 화면은 원래 웹앱 그대로라서, 코드가 바뀌면 `Ctrl+R`로 바로 반영돼요. 이 폴더의 `main.js`를 바꿨을 때만 앱을 껐다 켜면 돼요.
- ChatGPT 로그인 같은 바깥 주소는 평소 브라우저로 열려요. 로그인 뒤 창에서 `Ctrl+R`.
