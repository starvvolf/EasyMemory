# 단계별 모델 하향 실험

한 번에 하나의 AI 단계만 바꾸고, 나머지 입력·프롬프트·모델은 고정해 품질과 비용을 비교한다.

## 공통 중단 기준

- 원문 밖 사실, 틀린 계산·문법·논리 정답이 1건이라도 생기면 해당 케이스 실패
- 핵심 학습단위 누락 또는 LearningUnit ID 변화가 생기면 실패
- 학습단위 1개→문제 1개가 깨지거나 기계 오류가 생기면 실패
- 같은 실패 유형이 두 자료에서 반복되면 해당 모델 하향 묶음을 중단
- 기존 교사 평가보다 0.5점 이상 낮아지면 채택 보류

## 실행 순서

1. Prepare: Sol→Terra
2. Cards: Terra→Luna
3. Activity Design: Terra→Luna
4. Analyze: Terra→Luna
5. Plan: Terra→Luna

각 케이스는 고유한 결과 파일을 만들며 기존 기준선을 덮어쓰지 않는다.
