## 품질 평가

### 잘된 점

1. Pattern #1~#7이 각각 독립 문제로 유지되었다.
2. 모든 패턴 문제가 한국어 의미와 새 인물 정보를 보고 영어를 직접 말하는 방향이다.
3. he/she, his/her, him/her, is/has become 등 대명사와 3인칭 단수 형태를 실제 답에서 사용한다.
4. 답변 흐름은 배경·구체 설명 → 알게 된 계기 → 개인적 생각의 구조복원으로 분리되었다.
5. 문법은 설명 암기가 아니라 `She is Mina ...` 문장을 실제로 만드는 문제로 남았다.
6. 학교·이웃·배우·건강 스크립트의 고유 정보와 쉐도잉 횟수·방법은 핵심 문제에서 제외되었다.
7. 문제 앞면에 정답 영어 패턴이 노출되지 않는다.
8. 모든 apply 문제를 자동채점 완전 지원으로 과장하지 않고 자기확인 scaffold로 표시했다.

### 남은 한계

1. 플래시카드는 학습자가 실제로 말했는지, 발음이 정확한지 자동 확인하지 못한다.
2. 모범답안과 의미가 같은 다른 자연스러운 영어 표현을 시스템이 판정하지 못한다.
3. Pattern #1은 기능상 연결된 두 문장을 한 카드에서 요구한다. 허용 가능한 범위지만 다른 패턴보다 답이 길다.
4. Pattern #2의 `He/She is [이름]` 표현은 원문을 충실히 따른 결과지만 일반 영어에서 자연스러운 소개 방식인지는 원문 자체의 품질에 의존한다.
