# DFS/BFS 남은 모델 하향 실험

## 한눈에 보는 결론

| 단계 | 비교 | 결과 | 이유 |
|---|---|---|---|
| Activity Design | Terra → Luna | **하향 보류** | Luna가 새 BFS 문제의 정답을 `7`로 만들었지만 직접 계산하면 `8`이다. |
| Cards | Terra → Luna | **통과(교차 자료 확인 필요)** | 고정된 같은 Activity Design에서 9문제·정답·형식을 모두 보존했다. |

프로덕션 모델 설정은 변경하지 않았다. PDF 원본은 보내지 않았고, Prepare에서 확정된 구조화 내용과 출처 발췌만 사용했다.

## 고정 조건

- Prepare: `model-test-prepare-terra-dfs-bfs-r1.json` 또는 기존의 같은 9개 학습단위 기준선
- 학습단위: 9개 고정
- 추론 강도: 모두 `medium`
- Critic: 비활성화
- Activity 비교: 같은 Terra Prepare 입력에 Terra와 Luna를 각각 적용
- Cards 비교: 기존 Terra Activity Design을 그대로 고정하고 Cards 모델만 Luna로 변경

## Activity Design 비교

두 모델 모두 9개 학습단위에 문제 설계 하나씩을 만들었고 추천 형식도 같았다.

- 플래시카드 7개
- 구조복원 2개: DFS 절차, BFS 절차
- 누락된 학습단위 없음

하지만 계산형 문제의 정답 검산에서 두 결과 모두 오류가 발견됐다.

### Terra 결과의 오류

격자:

```text
00110
01110
10001
11001
```

`0`을 통과 가능한 칸으로 보면 연결 영역은 다음 3개다.

1. `(0,0), (0,1), (1,0)`
2. `(0,4), (1,4)`
3. `(2,1), (2,2), (2,3), (3,2), (3,3)`

Terra Activity Design은 정답을 `2`로 만들었고, 해설에는 벽 좌표까지 통과 칸으로 포함했다.

### Luna 결과의 오류

미로:

```text
1 0 1 1 1
1 1 1 0 1
0 0 1 0 1
1 1 1 1 1
```

시작 `(0,0)`의 거리를 `1`로 기록하면 유일한 최단 흐름은 다음과 같다.

```text
(0,0) → (1,0) → (1,1) → (1,2) → (2,2)
→ (3,2) → (3,3) → (3,4)
```

도착 칸의 기록값은 `8`인데 Luna Activity Design은 `7`로 만들었다.

또한 Terra는 DFS/BFS 절차 구조복원 2개를 `완전 지원`으로 판단했지만 Luna는 같은 두 문제까지 모두 `부분 지원`으로 낮춰 판단했다. 실제 추천 문제 형식은 같았으므로 생성 수에는 영향이 없었지만 지원 판단은 더 부정확했다.

따라서 Activity Design을 Luna로 낮추는 것은 이 자료에서 통과하지 못했다. 같은 종류의 새 계산 문제 정답 오류가 Terra와 Luna 결과에서 각각 확인되어 추가 반복 호출도 중단했다.

## Cards 단계만 격리한 비교

Activity Design은 기존 Terra 결과로 고정했다. 이 기준선은 다음 두 계산 문제의 최종 숫자가 이미 직접 검산된 상태다.

- 연결 영역: `3`
- BFS 최소 이동 횟수: `6`

Luna Cards 결과:

- 9개 학습단위 → 9문제 유지
- 학습단위 ID 9개 모두 유지
- 문제 방식 유지: 플래시카드 7개, 구조복원 2개
- 연결 영역 정답 `3` 유지
- BFS 최소 이동 횟수 `6` 유지
- DFS/BFS 구조복원 순서 정확
- 정답이 문제 앞면에 노출된 항목 없음
- 자동 형식 검사 오류 없음

작은 차이는 `graph-basics` 문제에서 Luna가 목표에 필수인 그래프 구성 요소·인접 관계 외에 `그래프 탐색의 의미`까지 함께 물었다는 점이다. 원문 안의 내용이라 사실 오류는 아니지만 성공 기준보다 요구 범위가 조금 넓어졌다. 나머지 8문제는 기준선과 같은 목표 범위를 유지했다.

따라서 Cards 단계의 Luna 하향은 DFS/BFS 한 자료에서는 통과로 본다. 다만 전체 채택은 다른 성격의 자료 결과까지 합쳐 판단해야 한다.
