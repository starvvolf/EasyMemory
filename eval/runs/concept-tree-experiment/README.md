# 개념트리 MCP 실험 결과

Study Forge 앱과 생성엔진에는 연결하지 않은 독립 실험이다. GPT가 개념어와 관계를 자연어 목차로 작성하고, MCP가 노드 ID·부모·순서·출처를 붙여 저장한다.

## PDF 입력: 운영체제 데드락

- 입력: `technical-deadlocks.pdf` 14쪽
- 결과: 27개 개념, 최대 깊이 2
- 페이지 근거 누락: 0개

```text
데드락
├─ 정의: 차단된 프로세스 집합
├─ 시스템 모델
│  ├─ 프로세스
│  └─ 자원 유형
│     └─ 자원 인스턴스
├─ 자원 사용 단계
│  ├─ 요청
│  ├─ 사용
│  └─ 반납
├─ 필요조건
│  ├─ 상호 배제
│  ├─ 점유와 대기
│  ├─ 비선점
│  └─ 순환 대기
├─ 자원 할당 그래프
│  ├─ 프로세스 정점
│  ├─ 자원 유형 정점
│  ├─ 요청 간선
│  ├─ 할당 간선
│  └─ 사이클
└─ 처리 전략
   ├─ 예방
   ├─ 회피
   │  ├─ 안전 상태
   │  ├─ 불안전 상태
   │  ├─ 클레임 간선
   │  └─ 은행원 알고리즘
   └─ 탐지와 복구
      ├─ 프로세스 종료
      └─ 자원 선점
```

## 채팅 주제 입력: 고등학교 수준의 미분

- 결과: 16개 개념, 최대 깊이 2
- 별도 자료 없이 사용자가 지정한 범위 안에서 구성

```text
미분
├─ 선행 개념
│  ├─ 함수
│  └─ 극한
├─ 핵심 개념
│  ├─ 평균변화율
│  └─ 순간변화율
├─ 표현
│  ├─ 미분계수
│  └─ 도함수
│     ├─ 상수의 미분
│     ├─ 합의 미분법
│     ├─ 곱의 미분법
│     ├─ 몫의 미분법
│     └─ 연쇄법칙
├─ 기하적 의미
│  └─ 접선의 기울기
└─ 활용
   ├─ 함수의 증가와 감소
   ├─ 극값
   └─ 최적화
```

## 판단

두 입력 방식이 같은 저장 구조로 수렴하는 것은 확인했다. 다만 현재 결과는 트리 생성·구조 검사의 실험이며, 개념의 중요도·선수 관계 검증·학습 완료 판정은 포함하지 않는다.
