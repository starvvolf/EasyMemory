# Study Forge 제품 방향

이 문서는 Study Forge가 해결하려는 문제, 현재 제품 목표와 장기적인 확장 방향을 구분해 정의한다. 현재 코드에 존재하는 화면이나 기능을 제품의 영구적인 정의로 고정하기 위한 문서가 아니다.

제품을 설계하고 변경할 때는 항상 다음 세 가지를 구분한다.

1. Study Forge가 궁극적으로 해결하려는 문제
2. 현재 단계에서 검증하고 완성해야 할 제품 목표
3. 장기적으로 확장할 수 있지만 아직 현재 요구사항은 아닌 방향

## 1. 해결하려는 문제

학습자는 자료를 읽은 뒤에도 스스로 다음을 결정해야 한다.

- 무엇을 실제로 외우거나 이해해야 하는가
- 어떤 내용은 핵심이고 어떤 내용은 예시나 설명에 불과한가
- 무엇을 어떤 방향으로 인출해야 하는가
- 어떤 방식으로 연습해야 실제 사용 가능한 기억이 되는가
- 학습자료를 어떻게 카드나 문제 형태로 가공해야 하는가

이 과정은 단순한 독해나 요약이 아니라 학습 목표 설정, 내용 선별, 인출 설계와 연습 자료 제작이 결합된 학습 설계 작업이다. 학습자는 교재를 이해하는 일과 별개로 상당한 시간과 판단을 이 작업에 사용해야 한다.

Study Forge는 이러한 학습 설계와 자료 가공의 부담을 줄이는 것을 목표로 한다. AI가 필요한 판단을 수행하거나 사용자가 더 효과적으로 판단할 수 있도록 지원하고, 그 결과를 실제로 연습할 수 있는 형태로 구현한다.

## 2. 제품의 본질

Study Forge는 단순한 PDF 요약기나 AI 카드 생성기가 아니다.

핵심은 학습자료를 "읽을 자료"에서 "직접 기억을 꺼내고 사용할 수 있게 만드는 훈련"으로 변환하는 것이다.

쉽게 표현하면 다음과 같은 방향을 따른다.

> 교재를 대신 읽어주는 AI가 아니라, 교재를 내가 직접 기억하고 사용할 수 있게 만드는 훈련으로 변환하는 AI 학습 도구

요약은 자료를 빠르게 파악하는 수단이 될 수 있고 암기카드는 훈련을 구현하는 한 가지 형식이 될 수 있다. 그러나 요약 결과나 카드 생성 자체가 제품의 최종 목적은 아니다. 제품의 가치는 사용자가 목표한 지식을 실제로 인출하고 활용할 수 있도록 학습 행동을 설계하는 데 있다.

## 3. 현재 1차 목표

현재 가장 중요한 목표는 PDF 등의 학습자료에서 고품질 암기카드를 생성하고, 사용자가 이를 검토한 뒤 실제로 학습할 수 있게 만드는 것이다.

현재 단계에서는 특히 다음이 중요하다.

- 무엇을 카드로 만들 가치가 있는지 선별
- 예시와 핵심 지식 구분
- 재사용 가능한 패턴 추출
- 적절한 인출 방향 결정
- 한 카드에 하나의 인출 대상 유지
- 사실상 같은 내용을 묻는 중복 최소화
- 생성 결과와 원문 근거의 연결 유지

고품질은 카드의 개수, 문장의 유창함 또는 생성 성공 여부만으로 판단하지 않는다. 학습 목표에 맞는 내용을 선별했는지, 카드 앞면이 적절한 인출 행동을 유도하는지, 답이 원자료에 충실한지, 실제 반복 학습에 사용할 수 있는지를 함께 판단한다.

현재의 카드 중심 목표는 제품 방향을 검증하기 위한 1차 범위다. 모든 학습을 영구적으로 카드에 한정한다는 의미는 아니다.

## 4. 사용자와 AI의 역할

Study Forge는 AI가 모든 학습 결정을 강제로 대신하는 제품으로 정의하지 않는다.

현재는 사용자가 다음과 같은 항목을 직접 선택할 수 있다.

- 학습 영역
- 인출 방식
- 카드 형태
- 변수 처리 방식

AI는 자료를 분석하고, 사용자가 판단할 수 있는 선택지를 구성하며, 사용자가 원하는 학습 방식을 실제 카드로 구현하는 역할을 한다. 사용자의 목적이 불분명하거나 하나의 정답으로 결정할 수 없는 경우에는 AI가 임의로 확정하기보다 판단에 필요한 근거와 선택지를 제공할 수 있다.

장기적으로 AI의 판단 정확도가 높아지면 일부 선택 과정은 자동화되거나 기본값으로 제안될 수 있다. 반대로 학습 목적, 개인 선호 또는 사용 맥락에 따라 사용자의 명시적인 통제가 계속 필요한 부분도 있을 수 있다.

따라서 사용자 통제와 AI 자동화 중 하나만을 제품의 영구 원칙으로 고정하지 않는다. 두 역할의 경계는 판단 정확도, 오류 비용과 사용자에게 필요한 통제 수준을 기준으로 조정한다.

## 5. 같은 자료라도 학습 목적에 따라 달라질 수 있음

좋은 학습 형태는 자료 자체만으로 결정되지 않는다. 같은 자료라도 사용자의 목표에 따라 적절한 학습 방식과 인출 방향이 달라질 수 있다.

예를 들어 하나의 영어 문장도 목표에 따라 다음과 같이 달라질 수 있다.

- 해석이 목표인 경우: 영어 → 한국어
- 말하기가 목표인 경우: 의미 또는 의도 → 영어
- 패턴 암기가 목표인 경우: 변수 자리를 남긴 템플릿
- 자연스러운 발화 연습이 목표인 경우: 구체적인 변수를 채운 완성 예문

따라서 자료의 언어, 형식이나 내용만 보고 학습 방식을 결정하지 않는다. AI는 자료의 성격과 함께 사용자가 학습 후 무엇을 이해하고, 기억하고, 실제로 할 수 있게 되기를 원하는지도 고려해야 한다.

사용자의 목적이 같은 자료에 여러 학습 방식을 요구한다면 하나의 고정된 카드 형식에 억지로 맞추기보다 목적별 인출 행동을 구분하는 방향을 선호한다.

## 6. 장기 비전

장기적으로 Study Forge는 모든 학습 내용을 무조건 플래시카드로 변환하는 시스템을 목표로 하지 않는다.

자료와 학습 목표에 따라 예를 들어 다음과 같은 서로 다른 능동 학습 형태를 사용할 수 있는 방향을 지향한다.

- 일반 플래시카드
- 빈칸 회상
- 스피킹 패턴
- 자유 회상 또는 백지복습
- 개념 설명
- 문제 풀이
- 단계별 힌트

장기적인 방향은 학습 내용을 가장 적절한 능동 학습 형태로 바꾸고, 사용자가 실제로 수행한 결과를 바탕으로 훈련을 개선하는 것이다. 다만 위 항목은 확장 가능한 제품 방향을 설명하는 예시이며, 현재 모두 구현되어 있거나 즉시 구현해야 하는 요구사항을 뜻하지 않는다.

장기 비전을 이유로 현재 핵심인 카드 생성 품질과 실제 학습 경험을 뒤로 미루지 않는다. 현재 단계에서 검증되지 않은 기능을 미리 추가해 제품과 코드의 복잡도를 높이지 않는다.

## 7. 현재 범위와 비범위

### 현재 범위

현재 제품 범위는 PDF 중심 학습자료를 고품질 암기카드와 실제 학습 흐름으로 전환하는 데 집중한다.

- PDF 중심 학습자료 분석
- 학습 영역 구성
- 인출 방식 설계
- 학습 단위 추출
- 암기카드 생성
- 카드 검토와 수정
- 덱 저장과 학습

이 범위는 현재 프로젝트의 실제 생성 흐름과 일치한다. 각 단계의 존재 자체보다, 단계들이 사용자의 학습 목적에 맞는 카드와 학습 행동으로 연결되는지가 중요하다.

### 현재 비범위

다음은 현재 단계의 제품 요구사항으로 간주하지 않는다.

- 모든 과목의 자동 튜터링
- 모든 학습법의 완전 자동 선택
- 완전 자율 학습 코치
- 아직 구현되지 않은 장기 기능의 선행 구현

비범위는 제품이 장기적으로 해당 방향을 절대 다루지 않는다는 뜻이 아니다. 현재 1차 목표를 완성하고 검증하기 전에는 우선순위와 구현 요구사항으로 취급하지 않는다는 뜻이다.

## 8. 제품 판단 기준

새 기능이나 구조 변경을 검토할 때 다음 질문을 기준으로 판단한다.

- 이 기능이 사용자가 실제로 기억하고 사용할 수 있게 만드는가?
- 단순히 카드 수나 기능 수만 늘리는 것은 아닌가?
- 학습 목표와 사용자가 수행할 인출 행동이 연결되어 있는가?
- 사용자가 통제해야 할 부분과 AI가 자동화할 부분을 적절히 나누고 있는가?
- 현재 구현을 영구적인 제품 정의로 오해하고 있지 않은가?
- 장기 비전을 이유로 현재 필요 없는 기능을 미리 만들고 있지 않은가?

추가로 생성 품질을 판단할 때는 다음을 확인한다.

- 자료에 있다는 이유만으로 암기 가치가 낮은 내용을 포함하지 않았는가?
- 예시를 핵심 지식으로 오인하거나, 핵심 지식을 지나치게 구체적인 예시로 분해하지 않았는가?
- 사용자의 목적과 반대되는 방향으로 답을 인출하게 만들지 않았는가?
- 원문에 없는 내용을 사실처럼 추가하지 않았는가?
- 생성 결과가 원자료의 근거와 연결되어 검토 가능한가?

Study Forge의 제품 결정은 기능의 양보다 학습 설계 부담의 실질적인 감소와 능동 인출의 품질을 우선한다.
