# 생성엔진 현재 상태

> 설계 의도가 아니라 2026-08-17 현재 실제 앱이 어떻게 움직이는지 기록한다.

## 현재 사용자 경로

```text
자료 입력
→ Analyze
→ Plan
→ 목차·범위 선택
→ Prepare
→ 학습단위 포함/제외 확인
→ Activity Design
→ AI 추천 자동 진행 또는 사용자 직접 선택
→ Cards
→ 문제 수정·저장
→ 학습·복습
```

### 자동 흐름

AI가 문제 방식과 지원 여부를 추천하고, 포함 가능한 학습단위를 곧바로 문제 생성으로 넘긴다.

### 사용자 선택 흐름

사용자가 추천 이유를 본 뒤 포함 여부와 문제 방식을 조정하고 문제를 생성한다.

두 흐름 모두 같은 LearningUnit, Activity Design, Cards 계약을 사용한다.

## 현재 연결된 핵심 변경

- Prepare가 만든 LearningUnit을 문제 개수의 기준으로 사용한다.
- LearningUnit마다 LearningObjective와 PracticeBlueprint를 정확히 하나씩 만든다.
- 선택된 학습단위마다 최종 문제를 정확히 하나 만든다.
- 실제 관계가 없는 구조복원 추천은 일반 규칙으로 다른 문제 방식으로 보정한다.
- 직접 자동채점이 어려운 중요한 내용은 삭제하지 않고 자기확인형 플래시카드로 보존할 수 있다.
- 사용자가 문제 만들기 방향을 자연어로 추가할 수 있으며, Prepare와 문제 설계·생성에 전달된다.
- 문제 생성 입력은 공통 원문 페이지를 한 번만 보내는 압축 경로를 사용한다.

| 확인 | 결과 |

실제 엔진 실험의 성공 호출 예상 비용은 사회 약 `$0.359`, 과학 약 `$0.347`이었다. 첫 실패 실행 비용은 별도 결과 파일에 저장되지 않았으므로 이 합계에 포함되지 않는다.

## 현재 잘 되는 부분

- 핵심 학습단위가 지원 판정 때문에 통째로 사라지는 현상이 줄었다.
- 자료마다 특수 규칙을 붙이지 않고 동일한 1:1 규칙이 사회·과학·OPIc·데드락에 적용된다.
- 문제 형식보다 학습자가 해야 하는 행동을 먼저 정한다.
- 자동 흐름과 사용자 선택 흐름이 같은 생성 계약을 사용한다.
- 문제 앞면의 구조복원 답 목록은 제거되고, 실제 학습 화면에서 답 모음은 섞인다.

## 아직 부족한 부분

1. **최대 개수 채우기 성향**  
   핵심 로직 단독 실험보다 실제 Prepare가 사회·과학에서 더 많은 단위를 만들었다. 최대치는 여전히 목표처럼 작용할 가능성이 있다.

2. **복수 정답 가능성**  
   사회 적용 문제처럼 여러 타당한 경로가 있는데 모범답안 하나만 제시할 수 있다.

3. **한 구조에 여러 관계 혼합**  
   과학 문제에서 질량 관계와 원소 생성 순서가 하나의 구조복원에 묶였다.

4. **자유 수행의 자동채점 한계**  
   말하기, 긴 풀이, 여러 표현이 가능한 답은 자기확인형 보조 훈련으로만 제공한다.

5. **작업 트리가 아직 정식 버전으로 묶이지 않음**  
   현재 기준 HEAD는 `fda889e`이고, 핵심 구현과 문서·실험 파일은 미커밋 변경으로 남아 있다. 이 문서는 현재 파일 상태를 설명하지만 Git 버전 자체를 고정한 것은 아니다.

## 현재 제품 경로와 과거 평가 코드

### 실제 사용 중

- `prepare`
- `activity-design`
- `cards` + ActivityDesign

### 제품 API에서 제거됨

- Recall Design API와 화면 상태
- 대표 예시 선택과 sample 생성
- Activity Design을 거치지 않는 full 생성
- recallDesign·approvedSample·sampleFeedback 요청 필드

과거 평가 결과를 재현하는 `pipeline/recall.ts`와 옛 CardContract 함수는 내부 실험 코드에만 남아 있다. 제품 API에서는 호출할 수 없으며 `cards` 요청에는 Activity Design이 반드시 필요하다.

## 다음 품질 확인 순서

1. 최대치를 덜 채우도록 바꾸기 전에, 최대치가 실제 결과를 얼마나 늘리는지 여러 자료에서 측정한다.
2. 복수 정답 가능 문제와 여러 관계 혼합 문제를 기계적으로 감지할 최소 규칙을 시험한다.
3. 내부 평가 도구가 옛 Recall/CardContract에 의존하는 범위를 별도 정리한다.
4. 같은 사회·과학 자료로 변경 전후를 다시 비교한다.

## 데이터 구조 축소 실험

- 축소 전 엔진과 실제 출력물을 별도 스냅샷으로 보존했다.
- Activity Design에서 다시 계산 가능한 지원 평가와 고정 정책 복사본을 제거했다.
- 기존 결과 기준 Activity Design 데이터는 사회 16.3%, 과학 14.5% 감소했다.
- Prepare의 지식 유형·변수 분해·선정 이유까지 제거한 실험은 핵심 범위가 흔들려 되돌렸다.
- 현재 Prepare 프롬프트와 학습단위 계약은 축소 전 상태로 복원되어 있다.

## 문제 생성 토큰 최적화

- Cards 단계는 AI가 실제 문제 내용만 만들고 출처·ID·추천 이유·빈 호환 필드는 서버가 복원한다.
- 동일 사회·과학 기준에서 Cards 총토큰이 각각 25.1%, 22.9% 감소했고 문제 수와 기계 검사는 유지됐다.
- JSON 들여쓰기까지 제거하는 추가 축소는 과학 핵심 관계 누락이 발생해 되돌렸다.
