## 앱 기반

- 되는 것: `Recaller 시작.cmd`(코드 받기 → 패키지 → 데이터 받기 → 127.0.0.1:3000), `Recaller 끝내기.cmd`(데이터 올리기). ChatGPT 계정 로그인으로 API 키 없이 생성. 태블릿은 같은 와이파이에서 6자리 코드로 연결. 화면 4개(오늘·공부·지식·일정).
- 막힌 점: 작업 폴더에 커밋 안 된 변경이 있으면 시작할 때 코드 받기가 실패한다. 작업 폴더(worktree)가 여러 개라 어느 폴더가 최신인지 헷갈리기 쉽다.
- 범위 밖: 모바일.
