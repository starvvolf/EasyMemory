# Recaller 현재 상태

갱신: 2026-09-28. 현재 목표·진행·다음 작업은 이 문서에서만 갱신한다.

## 지금 끝낼 것

대화에서 PDF와 학습 의도를 전달 → MCP로 생성 → 앱에서 풀이 → 저장 → 다시 열어 복습.
두 PDF는 테스트 자료다. 특정 자료에만 맞춘 제품으로 만들지 않는다.
**전체 흐름은 아직 미완료다.** 과거 대표범위 성공이나 코드 검사 통과로 완료 처리하지 않는다.

## 확인된 상태

- 두 PDF의 MCP 단계 결과와 기하 28개·반도체 22개 학습목표가 있다.
- 최신 출제 문서 50문항은 앱 등록·실제 풀이·재접속 복습 검증이 남아 있다.
- 기존 문제 화면의 공개 전 근거 노출, 자료 하나의 오류가 목록 전체를 막는 문제를 수정했다.
- 기존 9문항 화면에서 공개·제출 기록 구분을 확인했다. 전체 문항 품질이나 전체 흐름을 검증한 것은 아니다.
- 학습 진입 화면을 자료 선택 → 시작·이어 풀기 → 복습으로 단순화했다. 목표·상세 기록은 분리하고 복습 후보를 먼저 표시한다. 기존 9문항으로 실제 제출, 새로고침 후 기록 보존·이어하기, 오답 복습 이동과 모바일 폭을 확인했다. 린트·빌드 통과(기존 경고 있음).
- 자연스러운 답 표기의 채점, 출제 내용 품질, 최신 결과의 학습 연결은 남아 있다.

## 덜어내는 기준

- 활성 개발은 위 학습 흐름을 막는 문제 해결에 한정한다.
- API 생성 경로 확대, 별도 로그인 실행기, VS Code 연동, 클라우드 확장, 고급 개인화, 장식 위주 UI 개선은 보류한다. 기존 코드·데이터를 삭제했다는 뜻은 아니다.
- 새 담당·새 관리 체계·중복 보고서를 만들지 않는다. 구현은 필요한 기존 담당에게만 맡기고 기획팀장이 통합 확인한다.
- 기존 문제와 학습 기록, 원문 연결, 정답 공개 여부, 생성 소요시간은 보존한다.
- 검사 추가는 실제 결함을 잡는 경우에만 한다. 같은 결과를 확인하는 보고·검사를 중복 실행하지 않는다.
- 코드 삭제는 사용 지점 확인 후 시행한다. 참고 실험은 현재 실행 안내에서 제외하고 필요할 때만 찾는다.
