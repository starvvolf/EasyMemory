# 메인 보드

## 지금 집중할 것

- AI 대리 사용자 알파는 통과했다. 6종 문제 재생성 결과가 자료별로 상승·하락해, 모델 재호출이 아니라 생성 직후 계약 검사로 품질을 안정화한다.
- 부분 지원을 전부 제외하거나 완전 지원으로 과장하지 않고, 보조 훈련과 현재 미지원 범위를 함께 보여주는 최소 구조를 정한다.
- 추천한 학습 행동을 실제 문항이 시키는지, 정답을 문제 앞면이 먼저 보여주지 않는지, 추천 범위가 카드에서 빠지지 않았는지 검사한다.
- 새 문제 제작 도구는 기존 엔진을 교체하지 않은 시험 운행으로 연결한다.
