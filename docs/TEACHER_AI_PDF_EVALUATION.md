# AI 선생님 PDF별 기대-결과 비교

- 평가일: 2026-08-16
- 평가 범위: 중복 복사본을 제외한 평가용 PDF 6종과 DFS/BFS 자료 1종
- 평가 방식: 앱 결과를 보지 않은 선생 AI가 먼저 기대표를 작성한 뒤, 저장된 실제 앱 결과를 공개해 비교 채점
- 1차 평가는 저장된 평가 결과를 사용했다.
- 사용자의 명시적 승인 후 2026-08-16에 OPIc·데드락·권리장전·달의 위상·재난 체크리스트·미적분 6종의 문제 생성 단계를 Terra로 자료당 1회 다시 실행했다. DFS/BFS는 기존 결과를 유지했다.
- 재실행 범위는 앞 단계 결과를 고정한 `문제 생성` 단계다. 따라서 점수 변화는 카드 문항의 변동이고, 앞 단계의 범위 누락은 그대로 남아 있다.

## 2026-08-16 재실행에서 확인한 변화

- OPIc는 `부분 지원이면 전부 제외`하던 결과에서 벗어나 세 학습단위가 모두 문제를 받았다. 하지만 “영어 표현을 직접 말하기”라는 추천과 달리 영어 패턴 대부분을 문제 앞면에서 보여준다.
- 데드락은 네 필요조건 자유 입력이 개선됐다. 반면 그래프 판독과 안전 상태 판단은 여전히 해석 결과를 먼저 알려준 뒤 규칙을 고르는 문제다.
- 권리장전은 유지·누락 비교 문항이 좋아졌지만, 추천 범위의 제6조가 카드에서 빠졌다. 연도가 적힌 단어를 시간순으로 배열하게 해 지식 없이도 풀 수 있다.
- 달의 위상은 범위가 전혀 넓어지지 않았고, 위상 변화 답에서 `상대 위치가 달라져 보이는 밝은 면의 비율이 변한다`는 핵심 메커니즘이 빠졌다.
- 재난 체크리스트는 다른 대표 항목으로 교체됐을 뿐 전체 범위는 그대로다. 객관식 오답과 구조복원 단어가 너무 직접적이다.
- 미적분은 원문 밖 계산 문제를 직접 풀게 하던 위험이 줄고 보조 절차 문제로 바뀌었다. 그러나 여전히 `부분 지원` 표시가 없고 실제 계산·증명·그래프 훈련은 없다.

실행량:

- Terra 6회, Sol 0회
- 입력 18,180토큰, 출력 12,477토큰, 추론 2,043토큰
- 평가용 예상 비용 합계 약 $0.186
- 생성 문제 30개, 기계 형식 오류 0건

재실행 결론:

> 같은 학습내용으로 문제 생성만 다시 해도 점수는 오르거나 내려간다. 모델 재호출만으로는 안정적인 개선이 아니며, 추천한 학습 행동과 실제 문항이 일치하는지 검사하는 장치가 필요하다.

## 자료별 선생 판정

### OPIc 인물 묘사

선생 기대:

- 7개 공통 문장 기능을 각각 떠올린다.
- 새 인물 정보로 변수 자리를 바꾼다.
- 대명사와 3인칭 단수를 맞춘다.
- 여러 문장을 하나의 영어 답변으로 연결한다.

앱 결과:

- Prepare는 전체 흐름과 패턴 묶음을 비교적 잘 잡았다.
- Activity Design이 패턴 묶음을 `partial`로 보고 자동 생성에서 제외했다.
- 최종적으로 한국어 답변 흐름 구조복원 1개만 남았다.

판정:

- 완전한 실제 발화는 미지원이라는 판단은 맞다.
- 하지만 한국어 의도→영어 패턴, 대명사 선택, 어순 복원 같은 유용한 보조 훈련까지 모두 버렸다.
- 최초 주요 실패 단계는 문제 방식 추천과 포함 결정이다.

### 데드락

선생 기대:

- 네 조건의 의미를 상황에서 판별한다.
- 요청·할당 간선과 자원 인스턴스 수를 읽는다.
- 사이클과 데드락, 불안전 상태와 현재 데드락을 구별한다.
- 예방·회피·탐지·복구를 사례에 적용한다.

앱 결과:

- 정의, 네 조건, 그래프 규칙, 예방 정책, 회피, 탐지·복구를 고르게 포함했다.
- 문제의 조건문이 판단에 필요한 핵심 정보를 이미 말해주어 규칙 선택 문제가 됐다.
- 실제 그래프 판독, 안전 상태 설명, claim/request/assignment 변화는 부족했다.

판정:

- 범위 선정과 사실 정확성은 양호하다.
- 주요 손실은 문제 생성 단계에서 적용 과제가 한 줄 규칙 회상으로 낮아진 것이다.

### 권리장전

선생 기대:

- 세 문서의 시간·역할을 구별한다.
- 초기 요구가 제안과 최종 조문에서 유지·변형·누락된 과정을 추적한다.
- I~X의 내용과 적용 맥락, 혼동 조항의 경계를 설명한다.

앱 결과:

- 세 문서 순서, I/II/III, IV~VIII, IX/X 관계를 대체로 정확하게 만들었다.
- 최종 조항 번호·내용 대응에 문제 비중이 몰렸다.
- 제안·비준 절차, 변화 이유, 사례 적용, 누락된 요구 비교가 약했다.
- V의 정당보상을 형사절차 보호군에 넣는 범주 문제가 있었다.

판정:

- 사실과 출처는 대체로 양호하다.
- 최초 범위 편향은 학습 내용 선정에서 시작됐고, 카드 생성이 추천 이유보다 낮은 수준으로 축소했다.

### 달의 위상

선생 기대:

- 태양·지구·달 모형을 배치해 위상을 만든다.
- 지구 그림자·구름 오개념을 반박한다.
- 360도÷30일로 하루 약 12도 이동을 계산하고 다음 위치를 예측한다.
- 지구 자전과 달 공전을 함께 설명한다.

앱 결과:

- 모형 조작, 공간 배치, 각도 계산, 위치 예측, 지구의 위상은 전부 사라졌다.

판정:

- 생성된 문제의 정확성은 높다.
- 활동 안내를 부가 정보로 보고 핵심 수행까지 제외한 학습단위 선정이 문제다.

### 재난 체크리스트

선생 기대:

- 개인·금융 기록을 모으고 원본·사본·디지털본을 분산 보관한다.
- 계좌 연락처와 재산 목록을 실제로 작성한다.
- 재난 후 연락·지출 중단 조건·여러 사기 신호를 판단한다.

앱 결과:

- 기록 사본, 보관 구조, 계좌 범주, 재산 증빙, 채권자 연락, 사기 신호를 포함했다.
- 세부 기록과 사기 유형을 대표 항목 하나로 압축했다.
- 객관식 오답이 식단표·운동계획표처럼 너무 쉬웠다.

판정:

- 입문 복습에는 도움이 되지만 실제 준비가 완료됐다는 의미는 아니다.
- 학습단위 압축이 먼저 발생했고, 객관식 오답 생성이 난도를 더 낮췄다.

### 미적분 문제집

선생 기대:

- 그래프, 극한, 미분, 증명, 모델링을 직접 풀고 과정을 제시한다.
- 해설 없는 문제집이므로 원문만으로 정답을 확정할 수 없는 범위를 구별한다.

앱 결과:

- 미분 관련 객관식 6개를 만들었고 수학적 정답은 맞았다.
- 모든 단위를 완전 지원으로 표시하고 제한을 비워뒀다.
- 원문에 없는 문제 두 개와 모델이 계산한 정답·풀이를 원문 근거 문제처럼 사용했다.

판정:

- 짧은 미분 확인 문제로는 쓸 수 있지만 자료 전체 학습을 대표하지 못한다.
- 가장 큰 실패는 해설 없는 수행 자료라는 성격과 미지원 경계를 놓친 것이다.

### DFS/BFS

선생 기대:

- 표현 방식 비교, 탐색 순서·스택·큐 상태 추적, DFS/BFS 선택, 구현, 격자 적용을 균형 있게 연습한다.

앱 결과:

- 핵심 내용 21개를 폭넓고 대체로 정확하게 잡았다.
- 모든 결과가 플래시카드이고 답이 길다.
- 실제 그래프 순서 추적, 큐·스택 상태, 코드 작성·디버깅, 새 입력 계산은 없다.
- 일부 자리표시자가 실제 입력 없이 남고 비슷한 절차가 반복된다.

판정:

- 개념 복습 자료로는 좋다.
- 실패는 학습단위 추출보다 모든 단위를 플래시카드로 만든 문제 방식 선택에서 시작됐다.

## 공통 원인

### 1. 자료 전체 목표보다 네 문제 형식에 잘 들어가는 내용만 남는다

- 달의 위상에서는 모형 조작·예측이 사라졌다.
- 재난에서는 실제 준비 행동이 사라졌다.
- 미적분에서는 그래프·증명·모델링이 사라졌다.

지원하기 어려운 목표를 제외할 수는 있지만, 무엇을 제외했는지와 왜 앱으로 충분하지 않은지를 사용자에게 남겨야 한다.

### 2. 부분 지원을 두 극단으로 처리한다

- OPIc는 부분 지원 내용을 전부 제외해 한 문제만 남겼다.
- 미적분은 반대로 부분·미지원 수행을 모두 완전 지원으로 처리했다.

부분 지원은 `보조 훈련 생성 + 한계 표시`로 일관되게 다루는 편이 적절하다.

### 3. 문제에 필요한 판단을 먼저 말해준다

- 데드락은 사이클·인스턴스·불안전 상태를 문제에 이미 제공한다.
- DFS/BFS는 구체 입력 없이 일반 절차를 답하게 한다.

학습자가 실제 근거를 읽고 판단하도록 그래프·상황·입력 데이터를 제시해야 한다.

### 4. 정확성 검사는 범위와 행동을 검사하지 못한다

- 달의 위상 문제는 모두 정확하지만 자료 목표의 상당 부분이 없다.
- DFS/BFS는 정확하지만 실제 수행 대신 장문 회상이다.
- 여러 결과의 `qualityPassed`와 `qualityNotes`는 범위 누락을 설명하지 못한다.

## 다음 수정 우선순위

1. 문제 생성 전 `학습 목표별 훈련 포함 여부`를 만든다.
   - 핵심 직접 훈련
   - 보조 훈련
   - 현재 미지원이며 별도 수행 필요

2. 문제 생성 후 자료 전체 목표와 생성 문제의 대응표를 검사한다.
   - 핵심 목표가 문제 없이 사라졌는지
   - 같은 목표만 형식을 바꿔 반복했는지
   - 미지원 목표가 사용자에게 표시되는지

3. 부분 지원은 자동으로 버리거나 완전 지원으로 승격하지 않는다.
   - 가능한 보조 문제를 만들고 한계를 함께 남긴다.

4. 학습 행동에 맞는 실제 입력을 제공한다.
   - 그래프 판독에는 그래프
   - 알고리즘 추적에는 구체 노드·간선
   - 패턴 적용에는 새 변수 정보
   - 상황 판단에는 그럴듯한 조건과 오답

5. 원문에 해설·정답이 없는 자료는 별도 경로로 다룬다.
   - 원문 근거 정답과 모델이 계산·검증한 정답을 구분한다.
   - 직접 풀이가 필요한 목표를 네 문제 형식으로 완전 지원한다고 표시하지 않는다.

## 현재 판정

- 개념·분류·관계 자료: 알파 수준에서 사용 가능
- 수행·발화·계산 자료: 보조 학습 수준
- 해설 없는 문제집: 현재 자동 생성 결과를 원문 기반 완전 학습으로 제공하면 안 됨
