# Gold Reference 초안: OPIc 인물 묘사 패턴

## 1. 문서 목적

이 문서는 OPIc 인물 묘사 패턴 PDF에서 학습자료를 만들 때, 사람이 "좋은 결과라면 무엇이 나와야 하는가"를 검토하기 위한 첫 번째 gold/reference 사례다.

자동 채점 규칙, 고정된 카드 개수 또는 유일한 정답 문구를 정의하지 않는다. 대신 반드시 포착해야 할 학습 기능, 권장하거나 조건부로 포함할 대상, 제외할 내용과 적절한 인출 방향을 명시한다.

이 문서에서 가장 중요한 판정 원칙은 다음과 같다.

> 핵심 LearningUnit의 의미와 학습 기능을 포착하는 것이 필수이며, 대표 카드의 정확한 문구나 정확한 카드 개수는 필수가 아니다. 원문 의미, 학습 목표, 인출 방향을 보존한다면 자연스러운 표현 차이는 허용한다.

다만 여러 독립적인 LearningUnit을 부적절하게 한 카드로 합치거나, 하나의 단위를 의미 없이 여러 카드로 쪼개는 것은 허용 가능한 변형으로 보지 않는다.

이 사례는 반복되는 구체 예시에서 재사용 가능한 표현을 찾는 **패턴 추상화 중심 자료**의 reference다. 이 사례 하나를 근거로 Study Forge 전체의 eval schema를 확정하지 않는다. 향후 CS 개념, 단어 암기, 절차 학습처럼 성격이 다른 자료의 gold/reference를 추가한 뒤 공통 평가 구조를 결정한다.

## 2. 원자료

- 자료: `1.pdf`
- 주제: OPIc 인물 묘사 만능 패턴과 완성 스크립트
- 분량: 5페이지
- 구성:
  - 1페이지: 인물 묘사 답변 전략, 패턴 1~3
  - 2페이지: 패턴 4~7
  - 3~4페이지: 학교 동기, 이웃, 배우, 건강한 사람에 대한 완성 스크립트
  - 5페이지: 쉐도잉 목적과 수행 방법

원자료는 텍스트 레이어가 없는 이미지형 PDF이므로 페이지 이미지를 기준으로 내용을 확인했다.

## 3. 이 사례의 학습 목표

### 주 목표

OPIc 인물 묘사 질문을 받았을 때, 학습자가 다음을 할 수 있게 한다.

1. 인물 소개부터 마무리 평가까지 답변의 기본 흐름을 떠올린다.
2. 말하고 싶은 한국어 의미나 발화 의도를 보고 대응하는 영어 표현을 직접 생성한다.
3. 학교 동기, 이웃, 배우, 건강한 사람 등 인물 유형이 달라져도 공통 패턴의 변수 자리를 바꾸어 재사용한다.
4. 완성 스크립트 하나를 통째로 외우는 대신, 여러 스크립트를 구성하는 공통 스피킹 패턴을 인출한다.

### 이 reference에서 선택한 카드 형식

- 기본 인출 방향: 한국어 의미 또는 발화 의도 → 영어 표현
- 기본 변수 처리: 재사용 가능한 변수 자리를 남기는 템플릿형
- 기본 카드 크기: 한 카드에 하나의 발화 기능 또는 하나의 의미상 묶음

따라서 완성 예문의 이름, 나이, 외모와 관계를 임의의 값으로 채워 암기하는 결과는 이 reference의 기본 gold로 보지 않는다. 사용자가 별도로 완성 예문형을 선택하는 경우에는 다른 정답 구성이 가능하다.

## 4. LearningUnit 분류와 필수 의미 조건

이 사례의 LearningUnit은 다음 세 종류로 구분한다.

- **필수 핵심 LearningUnit**: LU-01~LU-07. 인물 묘사 스피킹 패턴의 생산적 인출을 위해 의미적으로 반드시 포착해야 한다.
- **권장·보조 LearningUnit**: LU-00. 답변 전체를 조직하는 데 유용하지만, 없다는 이유만으로 결과를 실패로 평가하지 않는다.
- **조건부 LearningUnit**: LU-05A. 배우나 공적 인물 영역이 학습 범위에 포함될 때 기대한다.

필수 여부는 아래에 적힌 영문 문자열의 정확한 재현 여부가 아니라, 해당 발화 기능과 의미를 학습 목표에 맞는 인출 형태로 보존했는지를 기준으로 판단한다.

### LU-00. 인물 묘사 답변의 기본 흐름

- **구분**: 권장 학습 단위·별도 구조 학습 후보
- **학습 대상**: 인물 소개 → 기본 정보와 관계 → 외모 또는 구체적 특징 → 좋아하는 이유 → 처음 알게 된 계기 → 이후 관계 변화 → 인물에 대한 최종 생각
- **학습 의도**: 인물 묘사 질문에 답할 때 문장을 무작위로 나열하지 않고 재사용 가능한 이야기 흐름을 구성한다.
- **원문 근거**:
  - 1페이지의 `답변 전략`: 이름·나이·배경, 구체적 설명, 알게 된 계기, 인물에 대한 생각
  - 3~4페이지의 네 완성 스크립트가 같은 순서를 반복해 보여준다.
- **주의**: 모든 답변에 일곱 단계를 기계적으로 강제하는 규칙은 아니다. 질문이 요구하는 정보에 맞게 일부 단계를 줄이거나 강조할 수 있다. LU-01~LU-07을 잘 추출했는데 LU-00 또는 답변 흐름 카드를 만들지 않았다는 이유만으로 실패로 평가하지 않는다.

### LU-01. 인물 주제와 이름 소개

- **구분**: 필수 패턴 단위
- **학습 대상**: 누구에 대해 말할지 밝히고 이름을 소개한다.
- **학습 의도**: 답변 도입부를 즉시 생성한다.
- **재사용 패턴**: `I'd like to talk about [인물 또는 관계]. His/Her name is [이름].`
- **원문 근거**:
  - 1페이지 `PATTERN #1`
  - 3~4페이지의 학교 동기, 이웃, 배우, 건강한 사람 스크립트 도입부
- **추상화 판단**: `my classmate`, `my neighbor`, `my favorite actress`, `a healthy person`은 서로 다른 핵심 카드가 아니라 `[인물 또는 관계]`에 들어갈 근거 예시다.

### LU-02. 관계·배경과 나이 설명

- **구분**: 필수 패턴 단위
- **학습 대상**: 인물의 관계나 배경을 말하고 대략적인 나이를 덧붙인다.
- **학습 의도**: 기본 인물 정보를 한 흐름으로 제시한다.
- **재사용 패턴**: `He/She is [관계 또는 배경 설명] and he/she is about [나이] years old.`
- **허용 가능한 간결화**: 두 번째 `he/she is`를 생략해 `He/She is [설명] and about [나이] years old.`로 만들 수 있다.
- **원문 근거**:
  - 1페이지 `PATTERN #2`
  - 3~4페이지의 나이와 관계·배경 설명 문장
- **주의**: `close friend`, `close neighbor`, `attractive actress`, `really healthy girl`은 완성 예시이며 기본 gold 카드에서 고정 답으로 만들지 않는다.

### LU-03. 외모 묘사로 전환하기

- **구분**: 필수 패턴 단위
- **학습 대상**: 외모라는 하위 주제로 전환하고 인물의 외형을 설명한다.
- **학습 의도**: 인물 묘사 답변에서 외모 정보를 자연스럽게 연결한다.
- **재사용 패턴**: `To talk about his/her appearance, he/she is [외모 설명].`
- **사용 가능한 확장**: 외모 특성에 따라 `he/she has [신체 특징]`을 함께 사용할 수 있다.
- **원문 근거**:
  - 1페이지 `PATTERN #3`
  - 1페이지 예시의 `very tall and has brown eyes`
  - 4페이지 배우와 건강한 사람 스크립트의 외모 문장
- **추상화 판단**: `very tall`, `brown eyes`, `blonde hair`, `fit`을 각각 필수 카드로 만들기보다 외모 전환 패턴의 변수 예시로 본다.

### LU-04. 좋아하는 이유를 구체적으로 말하기

- **구분**: 필수 패턴 단위
- **학습 대상**: 인물을 좋아하는 이유를 구체적인 특징과 연결한다.
- **학습 의도**: 단순 호감 표현을 이유가 있는 설명으로 확장한다.
- **재사용 패턴**: `I especially like him/her because [구체적인 특징 또는 이유].`
- **원문 근거**:
  - 2페이지 `PATTERN #4`
  - 2페이지의 영화 취향 예시
  - 3~4페이지의 연기력, 긍정적인 태도 등 문맥별 변형
- **추상화 판단**: 영화 취향, 연기력, 긍정적인 태도는 이유 자리에 들어가는 예시다. 각 예시를 모두 필수 핵심 카드로 만들지 않는다.

### LU-05. 처음 알게 된 계기 말하기

- **구분**: 필수 패턴 단위
- **학습 대상**: 개인적으로 아는 인물을 언제 또는 어떤 상황에서 처음 알게 되었는지 설명한다.
- **학습 의도**: 관계의 시작을 과거 사건과 연결해 이야기한다.
- **재사용 패턴**: `I first got to know him/her when [처음 알게 된 상황].`
- **원문 근거**:
  - 2페이지 `PATTERN #5`
  - 2페이지의 학교 첫 수업 예시
  - 3페이지의 학교 동기와 이웃, 4페이지의 건강한 사람 스크립트
- **추상화 판단**: 첫 수업, 이사, 헬스장 운동은 서로 다른 핵심 카드가 아니라 `[처음 알게 된 상황]`의 적용 예시다.

### LU-05A. 공적인 인물을 처음 접한 계기 말하기

- **구분**: 조건부 변형 단위
- **포함 조건**: 배우처럼 개인적으로 알게 된 사람이 아니라 작품이나 매체를 통해 처음 본 인물까지 학습 범위에 포함할 때
- **학습 대상**: 공적인 인물을 처음 본 계기나 작품을 설명한다.
- **학습 의도**: 개인적 관계가 없는 인물에게 `got to know`를 부자연스럽게 적용하지 않는다.
- **재사용 패턴**: `I first saw him/her when [처음 본 상황].`
- **원문 근거**: 4페이지 배우 스크립트의 `I first saw her when I watched "The Hunger Games."`
- **주의**: LU-05와 같은 카드 안에서 두 표현을 동시에 답하게 하지 않는다. 문맥별 별도 카드로 만들거나, 배우 영역을 선택한 경우에만 이 변형을 사용한다.

### LU-06. 이후의 관계 변화 말하기

- **구분**: 필수 패턴 단위
- **학습 대상**: 첫 만남 이후 현재의 관계나 역할이 어떻게 되었는지 설명한다.
- **학습 의도**: 과거의 만남을 현재 관계와 연결해 짧은 스토리라인을 완성한다.
- **재사용 패턴**: `Since then, he/she has become [현재 관계 또는 역할].`
- **원문 근거**:
  - 2페이지 `PATTERN #6`
  - 3~4페이지의 `best friend`, `favorite actress`, `exercise buddy` 변형
- **추상화 판단**: 현재 관계나 역할은 변수로 남긴다. 구체적인 역할을 임의로 만들어 고정하지 않는다.

### LU-07. 인물에 대한 최종 생각 말하기

- **구분**: 필수 패턴 단위
- **학습 대상**: 인물에 대한 자신의 평가나 생각으로 답변을 마무리한다.
- **학습 의도**: 묘사한 사실을 개인적인 평가와 연결하고 답변을 닫는다.
- **재사용 패턴**: `I think he/she is [인물에 대한 생각 또는 평가].`
- **원문 근거**:
  - 2페이지 `PATTERN #7`
  - 3~4페이지의 `a very nice guy`, `a very talented woman`, `a very nice role model` 변형
- **주의**: 평가 내용은 원자료의 예시를 그대로 암기하도록 강제하지 않는다. 사용자가 말하려는 인물에 맞게 채울 변수다.

## 5. LearningUnit이 아닌 생성·검토 제약

다음 항목은 최종 영어 표현의 정확성과 일관성을 검사하는 데 중요하지만, 이 학습 목표에서는 독립적인 핵심 카드로 만들 필요가 없다.

### 3인칭 단수와 대명사 일치

- 1페이지 답변 전략은 주어가 대부분 3인칭 단수이므로 주어·동사 수 일치에 주의하라고 안내한다.
- `he/she`, `his/her`, `is/has`의 일관성은 카드 품질 검사 조건으로 사용한다.
- 현재 목표가 인물 묘사 패턴 인출이므로 문법 규칙 자체를 별도 정의 카드로 만드는 것은 우선하지 않는다.

### 변수 일관성

- 하나의 템플릿 카드 안에서 인물의 성별 대명사와 관계 표현이 충돌하지 않아야 한다.
- 템플릿형을 선택한 경우 임의의 이름, 나이와 특징을 모델이 사실처럼 채우지 않는다.

## 6. 제외 항목과 제외 유형

제외는 해당 내용에 본질적인 학습 가치가 없다는 뜻과 같지 않다. 현재 학습 목표 밖이라 제외하는 경우와, 현재 목표 안에서도 중복되거나 학습 가치가 낮아 제외하는 경우를 구분한다.

### A. 현재 학습 목표 범위 밖

이 항목들은 다른 학습 목표에서는 유효한 학습 대상이 될 수 있지만, 현재 목표인 "인물 묘사 영어 패턴의 생산적 인출"에는 포함하지 않는다.

#### 쉐도잉 목적과 방법

- **분류**: `out_of_scope_for_current_goal`
- **원문 위치**: 5페이지
- **내용**: 전달력과 톤을 따라 하는 목적, 음성 파일 재생, 약 0.5초 뒤 따라 하기, 반복 횟수와 기간에 대한 안내
- **제외 이유**: 영어 인물 묘사 표현이 아니라 발화 연습 절차다. 핵심 LearningUnit이나 영어 패턴 카드로 만들지 않는다.

#### OPIc 질문 원문 전체

- **분류**: `out_of_scope_for_current_goal`
- **원문 위치**: 3~4페이지
- **제외 이유**: 질문은 답변 문맥을 보여주지만 현재 핵심 암기 대상은 인물 묘사 답변 패턴이다. 질문별 전체 문장을 각각 암기 카드로 만들지 않는다.
- **주의**: 향후 질문 청취·유형 판별을 별도 학습 목표로 두면 LearningUnit이 될 수 있다.

#### `about`, `that` 뒤의 키워드에 집중하라는 안내

- **분류**: `out_of_scope_for_current_goal`
- **원문 위치**: 1페이지 답변 전략
- **제외 이유**: 패턴을 분석하고 연습하는 방법에 관한 보조 지시다. 독립적인 인물 묘사 영어 표현이 아니다.

### B. 현재 목표에서도 중복되거나 학습 가치가 낮음

이 항목들은 현재 목표와 관련된 자료에 포함되어 있더라도 별도 핵심 카드로 만들 실익이 낮다.

#### 반복되는 완성 스크립트 전체

- **분류**: `redundant_example`
- **원문 위치**: 3~4페이지
- **내용**: 학교 동기, 이웃, 배우, 건강한 사람에 대한 전체 답변
- **제외 이유**: 네 스크립트는 대부분 같은 7개 패턴에 변수만 바꿔 적용한 예시다. 스크립트 문장마다 카드를 만들면 같은 패턴이 중복된다.
- **사용 방식**: 공통 패턴의 근거, 변수 예시와 문맥별 변형을 검증하는 자료로 사용한다.

#### 이름·나이·외모만 바뀐 고정 인물 정보

- **분류**: `redundant_example`
- **원문 위치**: 3~4페이지
- **예시**: Tom, Jennifer Lawrence, Amy, 21세, 25세, 27세, 갈색 눈, 금발 머리
- **제외 이유**: 이 PDF의 주 학습 목표는 해당 사실 암기가 아니라 패턴의 재사용이다. 변수 자리에 들어갈 예시로만 사용한다.

#### 반복되는 한국어 해석

- **분류**: `redundant_example`
- **원문 위치**: 1~4페이지
- **제외 이유**: 영어 패턴의 의미와 앞면 인출 단서를 구성하는 근거로는 사용하되, 영어 문장과 해석을 각각 별개의 핵심 지식으로 중복 카드화하지 않는다.

#### 단순 학습 독려 문구

- **분류**: `low_learning_value`
- **원문 위치**: 5페이지
- **예시**: 쉐도잉 효과에 대한 감탄, 매일 실천하라는 독려 문구
- **제외 이유**: 현재 학습 목표에 필요한 지식이나 인출 대상을 제공하지 않는다.

#### 페이지 정보와 교재 고지

- **분류**: `metadata`
- **원문 위치**: 각 페이지의 페이지 번호, 웹사이트와 하단 저작권 고지
- **제외 이유**: 학습 목표와 관계없는 문서 메타데이터다.

## 7. 허용 가능한 대표 카드 예시

아래 카드는 이 reference의 기본값인 "한국어 의미 → 영어 템플릿"을 적용한 좋은 결과의 예시다. 정확한 문구나 정확한 카드 개수를 gold 정답으로 요구하지 않는다. 핵심 LearningUnit의 의미, 원문 근거와 인출 방향을 보존한다면 더 자연스러운 한국어 단서, 대명사 표기 또는 동등한 영어 표현을 허용한다.

반대로 카드 수를 맞추기 위해 하나의 LearningUnit을 의미 없이 나누거나, 카드 수를 줄이기 위해 여러 독립적인 LearningUnit을 한 카드에서 동시에 답하게 하는 것은 허용하지 않는다. 앞면에는 `다음 뜻을 영어로 말하세요` 같은 반복적인 메타 문구를 붙이지 않는 것을 선호한다.

### 허용 가능한 보조 카드. 답변 흐름

- **앞면**: OPIc 인물 묘사 답변의 기본 흐름은?
- **뒷면**: 인물 소개 → 기본 정보·관계 → 외모·구체적 특징 → 좋아하는 이유 → 처음 알게 된 계기 → 이후 관계 변화 → 최종 생각
- **근거**: 1페이지, 3~4페이지
- **지위**: 권장·보조 예시. 이 카드가 없다는 이유만으로 실패로 평가하지 않는다.

### 대표 카드 예시 1. 인물과 이름 소개

- **앞면**: 저는 [인물 또는 관계]에 대해 이야기하려 합니다. 그 사람의 이름은 [이름]입니다.
- **뒷면**: `I'd like to talk about [person or relationship]. His/Her name is [name].`
- **근거**: 1페이지 `PATTERN #1`

### 대표 카드 예시 2. 관계·배경과 나이

- **앞면**: 그 사람은 [관계 또는 배경 설명]이고 대략 [나이]살입니다.
- **뒷면**: `He/She is [relationship or background] and about [age] years old.`
- **근거**: 1페이지 `PATTERN #2`

### 대표 카드 예시 3. 외모 묘사

- **앞면**: 그 사람의 외모에 대해 말하자면, 그 사람은 [외모 설명]입니다.
- **뒷면**: `To talk about his/her appearance, he/she is [appearance description].`
- **근거**: 1페이지 `PATTERN #3`
- **주의**: 신체 특징이 필요한 경우 `and has [physical feature]`를 사용할 수 있지만 한 가지 고정 외모를 정답으로 강제하지 않는다.

### 대표 카드 예시 4. 좋아하는 이유

- **앞면**: 저는 특히 [구체적인 특징 또는 이유] 때문에 그 사람을 좋아합니다.
- **뒷면**: `I especially like him/her because [specific trait or reason].`
- **근거**: 2페이지 `PATTERN #4`

### 대표 카드 예시 5. 처음 알게 된 계기

- **앞면**: 저는 [처음 알게 된 상황]에 그 사람을 처음 알게 되었습니다.
- **뒷면**: `I first got to know him/her when [situation].`
- **근거**: 2페이지 `PATTERN #5`

### 대표 카드 예시 6. 이후의 관계

- **앞면**: 그 이후로 그 사람은 제 [현재 관계 또는 역할]이 되었습니다.
- **뒷면**: `Since then, he/she has become [current relationship or role].`
- **근거**: 2페이지 `PATTERN #6`

### 대표 카드 예시 7. 최종 생각

- **앞면**: 저는 그 사람이 [생각 또는 평가]라고 생각합니다.
- **뒷면**: `I think he/she is [opinion or evaluation].`
- **근거**: 2페이지 `PATTERN #7`

### 조건부 카드. 배우 등 공적인 인물을 처음 본 계기

- **포함 조건**: 학습 범위에 배우와 같이 개인적으로 알지 못하는 인물 묘사가 포함될 때
- **앞면**: 저는 [처음 본 상황]에 그 사람을 처음 보았습니다.
- **뒷면**: `I first saw him/her when [situation].`
- **근거**: 4페이지 배우 스크립트

## 8. 사람이 검토할 때의 합격 기준

### LearningUnit 수준

- 인물과 이름 소개, 관계·배경과 나이, 외모 묘사, 좋아하는 이유, 처음 알게 된 계기, 이후 관계 변화, 최종 생각이라는 7개 필수 학습 기능이 의미적으로 포착되었는가?
- 완성 스크립트의 반복 문장보다 공통 패턴을 핵심으로 추출했는가?
- 개인적으로 아는 인물과 공적인 인물의 첫 접촉 표현 차이를 필요한 경우 구분했는가?
- 각 단위가 하나의 명확한 발화 기능을 가지는가?
- 각 단위가 실제 PDF 페이지에 근거하는가?
- 쉐도잉 방법을 핵심 영어 표현 LearningUnit으로 잘못 포함하지 않았는가?
- LU-00이 없다는 이유만으로 7개 핵심 패턴을 충족한 결과를 실패로 판단하지 않았는가?

### 카드 수준

- 기본 인출 방향이 한국어 의미 또는 발화 의도 → 영어 표현인가?
- 변수 자리가 유지되어 다른 인물과 상황에 재사용 가능한가?
- 한 카드가 가능한 한 하나의 패턴만 요구하는가?
- `다음 뜻을 영어로 말하세요` 같은 불필요한 메타 문구가 없는가?
- 원문에 없는 이름, 나이, 외모와 관계를 임의로 추가하지 않았는가?
- 대명사와 3인칭 단수 표현이 일관되는가?
- 자연스러운 표현 차이를 exact match 실패로 잘못 판단하지 않았는가?
- 여러 독립적인 LearningUnit을 한 카드에서 동시에 요구하거나 하나의 단위를 의미 없이 분할하지 않았는가?

### 카드 묶음 수준

- 학교 동기, 이웃, 배우, 건강한 사람의 완성 예시가 각각 중복 카드 묶음으로 생성되지 않았는가?
- 같은 패턴의 구체 예시와 일반화된 템플릿이 불필요하게 동시에 핵심 카드가 되지 않았는가?
- 카드 수가 많다는 이유로 더 좋은 결과라고 판단하지 않는가?
- 사용자가 인물 묘사 답변을 구성하는 데 필요한 범위는 충분히 남아 있는가?

## 9. 현재 reference에서 확정한 분류

### LU-00 답변 흐름

- 필수 gold에서 제외한다.
- 권장 학습 단위 또는 별도 구조 학습 후보로 둔다.
- 답변 흐름 카드가 없어도 7개 필수 패턴의 의미와 학습 기능을 잘 포착했다면 실패로 평가하지 않는다.

### 외모 패턴의 두 문법 형태

- `be + 형용사`와 `have + 신체 특징`을 현재 별도 필수 카드로 분리하지 않는다.
- 기본 외모 패턴이 다양한 외모 설명으로 확장될 수 있다는 점만 기록한다.
- 향후 두 형태를 독립적으로 생산하는 능력이 별도 목표가 되면 분리 여부를 다시 결정할 수 있다.

### 배우 문맥의 `I first saw him/her when ...`

- 조건부 LearningUnit으로 유지한다.
- 배우나 공적 인물 영역이 학습 범위에 포함되는 경우에만 기대한다.
- 일반적인 지인 묘사만 선택된 결과에 이 패턴이 없다는 이유로 실패로 평가하지 않는다.

### 완성 예문 적용 카드

- 이번 첫 gold/reference에서는 필수로 요구하지 않는다.
- 이번 사례는 반복 예시에서 재사용 가능한 템플릿을 추출하는 능력을 평가하는 데 집중한다.
- 향후 `템플릿 + 적용 연습`을 별도 학습 목표로 둔 eval 사례에서 완성 예문 카드의 적절성을 다룬다.

현재 reference는 exact-match 정답 세트가 아니라, 패턴 추상화 자료에서 좋은 결과가 충족해야 할 의미적 조건과 허용 범위를 정의한다.
