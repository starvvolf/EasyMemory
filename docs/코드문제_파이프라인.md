# 코드 문제 파이프라인 (미팅용 학습 자료, 2026-10-28 · 10-29 시간 줄이기 반영)

코드 탭에서 문제 하나가 만들어지고, 풀리고, 지식으로 남기까지의 길이다. 코드 위치: `src/lib/code/`, `src/lib/assist/code-ai.ts`, 화면 `src/app/study/workspace/CodeStudy.tsx`.

## 10/29 바뀐 점: 가져온 문제는 네 호출을 동시에

백준 번호·주소로 가져와 원문이 있으면 ②를 넷으로 나눠 동시에 부른다: 문제 세팅(모범·단순 풀이·지식), 테스트 생성기, 틀린 풀이, 독립 풀이. 각자 원문만 보고 쓴다. 문제 글·예제는 원문 그대로 쓴다. 검사(③④)는 그대로. 요청부터 저장까지 15~23초(전에는 25~43초). 그리고 **바로 열기**: 원문을 받자마자(2~6초) 문제를 연다. 학습자가 읽고 예제를 돌리는 동안 뒤에서 테스트를 만들고, 끝나면 제출이 열린다. 독립 풀이와 어긋나 다시 할 때는 독립 풀이도 새로 받는다. 주제로 새로 만드는 문제는 위 그림 그대로.

## 단계별 입력 → 출력

| 단계 | 입력 | 하는 일 | 출력 | AI |
|---|---|---|---|---|
| ① 가져오기 | 주소, 백준 번호 | 백준 번호·주소면 아카이브 원문. 블로그면 본문, 그 글이 백준 문제 하나를 가리키면 원문을 먼저. 막힌 페이지는 아카이브 사본 | 문제 글, 출처 주소 | 없음 |
| 같은 주소 확인 | 출처 주소 | 같은 주소·같은 종류로 만든 문제가 있으면 멈추고 [열기]/[새로 만들기] | — | 없음 |
| ② 초안 | 문제 글, 학습자 지식 목록 | 원문 문제가 있으면 그대로, 없으면 새로 씀 | 문제·제약, 모범 풀이, 단순 풀이(brute), 테스트 생성기, 틀린 풀이, 지식 이름·뜻 | 1번 |
| ②' 독립 풀이 | 문제 글·예제만 | 다른 모델이 처음부터 풂 | 두 번째 풀이 코드 | 1번 (②와 동시) |
| ③ 테스트 | 생성기, 모범·단순·틀린 풀이 | 입력을 만들고 제약 검사 → 모범 풀이로 기대 출력. 원문 예제가 없으면 작은 입력 30개 이상에서 단순 풀이와 같아야 함 | 숨은 테스트 20~40개, 틀린 풀이 검출 점수 | 없음 |
| ④ 대조 | 독립 풀이, 테스트 | 모든 테스트에서 같은지. 다르면 단순 풀이가 누가 맞는지 정함 | 통과 / 다시(이유를 모델에 돌려줌) | 없음 |
| ⑥ 채점 | 학습자 코드 | 로컬 컴파일러로 실행, 출력 비교. 처음 틀린 테스트 하나만 보여 줌 | 맞았습니다·틀렸습니다·시간 초과·메모리 초과·런타임·컴파일 | 없음 |
| 힌트 | 문제, 내 코드, 이번 풀이 기록 | 1 방향 → 2 문제 되는 줄 → 3 고친 줄 | 힌트 글 | 1번씩 |

AI는 만들고(②) 돕기만(힌트) 한다. **정답 판정은 전부 코드**(실제 실행과 비교)다.

## 실제 예 (10/28 모델 비교, 같은 입력 5개)

- gpt-6.1-terra: 5개 모두 첫 시도에 통과, 문제 하나에 약 60초.
- gpt-5.6-terra: 80~95초. gpt-6-luna: 4개 중 1개만 첫 시도 통과(예제를 잘못 읽고, 답 종류를 틀림).
- 그래서 초안은 6.1 terra, 독립 풀이는 일부러 다른 모델(5.6 terra) — 같은 실수를 같이 하지 않게.

## 교수님이 물을 만한 질문

1. **AI가 만든 문제의 정답이 맞는지 어떻게 아나?**
   세 겹이다. 원문 예제와 맞아야 하고(없으면 느리지만 단순한 풀이와 작은 입력 30개 이상에서 같아야 하고), 다른 모델이 문제 글만 보고 따로 푼 답이 모든 테스트에서 같아야 한다. 어긋나면 저장하지 않고 이유를 돌려줘 다시 만든다(최대 3번).
2. **테스트가 충분히 빡센지는?**
   흔한 실수가 든 틀린 풀이 3~5개를 같이 만들고, 숨은 테스트가 그걸 몇 개 잡는지 센다. 최대 크기 입력도 모양별로(무작위·정렬·중복·최악) 넣는다.
3. **채점은 어디서, 공정한가?**
   학습자 PC에서 Python·JS·C++·C#을 실제로 돌린다. Windows 작업 개체로 CPU 시간·메모리를 재고, 처음 한 번 PC 속도를 재서 기준 PC에 맞춰 보정한다.
4. **비용은?**
   문제 하나에 모델 호출 2번(초안·독립 풀이, 동시) + 실패 시 다시. 힌트는 누를 때만 1번. 채점·테스트 생성은 호출이 없다. ChatGPT 계정 구독 사용량으로 돈다.
5. **결과가 공부에 어떻게 남나?**
   문제마다 지식(예: 이분 탐색)이 붙는다. 풀이 중 틀림·힌트·질문은 "이번 풀이"에 모았다가 끝날 때 한 번에 기록해, 힌트를 받고 맞히면 "앎"이 되지 않는다. 그 기록이 복습 날짜를 정한다.

## 한계 (솔직하게)

- 답이 여러 개이거나 실수 오차를 허용하는 문제는 아직 채점하지 않아 만들지 않는다.
- 만드는 데 1~2분(실패하면 더) 걸리고, 그동안 진행 단계가 화면에 안 보인다.
- 독립 풀이도 AI라, 두 모델이 같은 실수를 하면 못 잡는다(단순 풀이 대조가 그걸 일부 막음).
- 모델 비교는 입력 5개뿐이다. 그래프·DP·문자열·큰 수 같은 다른 유형은 더 확인해야 한다.
