## 알파 테스트 준비 결과

- 모바일에서는 덱을 가로 칸반 대신 세로 목록과 상태 필터로 사용할 수 있다.
- 모바일·태블릿 PDF는 화면 너비에 맞춰 표시되고 원문 오른쪽이 잘리지 않는다.
- 잘못된 플래시카드·OX·객관식·구조복원 문제는 저장 전에 차단된다.
- 첫 화면은 PDF, 학습목표, 분석 시작을 우선하며 참고 자료와 추가 지시는 접혀 있다.
- 생성 진행은 추정 퍼센트가 아니라 실제 처리 단계를 보여준다.

## AI 대리 사용자 알파 결과

- 화면만 사용하는 AI 사용자 5명이 모바일 학습, 태블릿 PDF 가림, 데스크톱 실제 생성, 새로고침 복원과 정답 누출 재현을 나눠 점검했다.
- 권리장전 PDF는 실제 API로 분석부터 혼합 문제 8개 생성·저장·첫 문제 시작까지 완료했다.
- PDF 가림 전에 학습목표와 성공 기준이 정답을 노출하는 문제가 두 번 재현되어, 정답 확인 전에는 일반 안내만 보이도록 수정하고 브라우저에서 재검증했다.
- 새로고침 복원 실패는 한 번 보고됐지만 독립 재현에서는 같은 다음 문제와 누적 점수가 자동 복원돼 반복 문제로 확정하지 않았다. 초기 생성 화면이 잠깐 보이는 현상은 이후 개선 후보로 남겼다.
- 전체 덱 제목이 첫 학습 항목으로 표시되는 문제와 혼합 문제를 플래시카드로 표시하는 오류를 수정했다.
- 독립 평가 결과는 알파 진입 합격이다. 실제 사용자 분포를 대신하는 최종 검증은 아니며 생성 품질 변동은 계속 별도 평가한다.

## AI 선생님 자료별 품질 평가

- OPIc·데드락·권리장전·달의 위상·재난 체크리스트·미적분·DFS/BFS 7종에서 선생 기대표와 실제 앱 결과를 비교했다.
- 명시적 승인 후 6종의 문제 생성만 Terra로 다시 실행했다. 새 점수는 권리장전 6.8, DFS/BFS 7.0(기존 결과), 데드락 6.5, 재난 6.0, 달의 위상 5.1, 미적분 4.5, OPIc 5.0이다.

- 공통 문제는 부분 지원 목표를 전부 버리거나 반대로 완전 지원으로 과장하는 불일치다.
- 같은 학습내용으로 문제만 다시 만들어도 점수가 오르거나 내려갔다. 다음 생성 품질 목표는 자료 전체 목표 대응표와 함께 `추천한 행동이 실제 문항에 요구되는지`, `정답 단서가 앞면에 노출되는지`, `추천 항목이 빠지지 않았는지` 검사하는 것이다.
- 상세 보고서는 `docs/TEACHER_AI_PDF_EVALUATION.md`에 저장했다.

## 발견된 문제

### 우선 수정할 문제

- 순서 복원 문제의 답 모음은 화면에서 섞고 같은 학습 시도 안에서는 순서를 유지하도록 수정했다.
- AI는 한 번의 Terra 배치 호출로 회상, OX, 객관식, 순서, 순서 없음, 상하 구조 6종을 모두 유효한 QuestionSet으로 생성했다.
- 잘 정리된 고정 예시에서는 통과했지만 실제 PDF에서 나온 복잡한 학습단위에 대한 회귀검증은 아직 필요하다.

### 생성 품질 문제

- 관련된 여러 개념을 하나의 부모와 자식 구조로 억지 연결하는 문제가 있었다.
- 클레임 간선 변화와 다중 인스턴스 처리처럼 서로 다른 관계가 한 구조복원 문제에 섞이면 안 된다.
- 기존에 저장된 잘못된 구조 문제는 자동으로 내용까지 고쳐지지 않으므로 새 규칙으로 다시 생성해야 한다.

### 현재 범위의 한계

- 장문 서술형과 여러 동의어가 가능한 답은 아직 안정적으로 자동채점하지 않는다.
- 선생님용 문제 제작 도구는 별도 작업 공간에 있어 본 앱에서 바로 사용할 수 없다.
