# Recaller

개인 학습자료를 능동 인출 연습과 반복학습으로 연결하는 프로젝트입니다.

현재 통합 기준 브랜치: **codex/recaller-integration**

- [노트북·새 담당 시작 문서](docs/handoff/START_HERE.md)
- [통합 내역과 검증 결과·제한](docs/handoff/INTEGRATION_REPORT.md)

실행 환경은 Node.js 24와 npm을 기준으로 검증했습니다. 설치는 `npm ci`, 실행은 `npm run dev`입니다. Firebase 및 AI 계정 설정은 별도이며 키와 개인 학습자료는 저장소에 포함하지 않습니다. 새 문제작성 틀은 실험 도구로 포함돼 있고, 제품 화면 전체에 연결된 상태는 아닙니다.
