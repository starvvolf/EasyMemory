# Recaller (배포판)

이론(PDF)은 읽어서, 알고리즘은 풀어서, 실습에서는 만들어 보며 배운 것을 기억 하나로 쌓고, 잊을 때쯤 다시 묻는 PC 학습 앱입니다.

이 브랜치(`release`)는 `claude/recaller2`에서 실험용 화면 · 실험 데이터 · 개발 문서를 뺀 가벼운 판입니다(2026-11-13).
개발은 `claude/recaller2`에서 하고, 배포판은 거기서 다시 떠 옵니다.

## 켜고 끄기

`Recaller 앱.cmd` 하나만 씁니다. 처음 한 번 바탕화면에 `Recaller` 바로가기를 만듭니다.

- **켤 때**: 패키지(바뀐 때만) → 데이터 받기(RecallerData) → 앱 서버(127.0.0.1:3000) → 실습 서버(4100) → 창 열기
- **끌 때**: 창의 X(또는 Ctrl+Q) → 실습 서버 끄기 → 앱 서버 끄기 → 데이터 올리기

Node.js 24, AI는 ChatGPT 계정 로그인. 키와 개인 학습자료는 이 저장소에 넣지 않습니다.

## 폴더

| 폴더 | 무엇 |
|---|---|
| `src/` | 앱(Next.js). 화면 `src/app/study`, API `src/app/api`, 기능 `src/lib` |
| `desktop/` | Electron 앱(켜고 끄기) |
| `experiments/project-course/` | 실습 서버(4100) · 앱 안 편집기(4103) · VS Code 확장 |
| `extension/` | 크롬 확장(웹 글) |
| `scripts/` | 앱 켜기·끄기·데이터 동기화·보관 · 시연 상태 저장/되돌리기 |
| `tools/` | `시연 준비.cmd`, `데이터 보관하고 새로 시작.cmd`, 앱이 쓰는 문제·근거 도우미 코드 |
| `출제기준/` `평가기준/` `학습규칙/` | 앱이 읽는 규칙 파일 |

실험실 화면(`/lab`, `/lab/ai`, `/lab/gen`, `/lab/review`) · 토론방(`/room`) · 속도 체크 · 더보기의 "개발용 화면",
옛 학습 화면 조각 · 쓰지 않는 API(옛 덱 · 세션 · 프로젝트 · MCP 실험 요청 · 개인화 실험 주기 등),
`lab/` · `eval/`(시험용 PDF 3개만 남김) · `협업/` · `docs/` · `tmp/` · 개발 도구(토큰 사용량 · 작업 현황 · 용량 보기 · 에이전트 MCP) · 문제 만들기 실험 기록,

## 시연

`tools/시연 준비.cmd`: 알고리즘 기록을 "algo" 상태로, 시연용 실습(FPS 동시성)을 시작 상태로 되돌린 뒤 앱에서 F5.
