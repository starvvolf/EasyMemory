# 자유 대화 챗봇 도구 호출 테스트지

작성일: 2026-11-04. 대상: /agent-chat.html에 노출한 7개 도구. 기존 코스의 send_request/run_checks/파일 수정 도구는 이 실험판에 노출하지 않으므로 대상이 아니다.

## 시험하는 것

사용자 질문 하나 안에서 안내 → 도구 실행 상태 → 결과 설명이 이어지는지, 실제로 도구를 썼는지, 저장 상태와 반환 결과가 맞는지 확인한다. 모델이 한 말만 보고 호출 성공으로 치지 않는다.

- 사람용 시험: 아래 질문을 그대로 보내고 [입력·프롬프트 보기 → 실제 모델 입력]의 function_call과 function_call_output, 화면 진행 행, 오른쪽 상태를 확인한다.
- 자동 연결 시험: PC_FAKE_AI=1인 전용 임시 데이터에서 [도구시험:T01] 같은 식별자와 아래 질문을 보낸다. 가짜 모델이 정해진 호출을 내보내지만, 실행은 실제 OpenCode와 실제 파일·검색·코드 실행·상태 저장을 쓴다. 모델의 자연어 의도 판단 품질을 검증한 결과로 해석하지 않는다.
- 각 문항은 별도 새 대화에서 시작한다. 사용자 편집 프롬프트가 있으면 기본값 시험과 편집본 시험 결과를 따로 적는다. 기존 공부 대화를 재시작해서 쓰지 않는다.
- 실제 로그인 모델 시험은 별도 승인을 받은 묶음으로 실행한다. 도구 전후 재호출이 있으므로 질문 수와 실제 모델 호출 수는 다르다. 이번 자동 시험은 실제 AI 사용량이 들지 않는다.

## 공통 합격 기준

1. 준비 안내가 있으면 도구 진행 행보다 앞에 남는다. 모델이 안내를 생략해도 실제 실행 상태는 코드가 표시한다. 내부 생각 전문을 진행 설명으로 노출하지 않는다.
2. 실행 중에는 '진행 중', 끝나면 같은 행에 '완료/실패/중단'이 표시된다. 빠르게 끝나는 도구는 폴링 사이에 완료될 수 있다.
3. 도구 결과가 돌아오면 사용자가 '계속해'를 보내지 않아도 같은 요청 안에서 설명을 이어 간다.
4. 실패·중단 뒤 '진행 중'이 남지 않는다. 완료되지 않은 도구를 성공으로 표시하지 않는다.
5. 관찰은 실제 사용자 메시지 id와 인용을 보존하고 verified=false다. 학습 초점 변경을 실제 코드 검사 통과로 기록하지 않는다.
6. 기록 도구는 매번 예고하지 않아도 된다. 파일 읽기·검색·실행처럼 기다리는 작업은 짧은 설명을 필요에 따라 붙인다.

## 중단·여러 작업·대화 연속성 추가 시험

- C01: 코드 조각을 실행 중일 때 [멈추기]. 진행 행이 중단으로 바뀌고 다음 질문을 보낼 수 있어야 한다. 종료된 이전 작업이 늦게 돌아와도 새 대화에 글을 덧붙이지 않아야 한다. 자동 시험은 지연시킨 실행 콜백을 이용하며, 실제 SDK 중단과 실제 모델 설명 품질은 별도 확인한다.
- C02: T14에서 세 도구의 행이 각각 있어야 한다. 앞 도구 완료 → 다음 안내/작업 → 마지막 설명 순서를 확인한다. 모델이 모든 작업을 시작하기 전에 결과를 이미 확인했다고 단정하면 실패다.
- C03: T10에서 아래 보충을 마친 직후 같은 답으로 위 보충까지 다시 닫으려 하면 거절돼야 한다. 다른 사용자 답을 받은 뒤에만 위 칸 복귀를 허용한다(기존 agent-chat 상태 테스트에도 포함).
- C04: T05처럼 상태 조회만 필요할 때 파일 수정·서버 검사 같은 노출하지 않은 도구가 호출되지 않아야 한다. 실제 요청 tools가 7개 목록과 같은지 자동 시험에서 확인한다.

## 시험 결과 기록 양식

각 문항에 '실행 환경(가짜/로그인) / 편집 프롬프트 여부 / 대화 id / 실제 호출 목록 / 화면 상태 / 상태 변경 / 통과·실패 / 모델 호출 수 / 시간·토큰 / 근거 파일'을 남긴다. 테스트지가 있다는 것, 가짜 모델 연결 시험 통과, 실제 모델이 적절한 도구를 선택했다는 것은 서로 다른 결과다.

자동 실행 명령(프로젝트 코스 폴더):

```powershell
node --experimental-strip-types --disable-warning=ExperimentalWarning --test test/agent-chat-tools.test.ts test/agent-chat.test.ts
```

자동 문항의 정의는 lib/agent-chat-testcases.ts, 실행·순서·상태 검사는 test/agent-chat-tools.test.ts에 있다. 도구를 추가하면 문항 정의와 전체 도구 집합 검사를 같이 갱신한다.
