# 학습규칙

`출제기준/`이 "문제를 어떻게 만들지"라면, 여기는 **"만든 문제로 어떻게 공부시킬지"**다. 코드를 고치지 않고 이 파일만 바꿔서 공부 흐름을 조절한다.

| 파일 | 누가 읽나 | 무엇을 정하나 |
|---|---|---|
| `오늘할것.md` | 학습 화면, `/api/study-plan` | 하루 분량, 새 문제 나누기, 시험 직전 규칙, 첫 훑기 |
| `에이전트.md` | 자동화 에이전트(GPT·Claude·예약 작업) | 에이전트가 혼자 해도 되는 일과 물어봐야 하는 일, 매일 할 일 |

## 쓰는 법
- 기계가 읽는 줄은 `- [키] 값` 하나뿐이다. 나머지 글은 사람이 읽는 설명이다.
- 모르는 키나 범위 밖 값은 무시하지 않고 화면(정리 탭 아래)과 `/api/study-rules`에 경고로 보인다.
- 바꾼 뒤 학습 화면을 새로고침하면 바로 적용된다(빌드 필요 없음).
- 바꾼 이유는 `변경기록`에 한 줄 남긴다(아래).
