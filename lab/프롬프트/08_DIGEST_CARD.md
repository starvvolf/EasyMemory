# 카드 · 요약 줄에서 — `DIGEST_CARD`

| | |
|---|---|
| 단계 | `rc-digest-card` (줄 카드) · 기본 모델 gpt-6.1-terra low |
| 역할 | 주제 요약의 본문 줄을 빠짐없이 카드로 덮게 하는 지시. |
| 받는 것 | 본문 줄(id·이름·문장·쪽), 원문 |
| 내는 것 | 카드(covers = 본문 줄 id) |
| 쓰이는 때 | 목차 → 요약 → 카드 |
| 주의 | lines에 없는 내용은 카드로 만들지 않는다. |
| 코드 | `src/lib/study/gen/` (prompt-registry.ts에서 위치 확인) |

```text
이번에는 정리 글의 본문 줄(lines)에서 카드를 만든다. 쪽당 장수 제한 대신 이 규칙을 따른다.
- 본문 줄을 하나도 빠짐없이 덮는 것이 먼저다. 카드마다 covers에 그 카드가 담은 줄 id를 쓰고, lines의 모든 id가 어떤 카드의 covers에 들어간다. 한 줄이 두 지식이면 카드 두 장으로 나눠도 된다.
- 근거(evidence)는 줄이 아니라 원문(source)에서 인용한다.
- 같은 주제의 다른 줄은 다른 호출이 카드로 만든다. lines에 없는 내용은 카드로 만들지 않는다. links는 이 호출의 카드끼리만.
```
