# 카드 · 항목에서 바로 — `MAP_CARD`

| | |
|---|---|
| 단계 | `rc-digest-card` (줄 카드) · 기본 모델 gpt-6.1-terra low |
| 역할 | 항목(목차가 고른 이름과 쪽)마다 원문을 읽고 카드를 만들게 하는 지시. 앱 기본의 카드 호출. |
| 받는 것 | 주제, 항목 줄(id·이름·쪽), 그 쪽 원문·그림, 용어 목록 |
| 내는 것 | 카드(covers = 항목 id) |
| 쓰이는 때 | mapCards |
| 주의 | 조건 이름은 용어 카드, 판정 규칙은 적용 범위를 condition에, 경계 칸은 원문에 있을 때만. |
| 코드 | `src/lib/study/gen/` (prompt-registry.ts에서 위치 확인) |

```text
이번에는 목차가 고른 항목(lines)마다 원문(source)에서 그 항목의 내용을 찾아 카드를 만든다. 쪽당 장수 제한 대신 이 규칙을 따른다.
- lines는 이 주제가 다루는 항목의 이름과 쪽뿐이다. 항목마다 원문에서 정의·조건·판정 규칙·절차·예제(그림 속 판정 포함)를 읽어 카드로 만든다. 한 항목에 지식이 둘 이상이면(예: 정의와 그것으로 판정하는 규칙) 카드도 나눈다.
- 이름이 붙어 각각 정의되는 항목(예: 발생 조건 네 가지, 간선 종류)은 용어(term) 카드로 만든다. 결과가 "~ 조건이 성립한다"처럼 이름을 되풀이하는 조건(rule) 카드로 만들지 않는다. 조건(rule) 카드는 조건에 따라 결과가 갈리는 판정 규칙에만 쓰고, 원문에 있는 적용 범위(예: 자원 유형마다 인스턴스가 하나일 때)를 condition에 빠짐없이 쓴다.
- 경계(boundary)·한계 같은 칸은 원문에 그 내용(예외, 범위, 주의)이 있을 때만 쓴다. 없으면 빈 문자열로 둔다("원문에 제시되지 않음" 같은 말을 쓰지 않는다). 다른 칸과 같은 말을 되풀이하지 않는다.
- 모든 항목이 적어도 한 카드의 covers에 들어간다. 카드마다 covers에 그 카드가 다룬 항목 id.
- 근거(evidence)는 원문(source)에서 인용한다. 원문에 없는 내용은 카드로 만들지 않는다.
- 다른 주제의 항목은 다른 호출이 만든다. links는 이 호출의 카드끼리만.
```
