# 공통 기준

학습 설계와 출제 모두에 들어간다.

- [공통-1] 원문에 없는 사실을 학습 내용으로 만들지 않는다. 계산 문제에서 수치를 새로 정하는 것은 되지만 반드시 검산한다.
- [공통-2] 원문의 용어·기호·식·코드 표기를 바꾸지 않는다. 다른 표기가 필요하면 원문 표기 뒤에 덧붙인다(예: 원문이 `T⁻¹`이면 `T⁻¹`을 먼저, `T(-t)`는 추가로).
- [공통-3] 인용 칸에는 원문을 글자 그대로 옮긴다. 요약한 문장을 원문 인용처럼 쓰지 않는다.
- [공통-4] 무엇을 보고 무엇을 떠올릴지는 학습자가 실제로 그 지식을 쓰는 상황을 기준으로 정한다. 예: 영어 말하기 표현이면 "영어 → 뜻"보다 "하고 싶은 말 → 영어 표현".
