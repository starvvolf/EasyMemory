# 형식별 기준

출제 단계에 항상 들어간다(모델이 형식을 고르므로 세 형식 모두).

## choice (보기 고르기)
- [객관식-1] 목표를 판단 하나로 바꾸고, 판단에 필요한 조건을 모두 질문에 담는다. 보기는 정확히 4개, 정답은 하나.
- [객관식-2] 보기를 쓰기 전에 원문으로 정답을 확정한다.
- [객관식-3] 오답은 원문으로 반박할 수 있는, 학습자가 실제로 할 만한 혼동에서 만든다: 부호·순서 반전, 조건 누락, 비슷한 개념 혼동, 기준 바꾸기. 오답을 그럴듯하게 만들려고 원문 밖 사실을 넣지 않는다.
- [객관식-4] 네 보기의 문법·범위·구체성·길이를 맞춘다. 정답에만 조건이나 단서를 붙이지 않는다.
- [객관식-5] "항상·반드시·절대·모두·전혀" 같은 절대 표현은 실제 학습 대상이 절대 조건일 때만 쓴다. 오답에만 쓰면 요령으로 답을 고를 수 있다.

## short (짧은 값 입력)
- [단답-1] 답이 짧은 값 하나(수, 좌표, 기호, 용어, 20자 안팎)이고 표기 변형을 다 적을 수 있을 때만 쓴다.
- [단답-2] 여러 요소를 한 칸에 쓰게 하지 않는다(예: 식 세 개, 목록). 요소마다 따로 묻거나 self-check로 바꾼다.
- [단답-3] 인정 답안(accepted)에는 원문 표기를 먼저, 그다음 한국어 표기, 흔한 줄임말(예: BFS, DFS), 같은 뜻의 다른 표기를 넣는다.
- [단답-4] 학습 대상이 아닌 짧은 낱말만 지우지 않는다. 예: 영어 말하기 패턴에서 전치사 `about`만 빈칸으로 두면 패턴을 떠올리는지 재지 못한다.

## self-check (떠올린 뒤 비교)
- [자기확인-1] 식·정의·절차·이유처럼 여러 요소를 떠올려야 하거나 말로 설명해야 할 때 쓴다.
- [자기확인-2] 모범 답은 학습자가 자기 답과 비교하기 쉽게 핵심 요소를 짧게 나열한다.
- [자기확인-3] 순서나 구조를 떠올리는 목표면 "순서대로 쓰기"로 묻는다. 구조를 `BFC EAD` 같은 문자 암호로 바꾸지 않는다(부호화 규칙까지 재게 된다).
