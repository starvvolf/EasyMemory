## 1. 된 것 (`docs/DECISIONS.md` 10/26~28 "로컬 채점" 항목들)

- 4개 언어 실행·채점, 힌트 3단계, 코드/에러 설명, 반례 찾기, 빈칸 문제, 이번 풀이 기록(맞았을 때·나갈 때·2시간 뒤 지식에 합침).
- 숨은 테스트: AI가 생성기·검사기를 쓰고, 별도 Node 프로세스 하나(`src/lib/code/testgen/harness.mjs`)에서 최소·최대·극단값까지 만든다. 원문 예제가 없으면 단순 풀이와 작은 입력 300개 대조. 틀린 풀이는 점수(관문 아님), 못 잡으면 반례를 테스트에 추가.
- 독립 풀이(안전장치 ⑤): 다른 호출에서 문제 글만 보고 쓴 풀이가 숨은 테스트 전부와 같아야 저장. 문제 만들기 모델 `gpt-5.6-terra`(사용자). 독립 풀이 모델은 비교 중(기본 임시 terra, 실험 경로 `POST /api/code/problem/:id/solve-check`).
- 채점: Windows 작업 개체(`src/lib/code/jobrun/JobRun.cs`)로 CPU 시간·최대 메모리, 시간 초과·메모리 초과, 경계 구간 표시. PC 보정(`calibrate.ts`): 언어별 빈 프로그램 사용량 빼기, 벤치마크 속도 배율.
- 출력 비교 `compare.mjs`(처음 다른 자리 표시, 실수 오차 모드는 아직 AI 문제에 안 엶).
- 문제 파일과 숨은 테스트 파일 분리(목록은 테스트 안 읽음, 문제에 들어갈 때 미리 읽음).
- 바킹독 문제집 메뉴는 뺌(기능은 남김, 사용자).

## 2. 남은 일

1. **주소로 긁어오기** (사용자가 고른 방식: 앱이 페이지를 받고 AI는 그 글만 보고 세팅, 안 되면 바꿈)
   - 블로그·문제 페이지 주소 → 앱이 받아 본문만 추림 → 지금의 문제 만들기 흐름(생성기·독립 풀이)에 넣음.
   - 백준 번호만 넣으면 인터넷 아카이브 원문(`src/lib/code/archive.ts`)을 화면에 다시 연결.
   - 다른 세션이 데스크톱에 남긴 미커밋 `src/lib/code/import/`(page.ts, pipeline.ts 등)는 옛 흐름 기준이다. 쓸 부분만 가져오고 나머지는 지우는 쪽을 제안함(사용자 답 전).
2. 문제 만들기 단계별 시간·실패 이유 기록(다익스트라가 2번 시도에 약 10분, 구간 합은 저장 안 됨, 원인 기록이 없었음).
3. 독립 풀이 모델 정하기(새로 만든 어려운 문제들로 비교).
4. 학습자 코드에 넘기는 환경 변수 비우기(제안, 사용자 답 전).
5. 실제 사용 점검: 코드 탭을 처음부터 끝까지 써 보고 거슬리는 점 정리.
