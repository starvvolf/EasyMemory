# 두 컴퓨터(데스크톱·노트북)에서 번갈아 쓰기 (2026-10-14)

## 무엇이 어디에 있나
| 무엇 | 위치 | 두 컴퓨터가 같이 쓰려면 |
|---|---|---|
| 만든 문제, 그림 읽기, 등록 PDF, 모르는 것 노트 | 데이터 폴더(`.study-forge-data`) | 데이터 폴더를 **동기화 폴더**에 둔다 |
| 풀이 기록·복습 일정·신고·읽던 쪽 | 브라우저 + **데이터 폴더의 `study-records`**(2026-10-14부터) | 데이터 폴더를 따라간다. 열 때 더 최근 기록을 가져온다 |
| ChatGPT 로그인 | 각 컴퓨터의 프로젝트 안 `.study-forge-data\chatgpt-auth` | **공유하지 않는다**. 컴퓨터마다 따로 로그인 |
| 코드 | GitHub `claude/local-state-20260928` | 각자 pull |

## 처음 한 번
1. 두 컴퓨터 모두에서 같은 클라우드 동기화 폴더를 쓴다(OneDrive, Google Drive 등). 예: `...\OneDrive\RecallerData`.
2. 지금 가장 최신 데이터(노트북 `EasyMemory\.study-forge-data`)에서 `chatgpt-auth`를 **뺀** 나머지 폴더를 동기화 폴더로 옮긴다.
3. 두 컴퓨터의 `.env.local`에 한 줄 추가:
   ```
   STUDY_FORGE_DATA_DIR=C:\Users\jkh01\OneDrive\RecallerData
   ```
   (경로는 각 컴퓨터에서 실제 동기화 폴더 경로. ChatGPT 로그인은 따로 설정하지 않으면 프로젝트 안에 그대로 남는다.)
4. 앱을 켜고 `/study`에서 ChatGPT 연결을 한 번 한다.

## 매번 지킬 것
- **두 컴퓨터에서 동시에 앱을 켜지 않는다.** 같은 파일을 양쪽에서 쓰면 동기화가 충돌한다.
- 바꾸기 전에 쓰던 컴퓨터의 동기화가 끝났는지(클라우드 아이콘) 확인하고 넘어간다.
- 문제 만들기가 진행 중이면 그 컴퓨터에서 끝까지 둔다. 중간에 다른 컴퓨터에서 이어 가려면 그쪽에서 "다시 시작"을 누른다.
