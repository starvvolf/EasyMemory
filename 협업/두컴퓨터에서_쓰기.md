# 두 컴퓨터(데스크톱·노트북)에서 번갈아 쓰기 (2026-10-14)

## 무엇이 어디로 다니나
| 무엇 | 다니는 길 |
|---|---|
| 코드 | 공개 저장소 EasyMemory (`claude/local-state-20260928`) |
| 만든 문제·그림 읽기·등록 PDF·모르는 것 노트·풀이 기록 | **비공개 저장소 `starvvolf/RecallerData`** (`scripts/recaller-sync.mjs`) |
| ChatGPT 로그인, `.env.local` | 컴퓨터마다 따로(올리지 않음) |
| GPT 보고서 | 코드 저장소에 commit·push (`GPT_작업규칙.md`) |

## 매번
- **시작**: Recaller 앱(`Recaller 앱.cmd`, 바탕화면 바로가기) → 코드 받기 → (바뀌었으면) 패키지 설치 → 데이터 받기 → 앱 서버·실습 코스 서버 → 창
- **끝**: 창의 X → 확인 → 코스 서버·앱 서버 끄기 → 데이터 올리기
- 다른 컴퓨터로 옮길 때는 **쓰던 쪽에서 앱을 끈 뒤** 다른 쪽에서 켠다. 깜빡해도 다음에 끌 때 합쳐지며, 풀이 기록은 자료마다 더 최근 것이 남는다.
- 두 컴퓨터에서 동시에 앱을 켜지 않는다.

## 처음 한 번(컴퓨터마다)
1. 코드를 OneDrive 밖에 둔다(예: `C:\Users\jkh01\Documents\Codex\projects\EasyMemory`).
2. Recaller 앱을 처음 켜면 `RecallerData`를 프로젝트 옆(`..\RecallerData`)에 받고 `.env.local`에 `STUDY_FORGE_DATA_DIR`를 넣는다. 비공개 저장소라 Windows의 GitHub 로그인이 필요하다(GitHub Desktop이나 git 자격 증명).
3. `/study`에서 ChatGPT 연결을 한 번 한다.

프로젝트 안의 예전 `.study-forge-data`에는 이제 ChatGPT 로그인만 남아 쓰인다(나머지는 RecallerData로 옮겨졌다).
