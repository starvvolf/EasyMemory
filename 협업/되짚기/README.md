# 되짚기: Claude가 만든 비교용 시제품

Recaller의 핵심 아이디어를 Claude가 처음부터 가볍게 다시 만든 시제품이다. 사용자는 이 시제품의 **흐름과 단순한 UI**를 좋게 평가했고, 앞으로 Recaller 화면과 흐름을 다듬을 때 기준안으로 쓰려 한다. Recaller를 대체하려는 게 아니라, 같은 코어를 가볍게 만들었을 때 무엇이 좋아지고 무엇이 빠지는지 보여 주는 비교용이다.

## 파일
| 파일 | 설명 |
|---|---|
| `되짚기_최신_v9.html` | **최신판(메인).** claude.ai 아티팩트로 게시된 버전 9의 원본 코드. 단일 HTML |
| `되짚기.html` | 초기 단독 실행판. 읽기 화면과 질문 창이 없고, 예시 자료로 연습·기록만 된다. 브라우저에서 바로 열린다 |
| `테스트요청_GPT.md` | 초기판 기준 사용 평가 요청서 |
| `화면/` | 최신판 확인용 스크린샷 (가짜 PDF와 가짜 응답으로 찍은 것) |

- 게시 링크: https://claude.ai/artifact/6SoZ7pnUgAAWehvdNSp8TM (사용자 계정 전용)
- 사용자가 직접 만든 덱 "2D/3D 기하 변환"(14문제)이 그 아티팩트의 개인 저장소에 있다.

## 최신판은 어디서 돌아가나
최신판은 claude.ai 아티팩트 런타임(`window.claude`)에 기대어 동작한다. 로컬 브라우저에서 파일로 열면 PDF 읽기와 예시 연습은 되지만, 자료 만들기·질문 창·저장은 동작하지 않는다.

| 런타임 기능 | 쓰는 곳 |
|---|---|
| `sample` | 페이지 안에서 Claude 호출: 목표 설계, 문제 작성, 수정, 질문 창 답변 |
| `db` | 사용자별 개인 저장소 `data/users/<id>/`에 덱과 풀이 기록 저장 |
| `user` | 보는 사람의 id(개인 저장소 경로) |
| `assets` | 올린 원본 PDF 보관 |

외부 라이브러리: pdf.js 3.11.174(cdnjs, 필요할 때만 불러옴), KaTeX 0.16.9(MathML 출력, 실패 시 간단한 기호 치환으로 대체).

Recaller에 옮길 때는 `sample` 자리를 서버 API 호출로, `db`를 Firebase나 기존 저장소로, `assets`를 파일 저장소로 바꾸면 된다. 화면과 흐름 로직은 그대로 참고할 수 있다.

## 흐름
**홈 → 자료 만들기 → 읽기 → 연습 → 기록**

1. **자료 만들기**
   - PDF를 올리거나 텍스트를 붙여 넣는다. pdf.js로 쪽별 텍스트를 뽑는다.
   - Claude를 한 번 호출해 학습목표를 설계한다(`runDesign`, 입력 상한 `DESIGN_BUDGET` 46,000자).
   - 목표 5개씩 묶어 문제를 쓴다(`runAuthoring`).
   - 자동 검사(`validateItem`)를 거친다. 정답 노출, 보기 길이 차이, 단정 표현(`ABSOLUTE`), 형식 오류를 본다. 걸리면 한 번 수정 요청한다.
2. **읽기**
   - 원문을 화면 위쪽에 고정하고, "이 쪽에서 익힐 것"은 원문 아래에 둔다. 아래 내용 길이가 바뀌어도 원문 시작 위치가 흔들리지 않는다.
   - PDF는 화면 폭과 기기 배율(devicePixelRatio)에 맞춰 다시 그린다. 배율이 바뀌면 `watchDpr`가 다시 그린다. 그래서 선명하다.
   - 16:9 슬라이드는 폭 가득 보여 주고, "크게 보기"를 따로 둔다.
   - 문제의 근거 문장은 원문 위에 형광펜으로 표시한다(`highlightRects`, `markTextMulti`).
   - "이 쪽 문제 풀기"로 읽은 직후 그 쪽 문제를 바로 풀 수 있다.
3. **질문 창**(쉬운 풀이 탭을 없애고 이것으로 대체함)
   - 떠 있는 반투명 창이다. 끌어서 옮기고, 모든 가장자리로 크기를 바꾸고, 접기와 크게 보기를 할 수 있다.
   - 추천 질문 칩이 있다. 지금 보는 쪽의 원문을 근거로 답한다.
4. **연습**
   - 네 가지 형식: 고르기, 값 쓰기, 순서 맞추기, 떠올리고 확인(`FORMAT_LABEL`).
   - 풀기 전에는 학습목표와 근거를 숨기고, 답을 낸 뒤에만 보여 준다.
   - "모르겠어요", "정답 먼저 보기", "내 답도 맞아요"(자동 채점 뒤집기, 기록에 `override` 남김)가 있다.
   - 키보드로도 풀 수 있다: Enter, 숫자 1~4.
5. **기록과 복습**
   - 복습 간격은 10분 → 1일 → 3일 → 7일 → 16일 → 35일(`INTERVALS`)이다. 혼자 맞히면 한 칸 올라가고, 틀리면 처음으로 돌아간다.

## 기록 규칙 (정직성)
- 정답 공개, 결과 화면을 본 뒤의 재시도, 연습 중 원문을 열거나 질문한 쪽의 문제는 모두 **도움받은 풀이**로 기록한다. 간격이 늘지 않는다.
- 읽은 직후 푼 결과는 **읽은 직후**로 따로 기록하고, 복습은 다음 날부터 시작한다.
- 자기평가(떠올리고 확인)는 자동 채점과 다른 색으로 구분한다.
- "여러 날 혼자 맞힘"은 서로 다른 날짜에 혼자 맞힌 경우에만 센다.

## 사용자가 요청해서 반영한 것 (순서대로)
1. PDF를 보고, 원하면 쉬운 설명을 듣고, 문제까지 풀어 보는 읽기 흐름 추가
2. UI 다듬기(덜어내기 위주)
3. PDF 화질 개선(화면 폭·기기 배율에 맞춘 렌더링)
4. 원문을 위에 두고 익힐 것을 아래로 옮김
5. 16:9 원문 대응(폭 가득, 크게 보기)
6. 떠 있는 반투명 채팅창 추가, 크기 조절
7. 쉬운 풀이 탭을 없애고 채팅창으로만 설명

## 알려진 약점 (출제 품질은 사용자와 합의해 일단 보류)
- 목표 상한 18개와 "핵심만 미리 선택" 때문에 범위가 빠진다. 기하 32쪽 중 13쪽만 출제됐다. → 쪽 단위로 나눠 설계하고, 빠진 쪽을 표시해야 한다.
- 계산 문제가 없고 카드와 순서 문제로 치우친다.
- 순서 형식에는 정답 노출 검사가 빠져 있다.
- 단어 답이 값 쓰기 형식으로 나와서 "반시계" 같은 답이 오답 처리된다.

## 미검증
작업 환경에서 pdf.js와 cdnjs를 받을 수 없어서, 가짜 PDF 페이지 객체와 가짜 Claude 응답으로만 확인했다. 아래는 실제 환경에서 다시 봐야 한다.
- 실제 PDF 위 형광펜 위치
- 실제 KaTeX 조판
- 질문 창 실제 답변 품질

## Recaller로 옮긴 판 (`/study`, 2026-09-29)
되짚기의 화면·흐름·기록 규칙을 그대로 두고, 문제는 Recaller 생성 엔진의 출제 문서에서 받는다.

- 파일: `src/app/study/`(화면 `dejipgi-app.js`, 스타일 `dejipgi.css`, 연결 `DejipgiStudy.tsx`), 변환기 `src/lib/study/from-authoring.ts`
- 문제: `/api/personalization-lab`의 검증 통과 문서를 변환한다. 객관식 → 고르기, 빈칸 → 값 쓰기, 자기확인 서술형 → 떠올리고 확인. 내용은 고치지 않고, 정답 연결이 깨진 문항은 건너뛴 목록에 남긴다.
- 원본 PDF: `/api/mcp-runs/sources/<id>/pdf`. pdf.js는 설치된 `pdfjs-dist`(legacy 빌드), 수식은 설치된 KaTeX를 쓴다.
- 기록: 이 브라우저의 `localStorage`(`recaller:study:v1:<uid>`)에 문서 해시별로 남는다. 문서가 바뀌면 새 기록으로 시작하고 옛 기록은 지우지 않는다.
- "자료 만들기" 탭은 원본의 3단계 화면(자료 올리기 → 학습목표 고르기 → 문제 생성·검사)을 그대로 두었다(2026-09-29).
  - PDF 고르기·끌어 놓기, 텍스트 붙여 넣기, 쪽 범위·목적 입력은 브라우저에서 동작한다.
  - 학습목표 설계·문제 생성·저장은 원본처럼 페이지 안에서 Claude를 부르지 않는다. `env.builder`(Recaller 생성 엔진)에 맡기는데, 아직 비어 있어서 버튼이 꺼져 있다.
  - 기존 엔진 방식(자료 등록 → 요청 대기 목록 → 담당 AI가 MCP로 실행)으로 잇는 일은 `협업/작업지시_05_되짚기_엔진연결.md`에 남겼다. 연결에 쓸 부품(PDF 등록·요청 저장 API 어댑터, `src/lib/study/request-form.ts`)은 준비돼 있다.
- 질문 창은 화면과 동작만 살려 두었고, 답변은 유료 호출이라 연결하지 않았다.
- 원본 v9에서 고친 것: 정의되지 않았던 `docAspect`를 추가해 PDF가 실제로 그려진다.
