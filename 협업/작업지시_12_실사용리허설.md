## 1. 리허설 A — 기업윤리 1주차 (실제 호출 묶음 확인 1번, 상한 130번)
`/study` → 자료 만들기에서 `바탕 화면/강의자료_2026-10-12/반도체 산업과 기업윤리/반도체 산업과 기업윤리_01주차.pdf`.
- 목적 **핵심 암기**, 범위 전체, 메모 없음, **그림·수식도 읽기 켬**(화면에 나온 예상 쪽 수·시간을 적는다).
- "읽기 시작" → 진행 표시가 바뀌는 대로 기록: 그림 쪽 읽기 → 목차 → 자료 파악·학습 설계 → 목표 확인.
- **목표 확인**: 목차 수, 목표 수(보조 수), 기본 체크 수. 목표 3개를 무작위로 골라 원문과 대조(떠올릴 것이 원문과 맞는지). 그대로 확정.
- **목차가 끝나는 대로 공부**: 첫 목차 문제가 붙는 순간("첫 문제들이 준비됐어요")을 확인하고, 그때 연습을 시작할 수 있는지 본다.
- **연습 10문제**: 형식 분포, 플래시카드의 **"잘 모름 / 알고 있음"** 두 버튼, 틀린 뒤 "복습 필요로 표시" 문구(같은 연습에서 다시 나오지 않아야 함).
- **신고 → 다시 만들기**: 문제 하나를 "이 문제 이상해요"로 신고하고 다시 만들기. "다시 만든 문제" 자료가 따로 붙는지, 새 문제가 이전과 다른지.
- 호출 상한(60)에 닿아 멈추면 "다시 시작"으로 이어지는지 확인한다(멈춘 횟수 기록).
- 실험실 `/lab/gen`에서 이 실행을 열어 호출 수·시간·토큰을 적는다.
