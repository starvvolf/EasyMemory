# 지금 유효한 결정 (요약판)

`docs/DECISIONS.md`(덧붙이기만, 1,400줄 넘음)에서 **지금도 그대로인 것만** 한 장으로 추린 것. 자세한 이유·숫자는 괄호 속 날짜의 원문 항목에서 본다. 새 결정은 원문에 덧붙이고, 이 요약판에서도 해당 줄을 고치거나 더한다(바뀐 옛 줄은 지운다). 마지막 정리: 2026-11-11 A 세션.

## 원칙
- AI는 만들고 돕기만, 판정·기록·복습 날짜는 코드 (CLAUDE.md).
- 항상 사람이 바로 이해하기 쉽게: 화면 글·기억·AI 글은 용어보다 상황·예시로 (11/10).
- 특정 문제·자료에만 맞춘 하드코딩 금지, 지시문에 줄 수·길이 제한 걸지 않기 (사용자, 11/10~11).
- 웹 글을 주소로 가져오는 기능은 만들지 않는다.
- 기본 모델 terra low. 다른 모델은 실측으로 더 낫다고 확인한 곳에만, 이유를 남긴다.

## 앱 구조·화면
- 공부 화면은 전부 React: `StudyApp.tsx`가 그리고, `dejipgi-app.js`는 상태·채점·기록·AI 부르기만 (11/11).

- 데이터: 노트북 데이터로 새로 시작, 가볍게 동기화, 컴퓨터마다 동기화 끌 수 있음 (11/6, 11/9).

## PDF 자료 (엔진·자료 지도)
- 기억 단위로: 줄기 계획 → 기억 채우기(기억 하나 = 카드 한 장) (11/10).
- 새 PDF 자료는 문제를 자동으로 만들지 않는다. 문제는 자료 지도에서 원할 때 (11/8).
- 문제 만들기: 시험지 설계 → 문제 쓰기 → 상황 확인·직접 풀어 보기, 학습 목표 + 목표 밖 메인 기억 (11/10).
- 기출분석 빼기 (11/8). 흐름 카드 만들기 끄기 (11/9). 목차에서 강의 운영 안내 쪽 빼기 (11/8).
- 자료 지도 탭: 줄기 · 구조 · 기억 · 강의 (11/7~11/11). 구조는 큰 상자(카드 7장 이상)만 다시 정리 (11/8). 카드에 그림 붙이기 (11/8).
- 기억 카드 세 겹(앞면: 질문·한 줄·직관 / 핵심 / 자세히 접기), 왜·한계는 숨기고 문제에만, 모양 칸은 강제하지 않음, 풀이는 핵심에 (11/11).
- 강의 탭: 영역 한 흐름, 걸음마다 같은 틀 없음, 굵은 말 = 카드, 자료 넣을 때 강의 O/X (11/11).
- 기억 탭에서 바로 플래시카드, 결과는 기억 저장소로 (11/11).

## 기억 저장소·복습
- 주인 두 겹 (11/11): 갈래마다 다른 부분은 각 갈래(자료 A·알고리즘 B·실습 D), 같이 쓰는 바닥은 A. 영역은 A 총괄·엔진, B PS, C 쉬는 중, D 실습.
- 기억 복습에서 코드가 만드는 문제 빼기, 자료·알고리즘·실습 따로 (11/9).
- 지식 출처 3분류와 지식 창 체크 거르기 (11/6). 주제 정리 모델 terra 유지 (11/5).
- 학습자 모델은 갈래마다 따로 (11/10).

## 알고리즘 (PS 튜터, 구현 B 세션)
- 알고리즘 탭 기본은 PS 튜터: 접근을 체화시키는 학습 엔진 (11/8).
- 고리 하나 (11/11): 혼자 → 막힌 자리에서 작은 도움부터(도움 네 칸: 눈여겨볼 곳·방법 이름·계획·뼈대 코드) → 도움 받은 문제는 하루 뒤 혼자 다시 → 풀이 일지(문제마다 한 장). 처음 짜 보는 패턴은 뼈대에서 채우기부터. AI는 실력을 판정하지 않는다.
- 기억이 되는 것은 몰랐다가 배운 것만 (11/8). 알고리즘 기억은 무엇이 부족했는지 되새기기 좋은 모양 (11/10).
- 문제 재료는 필요할 때 조금씩, 유저가 넣은 백준 문제도 재료 (11/10). 숨은 테스트는 강의 풀이 없이, 세게, 가볍게 (11/9).
- 난이도는 AI에게 묻고 출처를 밝힌다 (11/8). 방법 고르기 보기는 개념 이름 + 이어진 개념 (11/10).
- 학습자 모델 v1, 처음 진단은 설문 44개(모름/알아요) (11/10~11/11).
- 학습자 기억 세 층 (11/11): ① 이번 풀이(채팅 답·제출·도움 칸, 끝나면 버림) → ② 문제 한 장(맞힘·그만둠·하다 나감. 칸은 코드 태그, AI는 끝날 때 1번 짧은 칸 넷: 막힌 곳 다섯 중 하나·그때 내 생각·이렇게 하면 돼요·새로 안 것) → ③ 태그 한 줄씩 압축 기억(코드 계산, 채팅·찾기가 같은 함수로 골라 씀). 나갈 때·앱 끌 때도 저장, 저장 중 미니 탭.
- 튜터 채팅: 해요체·한 걸음만·연 힌트까지, 정답 방향은 안 줌, 마지막 채점 결과는 줌 (11/11). 문제 찾아오기: AI 웹 검색으로 후보 3개, 내 기록으로 수준 맞춤 (11/11).

## 실습 (구현 D)
- 틀린 곳은 소크라테스식으로 짚기, 학습자가 물을 때는 담백하게, 생각으로 알 수 없는 이름은 알려 주기 (11/8, 11/11).
- 부족함 원장(찾기 → 채우기 → 기록 → 다시 확인), 모르는 것 후벼 파기·선행·실습 기억 카드 (11/8, 11/10).
- 도움 다이얼 하나(스스로 · 같이 · 빨리 만들기), 기록은 정직하게. 선행은 큰 덩어리를 스스로 표시 · 미리 묻지 않기 · 걸린 만큼만 받아 쓰고 쌓기 (11/11, 11/10 "위에서부터 묻기"를 바꿈). 먼저 알 것 지도 · 기억 "진행 방식" · 정해진 코스 기능은 뺌, 실습은 자유 대화 하나 (11/11). 실습 서버는 이 컴퓨터, 작업 폴더는 Recaller 밖 (11/8~9).
- 앱 안 편집기(웹 VS Code) 도입, 내 VS Code 방식도 남김 (11/11).
- 너무 쉬워요 = 다음으로, 너무 어려워요 = 짧은 설문 → 보충 로드맵 (11/7).
