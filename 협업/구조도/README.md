# Recaller 구조도 (2026-10-30, A · 2026-11-12 자료·기억·문제 칸 A 최신화)

브라우저로 여는 HTML 두 개. 지금 코드(claude/recaller2) 기준.

- `구조도.html`: 전체 흐름(자료·알고리즘·실습 → AI·사용자 → 기억 → 문제 → 사용자 → 복습). 칸을 누르면 그 부분의 세부 흐름이 작은 도식으로 나온다.
- `실습_구조도.html` (D, 11/12): 실습 한 판의 흐름, AI 호출 네 가지(언제 · 입출력 · 모델 · 시간 · 토큰), 코드가 맡는 것. 글로 된 것은 `docs/실습_파이프라인.md`.
- `앱구조.html` (A, 11/12): 앱이 어떻게 생겼나 한 장. 화면(탭 네 개) · 앱 서버(갈래 엔진 셋 + 기억 저장소) · 바깥(AI · 실습 서버 · 데이터 폴더 · 앱 창). 발표용 그림.
- `세부파이프라인.html`: PDF / 웹 글 / 코드 문제 / 지식 저장 뒤 처리 / 기록과 복습의 실제 단계, 모델, 잰 시간.

같은 내용의 claude.ai 페이지(비공개, 같은 계정이면 읽기 가능)도 있다. 고칠 때는 두 곳을 같이 고친다(A 스레드에 요청).

- 11/12 A: 자료 칸을 지금 엔진(줄기 계획 → 학습 목표 ‖ 질문·답 카드 채우기, 문제는 누를 때만)과 카드 한 장 · 병목 그림으로 바꿨다. 지식 → 기억, 지식 창 → 기억 도서관으로 이름을 맞췄다. 알고리즘(B)·실습(D) 칸 내용은 각 주인이 최신화한다. `세부파이프라인.html`은 아직 예전 기준.
