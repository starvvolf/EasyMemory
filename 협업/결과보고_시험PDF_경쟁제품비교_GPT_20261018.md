# 시험 PDF 경쟁제품 비교 · 2026-10-18

## 결론
- 그래픽스03·반도체07에서 유니브·NotebookLM의 맞춤형/기본형 8묶음, 86문항을 실제 생성하고 모두 열어 풀이 흐름을 확인했다. 원문 대조는 대표 문항 대상으로 했다.
- 세부 지시는 범위와 문제 성격을 개선했지만, 정답 노출·조건 누락까지 막지는 못했다.
- RemNote는 그래픽스 PDF 업로드가 파일 크기 Pro 제한으로 막혔다. 결제·분할 우회는 하지 않았다.
- 반도체에서는 맞춤형이 일관되게 우월하지 않았다. NotebookLM은 범위 편중과 서술 채점 실패가 남았다. Recaller의 동일 자료 새 결과는 이번에 생성하지 않아 우열을 단정하지 않는다.

## Claude가 판단할 것
1. Recaller의 차별점은 문제 생성 자체보다 **시험 범위의 누락을 보여주고 채우는 것**이어야 한다. 경쟁제품도 PDF 하나로 그럴듯한 문제를 바로 만든다.
2. 정답을 맞혔다는 완료 화면은 자료 전체를 공부했다는 증거가 아니다. 목차별 출제/미출제 범위를 표시할 가치가 있다.
3. 문제 조건·정답 노출을 별도로 검토해야 한다. 지시문에 금지 사항을 넣는 것만으로 해결되지 않았다.
4. 기본형/맞춤형 차이는 한 번씩의 관찰이다. 생성 변동과 설정 차이가 섞였으므로 프롬프트 효과로만 해석하지 않는다.
5. 채점 서비스 오류를 학습자의 오답으로 기록하면 안 된다. 평가 실패/미채점/오답을 제품에서 구분해야 한다.

- 사용자가 전체 PDF의 세 서비스 전송과 생성에 명시 승인했다. 그래픽스 먼저 진행했다.
- 원문·문항·계정 정보·캡처는 비공개 연구 데이터 폴더에만 보관한다. 이 문서는 집계·관찰만 기록한다.

- 두 제품에서 정답률이 높았다는 것은 AI 조사자가 답한 결과일 뿐, 사람의 학습 효과나 제품의 품질 점수가 아니다.
- 개별 서비스 내부 모델·토큰·호출 수는 확인 불가. 자동 조작 대기 시간이 섞여 생성 시간의 정밀 비교는 하지 않았다.

### 그래픽스 결과
**유니브**
- 두 조건 모두 객관식 3, OX 3, 주관식 2, 빈칸 2였다.
- 맞춤형에는 실제 외적, 좌표 평행이동, 동차좌표 나눗셈이 있었다. 기본형은 개념·성질 판단에 치우쳤다.

**NotebookLM**

## 후속 확인: 압축 및 퀴즈 외 출력물 보관

앞의 RemNote 차단은 원본 파일 기준이다. 후속 압축으로 그래픽스 업로드에 성공했으므로 최종적으로 '이 자료를 사용할 수 없다'고 해석하지 않는다.

- 비교 묶음은 연구자가 정한 `자료 × 서비스 × 설정`이다. 서비스 규격이 아니다. 유니브는 10문항으로 설정했고 NotebookLM은 표준 수량을 선택해 10~12문항이 나왔다. 이전 8묶음·86문항 집계는 추가 카드/요약과 구분한다.
- RemNote 공식 무료 정책: 파일당 8MB, PDF 총 3개. 출처: https://www.remnote.com/pricing 및 https://help.remnote.com/en/articles/6690972-uploading-pdfs-to-remnote (2026-10-18 확인).
- 그래픽스는 8,703,404→7,169,539bytes, 반도체는 10,361,256→7,793,547bytes로 압축했다. 원본 보존, 쪽 수/추출 글자 동일. 큰 그림에는 손실 압축이 적용됐으며 대표 행렬/표 가독성을 확인했다. 반도체 압축본 업로드는 아직 미실행.
- RemNote 그래픽스는 두 학습 구간 구성 후 첫 구간 요약과 대표 카드 생성까지 확인·저장했다. 전체 퀴즈 및 지시형/기본형 비교는 아직 하지 않았다.
- 유니브 그래픽스의 요약·개념 목록·암기 목록·펼친 마인드맵·카드 순회 기록을 추가 보관했다. 카드 10장 생성은 확인했으나 전체 앞뒤 수집 여부는 미확인이다. 메모는 수동 작성 기능으로 자동 출력물에 포함하지 않았다. AI 튜터 추가 실험은 미실행.
- NotebookLM 그래픽스의 초기 요약·대화형 보고서·데이터표·펼친 마인드맵·인포그래픽·50장 카드 순회 기록을 보관했다. 카드 첫 장 앞면은 저장 파일에 빠져 서비스에서 확인해야 한다. 슬라이드 14장 목록과 대표 화면, 오디오 20:56 생성도 확인했다. 전체 슬라이드/오디오 내용 검수 및 원본 다운로드는 미완료다. 인포그래픽 다운로드 시도는 시간 초과였다. 동영상은 마지막 확인 시 마무리 중이었다.
- NotebookLM 계정은 PLUS이다. 사용량 한도 근접 경고가 나타나 추가 생성은 중단했다. 무료 계정 제한 실측으로 일반화하지 않는다. 구매·업그레이드는 하지 않았다.
- 반도체는 이전 퀴즈 비교 자료가 보관돼 있지만, 이번 퀴즈 외 모든 형식 확장 수집은 아직 하지 않았다. 그래픽스 우선 요청을 따랐다.

실제 결과를 다시 열 수 있는 서비스 링크, 증거 파일 링크와 완전/부분/미검증 구분은 비공개 `competitor-pdf-20261018/결과물_보관목록.md`에 기록했다. 브라우저 텍스트 증거는 수식·접힌 내용의 완전한 내보내기가 아니므로 화면과 함께 확인한다. 원문·문항·계정이 포함된 캡처는 공개 저장소에 추가하지 않았다.

## RemNote 후속 비교 완료 범위

- 그래픽스 첫 학습 구간의 카드 6장 전체 문답 확인·저장, 기본 객관식 5문항과 설정형 객관식 5문항 끝까지 확인했다. 추가 기본 재생성 5문항도 따로 기록했다. 이는 전체 PDF·반도체까지 완전 검수했다는 의미가 아니다.
- 이 퀴즈 화면에는 자유 지시 입력칸이 없고 형식·난이도·문항 수·주제 범위 선택이 있다. 설정형은 Application(Harder), Full(5 questions), Cover All Topics를 선택했다. 전체 주제는 선택 구간 내 범위다. 다른 서비스의 자연어 세부 지시와 동일 조건으로 간주하지 않는다.
- 기본형의 첫 문항에서 원문 식과 반대인 연산 순서를 정답으로 지정했고, 추가 AI 해설도 이를 옹호했다. 원문 이미지와 문제·해설 증거는 비공개 보관함에 저장했다. 이 오류 때문에 생성 성공을 품질 통과로 보고하지 않는다.
- 설정형은 이유·용도·간단한 조건 추론으로 바뀌었지만 수치 대입 계산은 없었다. 일부 조건 누락 및 변수 표기 문제도 검토 대상으로 남는다. 단순 난이도 선택만으로 시험형 적용 문제가 보장되지는 않았다.
- 카드 화면의 수식 문자는 보이지만 접근성 텍스트에서는 빠지는 경우를 확인했다. 텍스트만으로 화면 렌더링 실패라고 판정하지 않았다.
- 정답 공개 방식으로 순회했으므로 표시된 0/5는 실제 학습자 성적이나 생성 품질 지표가 아니다. Recaller 사용자 기록과 3000 서버는 건드리지 않았다.
- RemNote 월 AI 크레딧 80% 경고로 이후 신규 생성은 중단했다. 결제·업그레이드 없음. 두 번째 구간과 반도체의 RemNote 비교는 남았다.
- 실제 결과, 설정과 실행 링크: 비공개 보관 목록의 `후속 완료: RemNote 그래픽스 첫 구간 비교`. 공개 보고서에는 문항 원문·화면을 넣지 않았다.

## NotebookLM 후속 생성 완료

- 사용자 요청에 따라 요약 → 질의응답 → 퀴즈 → 카드 → 마인드맵 → 보고서 → 데이터표 → 인포그래픽 순서로 누락 결과만 보충했다. 기존 결과는 다시 생성하지 않았다.
- 그래픽스는 질의응답만 추가했다. 반도체는 기존 요약·퀴즈를 유지하고 질의응답, 카드 55장, 마인드맵, 문서형 학습 가이드, 데이터표, 인포그래픽을 추가했다.
- 카드의 수량은 기본 설정으로 서비스가 결정했다. 중간 난이도와 주제 균형, 원문 충실성을 요청했다. 표·그림은 주요 관계와 수치 조건 보존을 요청했다. 따라서 무지시 기본값 결과로 분류하지 않는다.
- 반도체 카드 55장 앞뒤, 펼친 마인드맵, 보고서·표·인포그래픽과 완료 목록을 비공개 연구 폴더에 저장했다. 생성 완료를 전체 내용 정확성 검수 완료로 간주하지 않는다.
- 슬라이드·오디오·영상은 이번 작업에서 생성하지 않았다. 사용량 근접 경고는 있었으나 요청 결과는 모두 완성됐으며 추가 생성은 하지 않았다.
