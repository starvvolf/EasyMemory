# 시작하기 (2026-10-11 기준)

로컬이든 클라우드든, 이 프로젝트를 처음 여는 사람·AI는 **이 문서부터** 읽는다. 자세한 건 링크된 문서로 간다.

## 1. 한 줄 요약
Recaller는 PDF를 올리면 AI가 "무엇을 떠올려야 하는지" 골라 문제로 만들고, 읽기·연습·복습을 돕는 앱이다. 사용자 화면은 **되짚기(`/study`)** 하나다.

## 2. 켜는 법 (Windows)
- `Study Forge 로컬 열기.cmd` 실행. 로컬 실험 모드, 자동 생성, ChatGPT 연결이 켜진다.
- 화면: `/study`(되짚기), `/lab`(생성 실험실)
- 처음이면 되짚기 **자료 만들기** 탭에서 [ChatGPT 연결]
- 시험용 모델 바꾸기: `.env.local`에 `STUDY_FORGE_EXECUTOR_MODEL`, `STUDY_FORGE_EXECUTOR_EFFORT`(생성), `STUDY_FORGE_NOTE_MODEL`, `STUDY_FORGE_NOTE_EFFORT`(노트)
- **실제 AI 호출은 사용자 확인 뒤에만.** 개발·확인은 가짜 모델로.

## 3. 지금 상태
| 부분 | 상태 |
|---|---|
| 되짚기: 자료 만들기·읽기·연습·신고·다시 만들기 | 동작 |
| 모르는 것 노트(드래그로 물어보기, 질문 창 연결) | 1단계 동작 · 실제 호출 미검증 · 2단계(약점→연습) 남음 |
| 실험실 `/lab` | 동작 |
| 생성(6단계 + 출제), 가짜 모델 | 전 구간 통과 |
| 생성, **실제 모델** | 활동 설계까지 통과 · **끝까지 성공 0건** · 카드 근거 수정 후 재실측 대기 |
| **새 엔진(3단계, 목차 단위)** `/lab/gen` | 1차 구현 · 가짜 모델 테스트 통과 · **실제 모델 첫 실측 대기** (`협업/새엔진_1차_결과와_실측안내.md`) |

가장 큰 병목: **실제 모델로 끝까지 한 번 성공시키기.** 기록: `협업/검증기록_11.md` 맨 아래.

## 4. 데이터가 어디 있나 (git에 없음)
- `.study-forge-data/`
  - `mcp-sources/` 등록 PDF
  - `mcp-experiment-requests/` 생성 요청
  - `mcp/chatgpt-runs/` 단계별 실행 기록(모델 답 포함)
  - `study-executor/` 자동 실행기 상태·호출 기록
  - `study-notes/` 모르는 것 노트
  - `chatgpt-auth/` 로그인(암호화)
- `tools/problem-authoring-lab/runs/chatgpt-request-*/` 출제 결과
- 브라우저 localStorage: 되짚기 풀이 기록·신고·숨긴 목표
- 실패 원인을 볼 때는 `mcp/chatgpt-runs/<id>/run.json`의 `stageValidationFailures`와 `study-executor/<요청ID>/calls/`부터 본다.
