## Claude가 판단할 것

- 같은 PDF의 실험본들이 모두 공부 목록에 있으므로 ‘오늘 할 것’의 전체 시작에는 과거 실험본도 섞인다. 자료 이름에 실행 ID를 붙여 구별하도록 했지만 최종4개만 자동으로 골라 주는 기능은 아니다. 최종 전달 문서에서는 짧은 ID와 각 자료의 연습 버튼을 안내한다. 기존 자료·학습 기록은 삭제하거나 숨기지 않았다.

- 구형 생성 테스트는 현재 Codex 경계에 가짜 응답을 설치해 실제 호출을 막았다. 기존 HTTP 모양의 fixture 표현은 테스트 어댑터 안에서만 유지하며 실제 전송 규약이라고 주장하지 않는다. 학습 행동 불일치 거부·실제 임시 첨부 바이트·정리 동작을 확인했다. 옛 자동 후처리 기대는 이미 기록된 직접 JSON 보존 계약에 맞추고, 원문이나 제품 코드를 바꿔 통과시키지 않았다. 기존 환경 제약은 공통 모듈 경로와 임시 SDK를 지정한 재검사에서 해소했다.

- 한 출제 호출이 다른 호출보다 오래 대기하는 동안 프로세스는 살아 있었다. 현재 ChatGPT 응답 경로는 호출자가 넘긴 취소 신호만 사용하고 별도 전체 시간 제한은 두지 않는다. 이 사실만으로 실제 서버 정지나 실패를 단정하지 않으며, 이번 출제 가설과 섞어 통신 코드를 바꾸지 않았다.

- 문자열·수치 검사만으로는 상황 복제를 판정할 수 없어 별도 모델 검사를 붙였다. 이 판정 역시 독창성 보증이 아니며 표본 검토가 필요하다.
- 아래 게시 복제 통과 수치는 출제에 사용한 튜닝 기출 기준이다. 확인용 기출에 대한 복제 여부는 별도 사후 감사 도구로 확인하며, 그 내용·판정은 출제기에 다시 주지 않는다. 아직 수행하지 않은 확인용 검사를 포함해 100%라고 주장하지 않는다.
- 현재 형식은 기존 세 응답 방식을 유지한다. 실제 시험의 모든 응답 형식을 똑같이 지원한다고 주장하지 않는다.

- 원문 보충 후에도 이미 요약된 목표와 원문 표기가 충돌하면 오해가 남았다. 안내를 수정한 두 번째 사례에서도 2회 중 1회 혼동이 남아 추가 반복을 멈췄다. 원문 추가만으로 품질 문제가 해결됐다고 채택하지 않는다.
- 단서를 수정 가능하게 하는 작은 비교는 답 노출을 줄였지만 설명 목표를 이름 맞히기로 좁혔다. 두 번 반복돼 기각했다. 목표 ID·개수 유지뿐 아니라 실제 요구 행동이 유지되는지도 직접 확인해야 한다.
