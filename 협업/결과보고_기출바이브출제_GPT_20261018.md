# 기출 바이브 출제 · 중간 검증

## 결론

기출 선택 경로와 오프라인 검증을 완료했다. 기본 공부 자료 4종은 306문항, 첫 기출형 4종은 307문항 생성됐다. 첫 기출형은 식별 정확도는 낮아졌지만 품질 실패4건과 목표 누락1건으로 채택하지 않는다. 수식 검사 수정판을 별도 출제 중이며 강화·최종 동기화는 아직 완료가 아니다.

## Claude가 판단할 것

- 문자열·수치 검사만으로는 상황 복제를 판정할 수 없어 별도 모델 검사를 붙였다. 이 판정 역시 독창성 보증이 아니며 표본 검토가 필요하다.
- 현재 형식은 기존 세 응답 방식을 유지한다. 실제 시험의 모든 응답 형식을 똑같이 지원한다고 주장하지 않는다.
- 빌드에는 PDF worker 및 기존 동적 경로 추적 관련 경고가 남아 있다. 이번 변경과 기존 경고의 구분을 추가 확인할 예정이다.

## 자세한 내용

기출을 선택하지 않은 입력과 출제 프롬프트는 유지했다. 선택한 경우에만 등록 PDF 목록, 숫자형 경향 카드, 별도 베끼기 검사를 추가했다. 실행별 호출 기록에는 경향 분석과 검사 호출도 포함된다. 원문과 캡처는 비공개 데이터 저장소에만 둔다.

수치는 2026-10-18 첫 구현 검증 기준이며 최종 실측 후 갱신한다.

회차별 실행 파일을 분리하고 출제 관련 코드 스냅샷을 비공개로 보관한다. 확인용 전사에서 원본 대조로 기호 오타를 발견해 고쳤고, 수정 전 점수는 보존하며 수정 후 기준 평가를 다시 측정 중이다. 유리한 결과만 골라 채택하지 않는다.

수식 오탐 수정은 기출형 경로만 적용한다. 표시 명령을 핵심 낱말 비교에서 제외하되 정답 직접 노출 검사는 유지한다. 기존 일반 생성의 동작은 그대로다. 저장된 실패 응답 두 개의 오프라인 재생에서 오탐 해소를 확인했으며, 실제 재생성 품질은 아직 미검증이다. 제한 환경의 임시파일 이름 변경 권한 때문에 최초 검사 18건이 실패했으나, 허용된 환경에서는 전체 186건이 통과했다.

생성 호출 실측(평가 호출 제외): 기본형107회, 입력346,110/출력119,453토큰, 응답 시간 합계2,393,855ms. 첫 기출형89회, 입력799,476/출력92,797토큰, 응답 시간 합계1,890,628ms. 기본형은 일부 앞 단계 재사용 및 그림 읽기51회가 포함되어 있어 단순 비용 우열로 비교할 수 없다. 합산 응답 시간은 작업 전체 경과 시간과 다르다. 기출형의 입력량에는 별도 복제 검사의 기출 글자·이미지 입력이 포함된다.
