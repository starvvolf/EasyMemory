## 루트별 실험 서버 (A가 만듦, 모두 씀)

- `node scripts/run-lab.mjs --name <이름> --port <번호> [--data] [--dist] [--seed] [--env K=V]`. distDir·tsconfig·데이터 폴더를 따로 쓰고 로그는 `tmp/lab-<name>.log`.
- 포트: PS 3003(`Recaller PS실험 서버.cmd`), 프로젝트 3004(제안), 글·PDF 3005(데이터 `tmp/lab-text`, 빌드 `.next-lab-text`). 3002는 엔진 시험 서버.
- 서버끼리 데이터 폴더를 같이 쓰지 않는다(지식 저장소 쓰기 큐가 프로세스마다 따로). `--seed`는 처음 한 번 본 데이터의 knowledge/·code/를 복사.
- ChatGPT 로그인은 서버끼리 같이 쓴다(`coding\Recaller\.study-forge-data\chatgpt-auth`). 다른 폴더에서 서버를 띄우면 로그인이 안 보인다. 실험 서버에 `STUDY_FORGE_AUTO_EXECUTOR=1`이 빠지면 칩이 "ChatGPT 로그인"으로 보인다(run-lab.mjs가 기본으로 넣음).

## 모두 지킬 것

- 3000 서버는 묻지 않고 끄거나 다시 켜지 않는다. `.env.local`은 고치지 않고 키는 사용자가 넣는다.
- AI 사용량이 드는 실행은 하기 전에 말한다. 실측은 `.env.local` 키가 필요해 PC에서 `node --env-file=.env.local …`로 돌린다(원격 세션은 못 읽음).
- 공개 저장소: 강의 자료·문제 원문·모범 풀이·숨은 테스트·유니브 원문·`.env*`·키·ChatGPT 인증은 커밋하지 않는다.
- 원격 VM에서는 Windows용 Next 서버를 못 띄우고 git push가 403으로 막힌다. 서버 실행과 push는 PC에서.
