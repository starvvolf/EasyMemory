## 1. 한 일

1. **설계**: PS(코드 문제) ↔ 지식 저장소 양방향 루트를 설계했습니다.
   - 지금 기능으로 되는 것과 새로 필요한 것을 나눠서 정리했습니다.
   - 다른 루트와 동시에 실험할 수 있게 루트별 실험 서버도 설계했습니다.
2. **PS 창 AI 조언 설계와 구현**: "지켜보기" 기능입니다.
   - 학습자가 멈추거나, 막히거나, 같은 곳을 계속 고치면 지금까지의 코드를 예제와 가장 큰 숨은 테스트로 돌립니다.
   - 실행 결과에 문제가 없으면 모델에게 방향을 묻습니다.
   - 문제가 있을 때만 편집기 위에 한 줄로 알립니다.
3. **모드 두 개 구현**
   - 기본: 기존 그대로입니다.
   - 훈련: 7단계 PS 절차를 따릅니다(이해 → 추상화 → 탐색 → 정당성 → 복잡도 → 구현 → 복기).
4. **루트별 실험 서버**: `scripts/run-lab.mjs`와 `Recaller PS실험 서버.cmd`(포트 3003)를 만들었습니다.
5. **3003 로그인 칩 문제 수정**: 로그인은 정상적으로 저장되고 있었습니다. 원인은 실험 서버에 `STUDY_FORGE_AUTO_EXECUTOR=1`이 없어서 칩이 "ChatGPT 로그인"으로 보였던 것입니다.
6. **사용자 피드백 반영 (10/31 오후, 아직 커밋 안 함, 아래 4절 참고)**
   - 훈련 단계는 오른쪽 칸 위에, AI는 그 아래에 둡니다. 문제는 왼쪽에 그대로 둡니다.
   - 칸에서 다른 곳을 누르면 그 칸만 바로 채점해 ✓ 또는 "✗ 틀렸어요"를 보여 줍니다.
     - 앱이 직접 확인하는 칸: N의 최대, 시간 제한, 손으로 구한 답, 복잡도, 정당성 입력, 구현 경계 입력
     - AI가 확인하는 칸: 출력 한 줄, 추상화, 탐색 ①②③, "왜 항상 맞나". 바뀐 칸만 보내고, 칸 하나에 모델 호출 1번입니다.
   - 구현 단계 전에는 AI 칸이 "훈련 코치"가 됩니다.
     - 힌트, 반례 같은 코드 버튼 대신 예시 질문 3개를 채팅 입력창 바로 위에 둡니다.
     - 답과 코드는 주지 않습니다.
     - 구현 단계부터는 원래 버튼이 다시 나옵니다.
   - 훈련 모드에서는 단계마다 채팅이 따로입니다. 다음 단계로 가면 빈 채팅이 되고, 돌아가면 그 단계 대화가 보입니다. 화면에만 남고 새로고침하면 사라집니다.

## 2. 결정된 것

- `docs/DECISIONS.md` "2026-10-31 코드 문제: 훈련 모드 · 지켜보기 · 루트별 실험 서버"에 기록했습니다.
- 훈련 모드와 지켜보기는 **실험 서버에서만** 켜집니다(`RECALLER_PS_TRAIN=1`, `RECALLER_PS_WATCH=1`). 3000번 본 앱의 코드 화면은 그대로입니다. 스위치가 꺼져 있으면 해당 API가 404를 냅니다.
- 기록 규칙. 지식의 "앎"은 힌트 없이 통과했을 때만 셉니다.
  - 훈련 모드로 통과하면 `correct`가 아니라 "훈련 모드로 통과"라는 note로 남깁니다.
  - 지켜보기 경고를 받고 통과하면 "지켜보기 조언 n번 받고 통과"라는 note로 남깁니다.
  - 복기 단계에서 저장하면 문제의 knowledgeIds마다 "[복기] 핵심 발상 · 막힌 이유 · 다른 문제에도"라는 note를 남깁니다.
- 코치 AI는 모범 풀이를 보고 판단합니다. 대신 답에 모범 풀이의 18자 이상 줄이 들어 있으면 중립적인 질문으로 바꿉니다(`leaks()`).
- 실험 서버는 서로 데이터 폴더를 같이 쓰지 않습니다. 지식 저장소의 쓰기 큐가 프로세스마다 따로 있기 때문입니다. `--seed`를 주면 처음 한 번만 본 데이터의 knowledge/·code/를 복사합니다.
- ChatGPT 로그인은 서버끼리 같이 씁니다(cwd/.study-forge-data/chatgpt-auth).

## 5. 주의점

- **3000 서버**는 사용자에게 묻지 않고 끄거나 다시 켜지 않습니다. 실험은 3003에서만 합니다.
- **실험 서버를 새로 만들 때** `STUDY_FORGE_AUTO_EXECUTOR`가 빠지면 로그인 칩이 다시 "ChatGPT 로그인"으로 보입니다. run-lab.mjs가 기본으로 1을 넣습니다.
- **모델 호출 비용**: 칸별 AI 채점과 코치 채팅은 칸 하나, 질문 하나마다 ChatGPT를 1번 씁니다. 같은 내용은 다시 보내지 않습니다. 지켜보기는 문제당 최대 6번, 최소 3분 간격입니다.
- **VM에서는** Windows용 Next 서버를 띄울 수 없고 git push가 403으로 막힙니다. 서버 실행과 push는 사용자 PC에서 합니다.
- **줄바꿈**: 작업 폴더의 파일이 CRLF로 바뀌어 있습니다(HEAD는 LF). 그래서 `git diff`가 파일 전체를 바뀐 것으로 보여 줍니다. 실제 변경은 `git diff --ignore-cr-at-eol`로 보세요.
- **공개 저장소**: 문제 원문, 모범 풀이, 숨은 테스트, `.env*`, ChatGPT 인증은 커밋하지 않습니다.
- **커밋 범위**: 다른 스레드가 고친 파일(experiments/project-course/*, ProjectStudy.tsx, src/lib/study/gen/* 등)은 A 커밋에 섞지 않았습니다.
