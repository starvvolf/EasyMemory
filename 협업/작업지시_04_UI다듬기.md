## 할 일 (위에서부터 순서대로)
1. **내부 오류 문구 정리 (D3)**
   - 프로젝트 화면의 `서버 인증 설정이 없습니다. 누락된 환경 변수: AI_OWNER_EMAIL`
   - 학습 만들기 화면의 `저장된 학습을 불러오지 못했습니다: MCP 발행 덱 목록을 불러오지 못했습니다.`
   - 로컬 실험 모드에서 쓸 수 없는 기능은 숨기거나 "로컬 모드에서는 사용할 수 없어요"로 안내한다. 환경 변수 이름은 서버 로그에만 남긴다.
2. **MCP 실행 화면 분리 (D5)**: `/mcp-runs`의 SHA-256, 단계별 모델·추론 강도 선택, "기획팀장 대화에서 실행을 요청하세요"를 "개발자/실험" 영역이나 접힌 "상세"로 옮긴다. 사이드바에서도 학습자 메뉴와 구분한다.
3. **테마 통일 (D4)**: `/mcp-runs`, `/mcp-personalization`, 문제 미리보기를 메인 앱 테마 토큰에 맞춘다. 문제 카드가 밝은 면이어야 읽기 좋다고 판단되면 그렇게 해도 되지만, 페이지 바탕과 헤더·버튼은 메인 앱과 맞춘다.
4. **제품명 (D4)**: 화면에 보이는 "Study Forge"를 "Recaller"로 바꾼다. 코드 식별자, 저장 키, 경로는 바꾸지 않는다. 바꾸면 기존 기록과 해시 증거가 깨진다.
5. **자잘한 겹침 (D6)**: 상단 로컬 실험 배너가 오른쪽 배지에 가려 잘리는 문제(데스크톱·모바일), MCP 화면의 브라우저 기본 파일 선택 칸 스타일.
6. **코드 정리 (C5)**: `src/lib/personalization-lab/rule.ts`의 `recommend()`도 `objective-checklist.ts`처럼 이벤트를 시간순으로 정렬한 뒤 판단하게 한다.
7. **배포 전 과제 (C2, 지금은 기록만)**: 인터랙티브 HTML의 `answer-contract`에 정답이 포함되는 문제는 배포나 공유를 결정할 때 서버 채점으로 옮긴다. 이번에는 결과보고에 "보류"로 남긴다.
