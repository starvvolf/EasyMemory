# 방향 (Codex가 회고 바퀴마다 고친다 · 고정 원칙은 못 고침)

## 북극성
- **사람 신호**: 공부하면서 누른 "지엽 / 쉬움 / 이상해요 / 정답 추가 / 목표 빼기"가 문제 100개당 몇 건인가. 줄어야 한다.
- 판정단 점수(실패·의심 수)와 점수표 의심 신호는 **대리 지표**. 사람 신호와 어긋나면 사람 신호를 믿는다.

## 고정 원칙 (Codex 수정 금지 · 바꾸려면 아래 "제안"에)
- 고정 시험지·확인용 시험지는 바꾸지 않는다.
- 채택은 "판정 실패가 늘지 않음 + 확인용에서도 실패 안 늘어남"이 최소 조건.
- 위임 범위(작업지시 19) 밖 파일은 고치지 않는다.
- `docs/DECISIONS.md`의 사용자 결정을 거스르지 않는다 (self-check 카드 허용, 틀린 문제 10분 재출제 없음, 용어는 객관식 고르기 가능 등).
- 시험 과목(그래픽스 10/20, 반도체공학·기업윤리 10/24–25)에 도움이 되는 방향이 우선.
