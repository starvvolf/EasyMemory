## 하네스 수정
`SKILL.md`와 `references/`에 다음을 반영한다. 원칙만 적지 말고 **좋은 예와 나쁜 예를 기존 문항에서 가져와** 넣는다.
- **오답 만들기**: 흔한 오개념(부호 반전, 순서 반전, 조건 누락, 비슷한 개념 혼동)에서 만든다. 정답과 길이·문체를 맞춘다. 좋은 예로 기하 9·18·20을 참고한다.
- **답 형식**: 여러 요소를 답하는 문제는 요소별 빈칸이나 순서 배열로 낸다. 서술형은 `self-check`로 낸다. `exact-normalized`는 짧은 값(좌표, 수치, 기호 하나)에만 쓴다.
- **원문 표기 우선**: 인정 답안에 원문 표기를 반드시 넣고, 생성기가 새로 만든 표기(`T(q)`, `T(-f)`)는 추가 인정 답안으로만 쓴다.
- **배치**: 기본은 흐름 배치다. `frame` 좌표는 그림에 겹쳐 놓는 문항에만 쓴다. 렌더러가 흐름 배치를 지원하도록 바꾸는 작업이 필요하면 이 지시에 포함한다. 문서 스키마 버전을 올려야 하면 올리고, 이유를 결과보고에 쓴다.
- **출처 칸**: `sourceRange`에는 원문 위치(쪽, 소제목, 원문 구절)를 쓰고, 지식 요약은 `knowledgeContent`에만 쓴다. 이 규칙을 Learning Design 단계 지시문에도 넣는다. 해당 지시문 위치는 MCP 서버(`tools/study-forge-mcp/`)에서 찾아 결과보고에 적는다.
