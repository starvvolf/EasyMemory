## 1. 결과 화면 (그래픽스 02, 값 쓰기 문제 하나)
1. 정답과 표기만 다르게 입력(예: 공백·괄호) → 틀림 → "내 답도 맞아요" → "다음부터 이 답도 정답으로 칠까요?" → "정답에 추가".
2. 기록 탭 "고친 것"에 생겼는지, 같은 문제를 다시 풀 때 그 표기가 정답인지.
3. 같은 문제에서 한 번 더 "내 답도 맞아요" → "카드로 바꾸기"가 보이는지 → 누르면 그 문제가 떠올리기 카드가 되는지 → "고친 것"에서 되돌리면 값 쓰기로 돌아오는지.
4. 아무 문제에서 "너무 지엽적" → 목표가 빠지는지. 기업윤리에서 강의 운영 안내 목표(평가 비율·출석 등)가 남아 있으면 그걸로 해 보고 "비슷한 목표 n개도 뺄까요?"가 뜨는지.
5. "너무 쉬움" → 기록 탭 다음 복습이 약 35일 뒤인지.

## 2. 풀이 끝 피드백
1. "더 할 수 있어요" → 오늘 할 것의 하루 시간이 +15분, 아래 "내 조정"에 표시, "기본값으로"로 돌아가는지.
2. "아는 게 자꾸 나와요" → 그다음 맞힌 문제의 다음 복습이 1.25배인지(예: 3일 → 약 3.75일).
3. "너무 꼼꼼·지엽적" → 정리 탭 그 자료의 "핵심만"이 켜지고 보조 목표 문제가 오늘 할 것·연습에서 빠지는지. 단추로 끄면 돌아오는지.
4. "빠진 게 많아요" → 정리 탭으로 가서 "문제가 없는 쪽"이 보이는지. 쪽 하나 누르면 기록되는지.

## 3. 장부·코치
1. 데이터 폴더 `study-quality/장부.md`에 위 사건이 한 줄씩 있는지(원인 칸 확인). `patches.json` 확인.
2. 같은 원인을 3번 만들면(예: "너무 지엽적" 3번) 홈 오늘 할 것 아래 코치 카드 "‘지엽적’ 피드백 3번"이 뜨는지 → "다음 자료 메모에 넣기" → 자료 만들기 탭 메모 칸에 그 문장이 미리 들어가 있는지(실제 생성은 하지 않는다).
3. "닫기"한 카드가 새로고침 뒤에도 안 나오는지.
4. "Recaller 끝내기" 뒤 RecallerData에 `study-quality/`가 올라갔는지.

## 4. 용어 고르기 (2026-10-15 추가, 호출 0)
1. 기업윤리 2주차를 연습 → "용어 고르기" 칩이 붙은 문제가 나오는지(그 자료 카드 89개 중 약 17개). 보기 4개가 모두 같은 종류의 용어(예: 앵커링 효과·집단 사고·방관자 효과·윤리적 퇴색)인지.
2. 정답·오답이 자동 채점되는지, "카드로 풀기"를 누르면 그 문제만 카드로 바뀌는지.
3. 오답 중 정의에 함께 맞는 것이 있으면(객관식-6 위반) 문제 ID와 보기를 적는다.
4. `학습규칙/품질.md`의 `[용어-고르기]`를 `아니오`로 바꾸고 새로고침 → 모두 카드로 돌아오는지 → `예`로 되돌린다.
