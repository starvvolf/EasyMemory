# 금요일(10/30) 교수님 미팅 준비

2026-10-28 사용자가 정한 세 가지. 금요일 전에 끝낸다.

## 1. 시연 가능한 앱 (시연 중 오류 없음)

- **시연 경로를 먼저 고정**하고, 그 경로는 오류가 없게 만든다.
  - PDF: 넣기 → 읽기 → 문제 → 틀리기 → 지식에 "몰랐음" → 복습
  - 코드: 주소(또는 백준 번호) 넣기 → 문제 → 틀리기 → 힌트 → 맞히기 → 지식 반영
- 스레드별 점검·수정: A = 코드 탭, B = 지식·복습 화면, PDF 공부 화면(주인 없음)은 A가 시연 경로만 점검.
- **시연용 데이터 폴더**를 따로 만들어, 미리 만든 문제·지식을 넣어 둔다(만들기는 1~2분 걸리므로 현장에선 1개만 실제로).
- 시연 대본(어느 화면에서 무엇을 누르는지) + 리허설 2번 + 대비책(화면 녹화·스크린샷).

## 2. 파이프라인 학습 (사용자가 직접 이해해야 함, Claude가 도움)

파이프라인마다 학습 자료 한 장: 그림 1개, 단계별 입력 → 출력, 실제 예시 1개, 교수님이 물을 만한 질문 5개. 다 읽으면 Claude가 퀴즈로 확인.

| 파이프라인 | 자료 | 상태 |
|---|---|---|
| 코드 문제 (가져오기 → 초안 → 테스트 → 독립 풀이 대조 → 채점) | A(Claude)가 작성 | 내용은 10/27~28 대화에 있음, 정리만 |
| 지식 저장소 (들어오는 길 → 같은 지식 찾기 → 기록 → 복습) | B가 만든 미팅용 설명 | 사용자 눈높이로 다듬기 |
| 생성 엔진 (PDF → 정리 카드 → 기본·심화 문제 → 검사) | C 점검 뒤 작성 | C 점검이 먼저 |

예상 질문에 넣을 것: 기존 앱(Anki·유니브)과 차이, AI가 만든 문제·정답이 맞는지 어떻게 아나, 사용자 평가는 했나(미룬 이유·계획), 비용, 왜 DB가 없나·여러 사용자로 늘리면, 남은 기간에 무엇을 완성하나.

## 3. 노션 채우기

- **앱 설명 페이지**: 문제 → 해결 → 핵심 흐름 → 차별점 (한 페이지)
- **경쟁 제품 비교**: 3번 페이지 있음. 코드 학습 앱 비교, 로컬 채점 비교를 더한다.
- **기능 목록**: 2번 진행판 DB 갱신. 완료/진행/예정 + **예상 소요 시간**. 10/26~28에 한 것(로컬 채점·보정·숨은 테스트·독립 풀이, 주소로 가져오기, 임베딩·같은 지식 찾기 등) 반영.
