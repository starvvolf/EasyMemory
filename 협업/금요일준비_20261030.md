## 1. 시연 가능한 앱 (시연 중 오류 없음)

- **시연 경로를 먼저 고정**하고, 그 경로는 오류가 없게 만든다.
  - PDF: 넣기 → 읽기 → 문제 → 틀리기 → 지식에 "몰랐음" → 복습
  - 코드: 주소(또는 백준 번호) 넣기 → 문제 → 틀리기 → 힌트 → 맞히기 → 지식 반영
- 스레드별 점검·수정: A = 코드 탭, B = 지식·복습 화면, PDF 공부 화면(주인 없음)은 A가 시연 경로만 점검.
- **시연용 데이터 폴더**를 따로 만들어, 미리 만든 문제·지식을 넣어 둔다(만들기는 1~2분 걸리므로 현장에선 1개만 실제로).
- 시연 대본(어느 화면에서 무엇을 누르는지) + 리허설 2번 + 대비책(화면 녹화·스크린샷).
