## 시연 원칙
- 길게 쓰는 단계(PDF 생성, 문제 만들기, 숨은 테스트 만들기)는 영상, 짧거나 AI 없는 단계(채점·기억·복습)는 실제.
- 모든 시연은 리허설로 미리 채운 데이터에서 시작. 실패 시 대안: 녹화본·캡처·미리 끝낸 기록.
- 알고리즘은 BOJ 7576 토마토(`bakingdog-workbook.json` 0x09, 배운 것 카드 실측 예). BOJ 1004는 튜터 문제집에 없음 → 미팅용.
- 실습은 짝수 합 loop.js(11/5 실제 한 바퀴 기록). 단어 빈도는 실제로 돌린 기록 없음.

## 예상 질문
1. 그냥 ChatGPT에 올리면? → 대화가 끝나면 안 남는다. 틀린 순간을 기억으로 남기고 코드가 정한 날에 다시 묻는다.
2. AI가 틀린 문제·채점을 하면? → 채점은 AI가 안 한다(실행 비교, 직접 풀어 본 답이 다르면 안 냄).
3. 튜터가 답을 주면? → 질문으로 짚기, 정답 핵심 비율 79–86% → 7–21%.
4. 기억이 너무 쌓이면? → 알고리즘은 몰랐다가 배운 것만, PDF는 52쪽에 35개.
5. 효과 근거는? → 기능은 쟀지만 장기 기억 효과는 아직.
6. 비용은? → 사용자 ChatGPT 로그인. API 환산 문제 만들기 $0.19~0.26.
7. 왜 PC 앱? → 채점·실습 코드를 학습자 PC에서 돌리고 튜터가 작업 폴더를 쓴다.
8. 저작권은? → 공개 저장소에 원문을 올리지 않는다.

## 발표 전 체크
- 데이터 폴더는 지우지 않는다. 새로 시작하려면 사용자가 직접 `tools/데이터 보관하고 새로 시작.cmd`, 되돌릴 때 `restore`.
- 미리 채울 것: PDF 1개(카드·문제), 7576·1920 재료와 숨은 테스트, 짝수 합 실습 끝낸 기록, 오늘 › 문제 풀기에 세 갈래가 다 나오는지.
- 녹화본·빨리감기 영상·캡처, 절전·알림 끄기, 10분 리허설 2번.
