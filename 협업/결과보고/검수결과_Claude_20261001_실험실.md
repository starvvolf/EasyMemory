## Claude가 고친 것 (이 검수 커밋)
1. **실제 호출에서 JSON 응답 형식 지정이 빠졌음.** 실행기가 `callModel`에 `json: true`를 넘기지 않아, ChatGPT 공급자의 JSON 응답 모드가 꺼져 있었다. 가짜 모델에서는 드러나지 않는다. → 다시 `json: true`로 부른다. 형식이 틀린 답도 호출 기록에 남도록 `callModel`이 원래 답을 오류에 실어 보낸다(`rawText`). 테스트 추가.
2. **추론 강도 환경변수 검증이 사라졌음.** `STUDY_FORGE_EXECUTOR_EFFORT`에 오타가 있으면, 모델을 부른 뒤 요청 기록 단계에서 실패한다(사용량만 나감). → 허용값이 아니면 무시하게 되돌렸다. 테스트 추가.
3. **출제 결과가 저장소 폴더에 쌓임.** `tools/problem-authoring-lab/runs/chatgpt-request-*/`는 개인 실행 기록인데 git 무시 목록에 없었다. → `.gitignore`에 추가했다.
