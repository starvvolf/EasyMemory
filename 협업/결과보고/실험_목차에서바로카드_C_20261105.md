# 실험: 목차 → 바로 카드 (`lab.mapCards`, C, 2026-11-05)

사용자 제안: 자료 전체를 보내 "무엇을 배우는지"만 목차처럼 받고(예: p.6은 A·B·C를 배운다), 그 항목을 원문과 함께 넘겨 카드로 만든다. 화면에는 "A, B, C를 배운다" 줄 아래 A·B·C 카드를 붙인다.

## 구현 (실험 옵션, 기본값 꺼짐)
- `lab.mapCards: true` — 목차 호출이 주제와 항목(`tN-cK|이름|쪽`)을 쓴다(개념 줄 지시 재사용). 주제 요약(`rc-topic`) 호출은 없다. 코드가 "제목 (p.x–y): A, B, C를 배운다." 줄을 만든다.
- 카드 호출(`MAP_CARD`, digest.ts): 항목 이름 + 그 쪽 원문(그림 포함)으로 항목마다 정의·조건·판정·절차·예제 카드. 카드 `covers` = 항목 id → 화면에서 항목 아래에 붙음.
- `lab.mapUnit`: `"topic"`(AI가 1~3쪽 묶음, 기본) / `"page"`(쪽마다 한 묶음, 쪽 제목 그대로).
- 시험: `digest.test.ts` "목차 → 카드" (두 단위 모두, 주제 요약 호출 없음·카드가 항목에 붙음).

## 결과 (데드락 14쪽, terra low, 퀴즈 없음)
| | 기존 (목차 → 주제 요약 → 카드) | 주제 단위 `gen_d0329107` | 쪽 단위 `gen_c2ace2a7` |
|---|---|---|---|
| 카드까지 비용 | $0.12~0.19 | $0.086 | $0.087 |
| 카드 완료 | 29~57초 | 48초 | 40초 |
| 카드 | 35~40 | 33 | 37 |
| 목차 호출 | 7초·출력 ~250 | 19초·출력 682 | 17초·출력 783 |
| 카드 없는 항목 | — | 0 | 0 |

- 좋은 점: 비용 30~50% 적음. 구조가 그대로 보임(항목 → 카드). "네 조건이 동시에 성립" 카드가 네 조건 항목 모두에 붙음. 사이클 판정은 세 카드(없음/단일/복수)로 나뉨. 세마포어 예제 카드 있음. 영어 자료 규칙(영어(한국어))이 적용됨.
- 아쉬운 점: 쉬운 설명·흔한 오해가 없음(주제 요약을 뺐으므로). 퀴즈 재료에 주제 본문·흔한 오해가 들어가지 않음. 번역어가 주제마다 다름(Hold and wait: 점유와 대기 / 보유와 대기, Circular wait: 원형 대기 / 순환 대기). 목차 호출이 길어져(출력 2.5~3배) 카드 시작이 늦음.
- 쪽 단위: 카드 호출이 11개로 더 퍼져 가장 빠름(40초). 단 쪽 제목이 같은 슬라이드("Deadlock Characterization" p.4~7)가 같은 제목으로 반복되고, 예방 쪽에 개요 카드 하나가 네 항목에 다 붙음.
- 한 번씩 측정.

## 고친 뒤 (`gen_4468865f`, 주제 단위)
고친 것: 영어 자료 표기를 "한국어 번역(영어 원어)"로, 다시 나오면 한국어만(영어 낱말 섞지 않기). MAP_CARD에 "이름 붙은 항목은 용어 카드", "판정 규칙은 적용 범위를 condition에", "경계 칸은 원문에 있을 때만".
- 카드 33, $0.092, 카드 완료 45초.
- 영어 섞임 없어짐("자원을 보유한"), 의미 없는 경계 칸 0, 네 조건·간선이 용어 카드(동어반복 조건 카드 0). 형식: 용어 14·조건 9·사실 6·절차 3·목록 1.
- 남은 것: 원문 용어가 아닌 설명형 이름에도 영어를 지어 붙임("상호 배제의 부정 불가능성(Impossibility of denying mutual exclusion)") → 지시 추가(원문 용어에만), 실행 확인 전. 번역 흔들림 1곳(점유와 대기 / 보유와 대기). p.11–12가 한 주제로 묶여 p.12 예제(P2의 R2 요청) 전용 카드가 빠지고 일반 규칙 카드만 남음. 탐지 카드는 "순환 → 교착 상태"에 복수 인스턴스 주의가 경계 칸으로 붙음(전보다 나음).
