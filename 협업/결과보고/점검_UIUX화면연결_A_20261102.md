# 점검: 실제로 쓸 수 있게 — 화면 연결·UI/UX 부족한 점 (2026-11-02, A·Claude)

사용자 요청: "실제 사용 가능하게끔 UI UX 보고 화면 연결 부족한 점 찾기. 지금은 문제가 많음."

- 방법: 앱(127.0.0.1:3000, 3000 서버는 건드리지 않음)을 Claude 앱의 브라우저 창으로 처음부터 눌러 봄. 오늘 → 공부(PDF·웹 글·코드·프로젝트) → 자료 지도 → 원문 쪽 → 지식 → 일정 → ··· 메뉴 → 새 공부 → 지식 사이드바.

- 데이터: PC 테스트 데이터(`review-test-data`). 지식 274개, PDF 실행 여러 개, 웹 글 5, 코드 문제 23, 프로젝트 1.
