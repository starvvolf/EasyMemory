# 글 지도: A 점검(10/29 새벽) 반영 결과 (B 스레드)

근거: `보관/협업/사용자점검_PDF와긴글_20261029.md` 3절 8~13번, A의 부탁 1~4.

## 고친 것
1. **웹 글은 바로 글 지도로.** 지식 잡기 뒤 "시험이나 기한이 있나요?" 없이 웹 글 화면(글 지도)으로 간다. 목표·기한은 글 지도 아래 접힌 칸 "목표·기한에 넣기"에서(시험·수업 자료일 때만).
2. **개념어 뜻이 늘 보이게.** 칩 대신 "이름 — 이 글에서의 뜻" 줄. 누르면 고름(＋), 다시 누르면 빠짐. 모르는 것을 위로, 아는 것(✓)은 뒤로, 처음 8개 + "나머지 n개 보기". 이미 아는 것과 이미 있던 핵심은 이름으로 알려 줌.
3. **기다림 안내 "20초쯤" 고정.** 글 지도는 개념어를 한 줄로만 받아 글 길이와 거의 상관없이 14~20초.
4. **핵심 확인 카드 앞면 = 질문.** 핵심마다 확인 질문(ask)을 함께 받아 플래시카드 앞면·객관식 질문으로 쓴다. 지식 이름은 질문으로 바꾸지 않고, "글에 실제로 나온 말로" 짓게 했다(지식창 목록·같은 지식 찾기가 질문 문장으로 차지 않게).

## 남은 것 (시연 뒤)
- 6. 앱 안에서 본문 다시 보기: 본문은 이미 저장돼 있음(최대 6만 자). 흐름 단계 → 해당 부분으로 가려면 단계마다 짧은 인용을 같이 받으면 됨.
- 7. PDF 과목·시험일: 과목 = 목표라 PDF 화면이 과목을 물으면 목표 동기화는 이미 됨. 고칠 때 B는 목표 쪽만 확인.
- 핵심 이름과 개념어가 겹치는 경우(차익거래)가 있음. 개념어를 고르면 같은 지식으로 합쳐져 문제는 없지만, 목록에서 중복으로 보인다.
