## 2. 바꿀 실행 구조 (안)

**앱 하나:** `Recaller` 바로가기(Electron)만 쓴다.

**켤 때**는 로딩 창에 단계가 나온다.
1. 코드 받기
2. 패키지(바뀐 때만)
3. 데이터 받기(RecallerData)
4. 앱 서버(3000)
5. 실습 코스 서버(4100)
6. 준비 확인 → 창 열기

**끌 때**는 X → "Recaller를 끝낼까요? 공부 기록을 저장하고 서버를 꺼요" [끝내기]/[취소].
1. 저장
2. 코스 서버 끄기
3. 앱 서버 끄기
4. 데이터 올리기
5. 창 닫기

**실험 서버**(엔진 3002, PS 3003)와 사용량 3091은 제품 흐름에서 뺀다.
- `lab/`에서 켠다(`lab/엔진 실험 서버.cmd` 등).
- 앱의 ··· > 개발용 화면에서도 열 수 있게 한다.

**루트 `.cmd`**: `Recaller 앱.cmd` 하나만 남긴다(바로가기를 만든다).
- 끝내기·시작은 앱이 한다.
- 나머지는 `lab/`·`tools/`로 옮긴다.

**데이터 폴더**는 RecallerData로 통일한다(4절). 그래야 끌 때 저장한 것이 다른 컴퓨터로 간다.

## 4. 실험 데이터 보관과 시연용 빈 데이터 (안)

- 지금 데이터(지식, 코드 문제 51개, PDF 실행 13개, 기록 등 356MB)는 RecallerData에 `보관/2026-11-05-실험데이터/`로 한 번 넣는다. 이미 올린 앱 데이터는 그쪽으로 옮긴다.

- 실험실 데이터(`tmp/engine-data`, `tmp/lab-ps`, `experiments/*/out`)는 PC에만 둔다. 4-1의 위치 목록에 남긴다.

### 4-1. 용량 큰 것 위치 목록

`tools/space.mjs`(새로 만든다)가 PC에서 크기를 재고, 지워도 되는 것과 이유를 보여 준다. 대상은 다음과 같다.
