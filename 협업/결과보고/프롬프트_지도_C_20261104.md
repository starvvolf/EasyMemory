## 6. 알려진 문제 (검토 받고 싶은 곳)
1. 출제
   - 비전공 자료(기업윤리)에서 약함: 사례 줄거리를 묻거나 표 제목을 보기로 씀. 금지 지시를 넣었지만 여전히 가끔 나옴.
   - 같은 지식을 묻는 문항: 원문이 같은 규칙을 여러 주제에서 반복하면 생김. 목표 단위 출제 + `sameAsk`로 줄였지만 프롬프트로 더 막을 수 있는지.
   - 눈가림 풀이(⑩) 방식 미정: 지금은 카드 근거 쪽만 준다(`sourceOf`, 원문 전체 아님). 근거 쪽 / 관련 쪽 추가 / 원문 전체 중 무엇이 맞는지, OX의 X 진술만 따로 확인할지.
2. 카드(기존 경로 데드락 비교에서 나온 것)
   - 같은 판정 규칙이 여러 주제 카드에 반복됨.
   - 깨진 제목("deadlock state.", "V" 한 글자), 순서가 뒤바뀐 절차 카드.
   - 경계(boundary) 칸에 "그림 (b)" 같은 그림 지시가 들어감.
   - 주제 제목만 옮긴 빈 카드, 동어반복 조건 카드("~이 성립한다").
3. 개념 줄(실험, 꺼둠)
   - 카드까지 9~17초 느림(목차 출력이 2배).
   - 영어 원어의 한국어 번역어가 실행마다 바뀜.
   - 줄 이름 반복 금지 지시가 용어까지 바꿈("상호 배제"→"단독 사용") → 보완 지시 넣음, 실행 확인 전.
   - 개념 줄 단위로 나누다 보니 한 장이어야 할 카드(네 조건 전체, Claim edge 흐름)가 쪼개짐.
4. 프롬프트 예시 치우침: `Q_MATERIAL`·`Q_CHOICE`·`Q_CLOZE`의 예시가 데드락·그래픽스(클리핑)에서 왔다. 다른 분야에서 예시를 베끼는지 확인 필요.
