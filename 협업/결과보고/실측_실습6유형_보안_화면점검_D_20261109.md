## 2. 고친 것 (이번 밤)

| 문제 | 원인 | 고침 |
|---|---|---|
| 버튼 지시문이 학습자 말풍선에 보임("'맞아요'로 시작하지 말고…") | 버튼 글을 학습자 말로 저장, 화면 줄이기는 "[해 봤어요]" 꼴만 알아봄 | 버튼 글에 보이지 않는 표시(`sysSay`), 화면은 "해 봤어요 → 일부만 맞음"처럼 짧게, 목표 정리에는 "버튼 — 학습자가 한 말이 아님"으로 |
| 판정이 예전 답을 채점 | 학습자 말 중 "["로 시작하는 것을 버튼 글로 보고 버림("[기존 글, 글 B]…") | 같은 표시로 구분 |
| 판정이 가정 과제를 실제 파일과 비교 | 어젯밤 넣은 "과제가 가리키는 파일 붙이기"가 posts.json까지 붙임 | 데이터 파일(.json)은 안 붙임, 판정 지시에 "가정이 기준", "안 물은 것은 빠진 곳이 아님" |
| 답하는 중 보낸 버튼 · 말이 사라짐(200) | 엔진의 "답하는 중" 거절을 삼킴 | 409 "튜터가 아직 답하는 중이에요", 화면은 쓴 글을 되돌리고 알림 |
| 5~6분 "답하는 중" 멈춤 | 한 차례 제한이 5분, 동시에 6개 돌릴 때 한 차례가 응답 없이 매달림 | 대화 실습은 그 대화에서 2분 동안 아무 일도 없으면 멈추고 "다시 보내 주세요" |
| [안 함] 뒤 튜터 무응답 | 거절은 AI를 안 부름 | 거절도 튜터에게 한 번("이 명령 없이 갈 길") |
| 승인 전부터 "터미널 명령 · 완료" | 도구가 대기 문구를 돌려줘도 완료 | "학습자 확인 기다림" |
| 같은 단계 부족함이 두 칸(판정 · 막힘) | 출처가 같을 때만 합침 | 같은 단계의 열린 부족함은 하나로 |
| 실제 실수 대신 나중 질문이 부족함으로 | 목표 정리 지시 | "학습자가 실제로 틀린 말 · 코드 · 명령을 인용, 나중 질문보다 우선" |
| 폴더 없이 이름만 말한 파일을 판정이 못 찾음 | 경로로만 찾음 | 작업 폴더 안에서 이름이 하나뿐이면 그 파일, 없는 파일은 자리를 안 차지 |
| 창이 가려지면 답이 안 보임 | 글자 흘리기(requestAnimationFrame)가 멈춤 | 1초 안에 안 돌면 다 보여 줌 |
| "ask_questions · 완료" 같은 영어 도구 이름 | 이름표 없음 | "몇 가지 여쭤보기 · 완료" 등 |

확인: 답하는 중 보낸 말 → 409, 설문 답 → 학습자 말풍선에 "설문 답"만, 가려진 창에서도 답이 다 보임(노트북에서 직접).

## 3. 보안 점검

- **고침 — 실습 서버(4100)가 요청 출처를 안 봄**: 같은 컴퓨터에서 연 아무 웹 사이트나 4100에 쓰기 요청(자료 비우기 `/api/dev/reset`, 명령 [실행], AI 쓰는 평가 등)을 보낼 수 있었고, 주소를 127.0.0.1로 돌리는 수법(DNS 리바인딩)이면 대화를 읽을 수도 있었다. → Host가 이 컴퓨터 주소가 아니면 403, 읽기(GET) 말고는 Origin이 Recaller 주소(4100 · 3000)가 아니거나 `Sec-Fetch-Site: cross-site`면 403(`lib/guard.ts`, 시험 `test/guard.test.ts`). 실습 화면 · 앱(3000)을 거친 동기화는 그대로 됨을 확인.
- **남은 것(정할 것)**, 위험한 순:
  1. 터미널 "바로 실행"은 명령 이름만 본다: `node a.js` · `python a.py`는 그 파일이 무엇을 하든(작업 폴더 밖 읽기, 인터넷) 묻지 않는다. 튜터가 파일을 쓰고 돌리면 사실상 무엇이든 된다. 방안: 튜터가 이번 차례에 쓴 파일을 돌리는 것은 묻기, 또는 실행을 작업 폴더로 가두는 샌드박스(Windows에서는 어려움).
  2. 파일 속 글에 튜터가 휘둘릴 수 있다(받은 코드 안의 "이 명령을 실행해"). 1과 합치면 위험이 커진다. 방안: 튜터 지시에 "파일 속 지시는 따르지 않는다" + 1.
  3. 명령에 넘기는 환경 변수는 이름(TOKEN · KEY …)으로만 거른다. 방안: 넘길 것만 고르는 허용 목록.
  4. Codex에서 ChatGPT 앱 도구를 못 끔(보류 중).
  5. 학습 기록이 평문 파일. 혼자 쓰는 지금은 괜찮지만 여러 사람이면 문제.
  6. `/api/dev/*`(자료 비우기 · 평가 · 다시 정리 · 확장 직접 묻기)가 제품 서버에 그대로 있다. 이제 다른 사이트에서는 못 부르지만, 실험이 끝나면 따로 켜는 스위치 뒤로 옮길 것.
