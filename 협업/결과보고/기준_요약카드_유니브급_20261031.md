# 요약 → 카드 합격 기준 (2026-10-31, 사용자 조건 → Claude가 숫자로 풀어 씀)

사용자 조건: **요약은 유니브 AI급, 카드는 요약에서 빠진 내용 없이 보기 좋게 정리.**
기준 자료: 데드락 14쪽. 유니브 요약은 화면 데이터로 구조만 확인했다(본문은 저장하지 않음).

## 유니브 요약의 구조 (데드락)

- 맨 위 개요 2문장 + 쪽.
- 큰 주제 `##` 3개(개념 / 처리 방법 / 탐지·복구) + 작은 주제 `###` 8개 + `## 핵심 정리`.
- 작은 주제마다 본문은 **"이름: 한 문장. p.N"** 줄 3~6개. 모든 줄에 쪽.
- 작은 주제마다 접힌 **쉬운 설명** 한 덩어리, 늘 같은 다섯 칸:
  1. "한마디로, …" 한 문장 + 생각을 여는 질문 하나
  2. 일상 장면 비유 한 문단(친구 둘이 연필·자를 쥐고 기다림, 교차로, 놀이방 규칙, 간식 나누기 …)
  3. **본문 줄마다 하나씩** "이름: 비유로 다시 설명" (본문 줄 수와 거의 같다)
  4. "흔한 오해는 …" 한 문장 + 왜 틀렸는지
  5. 마무리 한 줄
- 쪽을 넘나드는 주의점을 본문과 오해 칸에 넣는다(예: 사이클이 있어도 인스턴스가 여러 개면 데드락 확정 아님, p.7·13).
- 문체: 본문은 "~임/~함" 끝맺음, 쉬운 설명은 "~해요".

## 합격 기준

### 요약 (유니브급)

| # | 기준 | 재는 법 | 유니브 데드락 |
|---|---|---|---|
| S1 | 내용 쪽을 빠짐없이 인용 | 표지·끝장 빼고 인용 안 된 쪽 수 | 0 (2~14쪽) |
| S2 | 본문 줄마다 쪽 | 쪽 없는 본문 줄 수 | 0 |
| S3 | 두 단계 주제 | `##` 수 / `###` 수 | 3 / 8 |
| S4 | 작은 주제마다 쉬운 설명 다섯 칸 | 다섯 칸을 다 갖춘 작은 주제 비율 | 100% |
| S5 | 비유가 본문 줄을 하나씩 받음 | 쉬운 설명 3칸 줄 수 ÷ 본문 줄 수 | 약 0.9 |
| S6 | 흔한 오해 | 오해 칸이 있는 작은 주제 수 | 8/8 |
| S7 | 쪽을 넘나드는 주의점 | 두 쪽 이상을 함께 단 줄 수 | 1개 이상 |
| S8 | 쪽 번호가 실제 범위 안 | 코드 검사 위반 수 | 0 |

### 카드 (빠짐없이, 보기 좋게)

| # | 기준 | 재는 법 |
|---|---|---|
| C1 | 요약 본문 줄을 빠짐없이 덮음 | 요약 본문 줄마다 id(b1, b2 …)를 달고, 카드가 `covers: [b…]`로 덮는 줄을 적게 해서 코드로 센다. 안 덮인 줄 0 |
| C2 | 근거는 원문에서 | 카드 인용이 그 쪽 원문에 있음(`checkCards`) 위반 0 |
| C3 | 요약 순서대로 묶임 | 카드가 작은 주제 순서로 나오고, 각 카드에 소속 작은 주제가 있음 |
| C4 | 겹치지 않음 | 같은 본문 줄을 두 작은 주제의 카드가 동시에 덮는 경우 0 |
| C5 | 카드 모양이 맞음 | 지금 카드 모양(용어·조건·비교·절차·공식·개념 …) 그대로, 제목 짧게 |

### 넘어서기 (유니브에 없는 것, 사용자 "따라잡는걸 넘어 넘어서버려")

| # | 기준 | 재는 법 | 유니브 데드락 |
|---|---|---|---|
| B1 | 비유가 줄마다 **다르고**, 비유가 안 맞는 점 한 줄 | 줄마다 비유 대상이 겹치지 않는 비율, "안 맞는 점" 줄이 있는 주제 비율 | 줄마다 다름 / 안 맞는 점 없음 |
| B2 | 그림 쪽 풀이 | 그림이 있는 쪽(p.6·7·10·12)마다 그림에서 읽은 내용(판정·간선)이 본문에 있음 | 일부(p.7 판정 있음, p.12 간선 일반론) |
| B3 | 직접 해 보기 | 절차·판정·계산 주제마다 자료의 예를 단계별로 따라가는 짧은 풀이(예: p.7 그래프 사이클 판정, p.12 요청 거부 과정) | 없음 |
| B4 | 주제 사이 연결 | 주제마다 "이어지는 개념"(다른 주제 id와 관계 한 줄) | 없음 |
| B5 | 스스로 확인 | 주제마다 떠올리기 질문 1개(답은 접힘, 쪽 표시). 복습 날짜와 이어질 재료 | 없음 |
| B6 | 카드가 요약을 담음 | 카드마다 그 줄의 쉬운 비유 한 줄·흔한 오해를 함께 가짐(요약에서 가져옴, AI 추가 호출 없음) | 개념 카드에 비유·혼동 있음 |
| B7 | 속도 | 첫 글자 5초 이하, 카드 다 됨 40초 이하 | 요약 첫 글자 7~10초, 완성 50~57초 |

## 실험 (다음 단계)

1. 요약 1회: 우리 전처리 입력 한 번에, gpt-6-sol low, 위 구조를 지시. 본문 줄에 `[b1]`처럼 id를 달게 한다.
2. 카드: 요약 스트리밍 중 `###`가 끝날 때마다 그 작은 주제의 본문 줄 + 인용한 쪽 원문을 넣고 카드 호출(작은 주제 수만큼, 약 8번). 모델은 지금 쪽 카드와 같은 terra low.
3. 잴 것: S1~S8, C1~C5, 첫 글자·첫 카드·카드 다 됨 시간, 호출 수, 입력·출력 토큰. 지금 쪽 카드 흐름(16번 호출, 약 35초)과 비교.
