# 작업지시 13: 단계별 모델 비교 (2026-10-12)

`GPT_작업규칙.md`를 따른다. 코드·기준 파일은 고치지 않는다.

## 목적
시험 기간에 쓸 기본 모델을 정한다. 단계마다 따로 비교하고, 앞 단계는 고정해서 차이가 그 단계에서만 나게 한다.
**판정 기준: 품질이 기준(C0)보다 나빠지지 않으면 더 빠르고 싼 쪽.** 나빠지면 C0 유지.

현재 기본값(C0, `DEFAULT_GEN_MODELS`): 그림 읽기 sol·medium / 목차 sol·medium / 분류 sol·low / 설계 sol·medium / 출제 sol·medium.

## 0. 받기·검증
`claude/local-state-20260928` pull(`c997055` 이상). 테스트·lint·build.

## 1. 그림 읽기 (실제 호출 18번, 묶음 확인 1번)
실험실 "이미지 읽기 시험", 쪽 이미지 방식. 지난번 6쪽(그래픽스 02 p.10·18, 04 p.20·30, 반도체 공학 07주 p.34·44)을 아래 3가지로 읽힌다.
- sol·low / astra·low / luna·low (sol·medium 결과는 지난 보고서 것을 기준으로 쓴다)

쪽마다 원본 이미지와 대조: 행렬 원소·부호·수식·수치 **오류 수**, 지어낸 내용, 빠진 본문, 시간, 토큰.

## 2. 출제 (실제 호출 약 90번: 기준 실행 약 60 + 출제만 다시 약 25, 묶음 확인 1번)
먼저 기준 실행을 하나 만든다: 실험실 새 실행, 그래픽스 02 전체, 핵심 암기, **그림·수식 쪽 읽기 켬**, 모델은 기본값 그대로, "목표 확인 없이 끝까지". 그림 읽기가 처음이라 약 30쪽을 읽는다(약 30번). 이 읽기는 뒤 실행들이 재사용한다.
→ 이 실행이 **C0**다. 호출 약 60번.

C0에서 "앞 단계 고정 재실행 → 출제만 다시"를 3번:
- 출제 sol·low / astra·medium / luna·low

비교(C0 포함 4개): 점수표의 형식 분포, short-wordy, 경고(특히 choice-length-cue), 출제 시간·토큰.
그리고 **실행마다 같은 목표 5개**(행렬·식이 들어간 목표 3개 + 개념 목표 2개)를 골라 문제와 정답을 원문(쪽 이미지)과 대조: 의미 오류, 정답 오류, 조건 누락, 정답 노출.

## 3. 설계 (실제 호출 약 20번, 묶음 확인 1번)
C0에서 "설계부터 다시"를 2번: 설계 sol·low / sol·high (출제는 sol·medium 고정).
비교: 목표 수, 핵심·보조 비율, 이상한 목표 수(원문을 가리키는 말, 강의 안내 암기, 같은 내용 반복), 점수표의 "목표로 안 쓰인 핵심·패턴·설명".

## 4. 목차·분류 (실제 호출 약 50번, 묶음 확인 1번)
새 실행 2개(그래픽스 02, 같은 설정). 목차·분류만 바꾸고 설계·출제는 sol·medium 고정:
- 목차·분류 astra·low / luna·low (C0이 sol·medium·sol·low)
- 그림 읽기는 C0 것을 재사용해 0번이어야 한다. 아니면 멈추고 보고.

비교(C0 포함 3개): 단원 수, 세부 항목이 슬라이드 제목과 맞는지(단원 2개 표본), 분류 오류(강의 안내가 핵심 지식, 대안·이유 누락), 점수표의 "목표로 안 쓰인 핵심·패턴·설명", 목차·분류 단계 시간.

## 순서와 상한
