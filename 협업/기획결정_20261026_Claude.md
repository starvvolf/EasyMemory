# 기획 결정 기록 (2026-10-26, Claude)

사용자와 정한 내용(주식 칼럼·암기 PPT·코드·CS 흐름, 지식 저장, 메모리 3단계, 에이전트 툴, 코드 학습 설계)을 바탕으로 만들면서,
말로 정해지지 않아 Claude가 혼자 정한 **기획상의 결정**만 적는다. 기술적인 선택은 적지 않는다.
바꾸고 싶은 항목은 번호로 말해 주면 된다.

## 지식

1. **같은 지식인지 판단**: 이름이 같거나(띄어쓰기·대소문자 무시) 아주 비슷하면 자동으로 하나로 합친다. 애매한 것은 합치지 않고, 지식창의 "같은 지식 합치기"로 사람이 합친다.
2. **다시 만나도 상태는 내려가지 않는다**: "앎"인 지식을 새 글에서 다시 만나면 "다시 만남" 기록만 남고 "앎"은 그대로다.
3. **몰랐음이 되는 순간**: 물어봤을 때, 틀렸을 때, 힌트를 받았을 때(정답 보기 포함). 졸업했던 지식도 이때 복습으로 돌아온다.
4. **앎이 되는 순간**: 힌트 없이 맞혔을 때.
5. **자동 졸업**: 마지막으로 틀린 뒤 **서로 다른 3일**에 맞히면 졸업(복습에서 빠짐, 기록은 남음). 사람이 직접 졸업시키거나 되돌릴 수도 있다.
6. **PDF 자료의 지식**: 지금까지 만든 PDF 자료의 지식 포인트는 "만남"으로 지식창에 들어오고, 폴더는 `자료 이름 / 구역`으로 잡는다.
7. **폴더를 지우면** 안의 지식과 하위 폴더는 한 단계 위로 올라간다. 지식은 지워지지 않는다.
8. **PDF 문제 풀이도 지식 기록에 남는다**: 맞힘 → 맞힘, 틀림 → 틀림, 정답 보고 풂 → 힌트 받음. "읽은 직후 확인" 문제는 남기지 않는다(읽자마자 푸는 것이라 기억의 증거로 약함).
9. **지식에서 바로 만드는 문제는 AI를 부르지 않는다**: 플래시카드(늘), 객관식·OX(설명이 있고 섞을 다른 지식이 있을 때), 빈칸(고리에 이어져 있을 때). 플래시카드는 학습자가 "알았어요 / 몰랐어요"로 스스로 채점한다.
10. **복습하기**는 몰랐음(많이 틀린 순) → 졸업 전의 앎(오래 안 본 순)으로 10문제를 고르고, 지식마다 문제 종류를 돌아가며 낸다.

## 문제 이름

11. 앱 전체에서 같은 이름을 쓴다: 고르기 → **객관식**, 값 쓰기 → **주관식**, 순서 맞추기 → **순서**, 떠올리고 확인 → **플래시카드**, 보기가 O/X 두 개뿐이면 **OX**, 용어 고르기 → **객관식 · 용어**. 지식에서 만드는 문제는 **빈칸**, **알아보기**가 더 있다.

## 칼럼 (크롬 확장)

12. **오늘의 시세, 날짜, 이번 분기 숫자처럼 시간이 지나면 의미 없는 사실은 지식으로 뽑지 않는다.**
13. **AI 호출은 버튼을 눌렀을 때만**: 글을 열기만 해서는 "지식 잡기"를 하지 않는다. 글도 버튼을 누를 때만 보낸다.
14. **폴더**: 지식을 넣을 폴더는 AI가 기존 폴더 중에서 고르거나 새로 만들고, 패널에서 직접 고를 수도 있다.
15. **목표 달성 기준**
    - 용어를 안다: 이 글의 용어 지식이 모두 "앎"이 되면.
    - 주장을 말할 수 있다: 글을 덮고 쓴 한 줄을 AI가 "맞음"으로 판정하면(일부·다름은 미달성).
    - 고리를 설명할 수 있다: 고리에 걸린 지식이 모두 "앎"이 되면.
    - 다른 글에서 알아본다: 예전에 배운 지식이 이 글에 나왔을 때, "알아보기" 문제를 맞히면. 예전에 배운 지식이 안 나온 글은 이 목표가 잠겨 있다.
16. 확장의 사이드 패널은 앱의 화면(`/ext`)을 그대로 띄운다. 그래서 Recaller가 켜져 있어야 동작한다.

## 코드

17. **예제 실행은 기록에 남지 않고, 제출만 지식 기록에 남는다.** 컴파일 에러는 문법 실수라 지식 기록에 남기지 않는다.
18. **제출하면 처음 틀린 테스트 하나만 보여 준다.** 나머지 숨은 테스트는 보여 주지 않는다.
19. **힌트 3단계**: 1 방향만(어느 지식을 다시 볼지), 2 문제 되는 줄 짚기, 3 고친 줄 보여 주기. 어느 단계든 받으면 그 문제의 지식이 "몰랐음"이 된다. 힌트를 받고 통과하면 "앎"이 되지 않고 "힌트 n번 받고 통과" 메모만 남는다.
20. **코드를 드래그해서 물으면** 그 문제의 지식에 "물어봄"이 남는다.
21. **기본 문제 5개를 새로 써서 넣었다**: 가진 카드 확인하기(이분 탐색), 처음으로 x 이상인 자리(lower_bound), 구간 합 빠르게 구하기(누적 합, 자료형 범위), 합이 X인 두 수(투 포인터), 빈칸 채우기: 이분 탐색. 백준 문제를 베끼지 않았다.
22. **AI가 만든 문제는 모범 풀이로 확인된 테스트가 3개 미만이면 저장하지 않는다.** 빈칸 문제는 빈칸을 채운 코드가 테스트를 통과해야 저장한다.
23. 코드 문제의 지식은 문제 폴더(예: `알고리즘/이분 탐색`)에 들어간다.
24. **메모리 초과 판정은 하지 않는다.** 시간 제한(기본 2초)만 본다.
25. 문제를 열어도 타이머가 저절로 켜지지 않는다. "타이머 켜고 풀기" 버튼으로 켠다.
26. 언어는 마지막에 고른 것을 기억하고, 언어마다 쓰던 코드를 따로 저장한다.

## 일정

27. **기한이 있으면** 오늘부터 기한 전날까지 똑같이 나누고, **기한 전날은 "전체 훑기 + 약한 것 몰아 보기"**로 잡는다. 기한이 내일이면 오늘 하루에 전부 넣는다.
28. 나누는 기준: 지식 폴더를 고르면 그 폴더에서 복습할 지식(몰랐음 먼저), 아니면 적은 분량(쪽·강·장·문제·단원).
29. **기한이 없으면** 따로 나누지 않고 복습 간격대로 간다.
30. 다시 나누면 아직 안 한 할 일만 새로 바꾸고, 이미 한 것은 그대로 둔다.
31. **타이머**: 1분이 안 되면 저장하지 않는다. 뽀모도로는 25분/50분, 끝나면 소리와 알림을 주고, "끝내고 저장"을 눌러야 저장한다(끝나도 시간은 계속 잰다).
32. 기존 앱의 "과목 시험일"과 새 "기한"은 아직 합치지 않았다. 둘 다 있다.

## 화면

33. **지식 탭을 새 지식창으로 바꿨다.** 예전 "자료별 지식 포인트" 화면은 지식창 왼쪽 아래 버튼으로 갈 수 있다.
34. **탭 순서**: 홈, 지식, 읽기, 연습, **코드, 일정**, 자료, 기록, 작업대.
35. **지식 사이드바**는 넓은 화면(1300px 이상)에서 기본으로 열리고, 머리글의 "지식 사이드바" 버튼으로 끄고 켠다. 브라우저마다 기억한다. 좁은 화면에서는 위에 겹쳐 열린다.
36. 사이드바의 "물어보기"에서 AI가 고리를 제안해도 **"잇기"를 눌러야 이어진다**(저절로 잇지 않는다).
37. 지식창의 "AI가 보는 요약"은 메모리 1단계를 그대로 보여 준다. AI가 무엇을 보는지 학습자가 볼 수 있게 했다.

## 에이전트

38. 에이전트가 화면에 띄운 블록은 왼쪽 아래에 최근 3개까지 쌓인다. 답하거나 닫으면 사라진다.
39. "기한 묻기"는 에이전트가 화면에 질문("시험이나 기한이 있나요?")을 띄우고, 학습자의 답을 에이전트가 읽어 가는 방식이다.
40. 채점(`grade`, `code_judge`)은 늘 툴이 하고, 에이전트가 스스로 맞다/틀리다를 정하지 않게 툴 설명에 적었다.

## 화면 정리 (2026-10-26 새벽, 메뉴 A안)

41. **메뉴는 넷**: 오늘 · 공부 · 지식 · 일정. 학습 기록·계정, 한 장 정리, 자료별 지식 포인트(예전 화면), 보관함, 프롬프트 설정, 태블릿, 작업대, 토론방은 오른쪽 위 **⋯ 더보기**로 옮겼다.
42. **오늘** 화면은 "무엇을 공부할까요?" → 다가오는 기한 · 오늘 할 일 · 다시 볼 지식(바로 복습) · 이어서 하기 → PDF 오늘 할 것 → 코치 순서. 예전 홈의 지식 포인트 구름과 자료 목록은 뺐다(지식·공부에 있다). 보여 줄 것이 없는 칸은 아예 숨긴다.
43. **공부**는 PDF 자료 / 웹 글 / 코드 세 갈래와 "+ 새 공부". PDF 자료 갈래에서는 "오늘 할 것"을 빼고(오늘 화면에 있으니) 연습 숫자와 자료 목록만 둔다.
44. **새 공부 흐름**: 종류 고르기 → (PDF는 기존 자료 넣기 화면, 웹 글·코드는 그 자리에서 만들기) → "시험이나 기한이 있나요?" → 공부하러 가기. PDF는 기존처럼 과목·시험일로 계획한다.
45. 크롬 확장이 없어도 되게, 웹 글은 **붙여 넣어서** 시작할 수 있다.
46. **지식 사이드바**는 닫혀 있을 때 오른쪽 가장자리 손잡이로 남고, 지금 화면과 관련된 지식 수를 보여 준다.
47. 실험 모드 띠와 "이 브라우저에만 저장" 표시는 숨기고, 더보기 맨 아래 한 줄로 알린다.
48. 지식창의 "어디서 만났나"와 "내 기록"은 접어 둔다. 단, 틀림·힌트·물어봄이 있는 지식은 기록을 펼쳐서 보여 준다. "AI가 보는 요약"과 예전 화면은 지식창의 ⋯ 안으로.
49. 새 공부에서 만드는 빈칸 코드 문제는 Python으로 만든다(코드 화면의 문제 만들기에서는 언어를 고를 수 있다).
50. 기본 코드 문제 5개의 지식(이분 탐색, lower_bound, 누적 합, 자료형 범위, 투 포인터, 정렬, 탐색 범위의 경계)에 뜻을 넣어 두었다. 처음부터 지식창에서 확인 문제가 나온다.
