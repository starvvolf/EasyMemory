## 진행 방법
1. 작업자는 지시문 하나를 맡아 시작할 때 위 표의 상태를 "진행 중"으로 바꾼다.
2. 끝나면 `결과보고/`에 `결과보고_주제_작업자_YYYYMMDD.md`를 남긴다. 캡처는 `캡처/<주제>/`에 둔다.
3. 표의 상태를 "완료" 또는 "부분 완료"로 바꾼다.
4. 지시문 범위를 넘는 변경이 필요하면 바로 고치지 말고 결과보고에 제안으로 남긴다(`AGENTS.md`, `docs/GENERATION_ENGINE_BOUNDARY.md`의 경계 규칙과 같다).
