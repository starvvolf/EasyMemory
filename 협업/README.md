# 협업 문서

Recaller 작업을 여러 AI(Codex, Claude 등)와 사람이 나눠 할 때 주고받는 문서를 모아 두는 폴더다.

## 이 폴더의 원칙
- **이 폴더는 검토용 복사본(`바탕 화면\Recaller`) 안에 있다.** 코드 수정은 반드시 원본 개발 저장소(`codex/recaller-integration` 브랜치, `먼저읽기.md`에 적힌 경로)에서 한다. 복사본의 `project/`를 고치지 않는다.
- 작업지시문에 적힌 파일 경로는 모두 저장소 루트(`project/`에 해당하는 위치) 기준이다.
- 지시문의 "완료 기준"을 전부 확인하기 전에는 완료로 보고하지 않는다. 확인하지 못한 항목은 "미검증"으로 남긴다.

## 진행 방법
1. 작업자는 지시문 하나를 맡아 시작할 때 위 표의 상태를 "진행 중"으로 바꾼다.
2. 끝나면 같은 폴더에 `결과보고_0N_작업자_날짜.md`를 남긴다. 무엇을 바꿨는지(파일·커밋), 완료 기준별 확인 결과, 미검증 항목, 지시와 다르게 판단한 부분과 이유를 적는다.
3. 표의 상태를 "완료" 또는 "부분 완료"로 바꾼다.
4. 지시문 범위를 넘는 변경이 필요하면 바로 고치지 말고 결과보고에 제안으로 남긴다(`AGENTS.md`, `docs/GENERATION_ENGINE_BOUNDARY.md`의 경계 규칙과 같다).

- 검수·리뷰: `검수결과_작업자_YYYYMMDD.md`
- 결정 기록(사용자가 확정한 방향): `결정_YYYYMMDD_주제.md`
