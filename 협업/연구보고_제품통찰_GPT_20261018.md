# Recaller 제품 통찰 연구 · 2026-10-18

## 1. 결론

Recaller는 이제 단순한 PDF 문제 생성기가 아니라 **원문·목표·연습·약점·노트를 연결하는 개인 시험 준비 도구**다. 그러나 기능의 연결보다 사용자가 이해하는 연결이 뒤처져 있다. 공부 루프는 실제로 돌고 날짜가 바뀌면 복습도 잡히지만, ‘오늘 완료’와 ‘시험 범위 준비 완료’, ‘생성된 문제’와 ‘실제로 풀 수 있는 문제’, ‘브라우저 저장’과 ‘서버 기록’이 다르다. 다음 단계는 새 기능을 늘리는 것이 아니라 **오늘 무엇을 해야 하고 무엇이 아직 남았는지를 믿을 수 있게 만드는 것**이다. 경쟁 제품보다 생성 품질이나 학습 효과가 우수하다는 증거는 이번 조사에서 확보하지 못했다.

- 따라서 신규 생성·질문 응답·신고 재생성의 끝까지 검증은 **미완료**다. 저장된 결과를 이용한 실제 화면 조작과 기존 동일 입력 실험 재분석을 수행했다. 새 실험을 했다고 표현하지 않는다.

## 6. Claude가 판단할 것

1. **시험 전날 새 문제를 모두 제외하는 정책:** 아직 안 본 범위가 많을 때도 맞는가? 최소한 ‘오늘 일정 완료≠범위 완료’를 명시해야 한다.
2. **로컬 기록 책임:** 현재 화면은 ‘이 브라우저에만 저장’이라 거짓 성공 표시는 아니다. 그러나 records API는 연결되어 있고 로컬 허용 목록에서 차단된다. 의도적 브라우저 전용인지 누락인지 확정하고 경로를 정리할 것. 클라우드 모드 전체 장애로 일반화하지 말 것.
3. **저장66·표시64:** 데이터 유효성 검사나 표시 변환에서 무엇이 빠지는지 원인 추적 후 복구. 이번 보고서는 숫자 차이만 확인했으며 두 문항의 원인까지 단정하지 않는다.
4. **한 장 정리의 목적:** 모든 목표를 다시 나열할 것인가, 시험 직전 돌아볼 핵심 지도인가? 후자라면 기본 화면부터 바꿔야 한다.
5. **경쟁 우위:** 새 문제 형식보다 범위 신뢰·오류 복구·다음 날 재진입에 집중할지 결정. 경쟁 제품 동일 자료 생성 비교 없이는 품질 우위 선언 금지.
6. **효율 개선:** 기출 복제 검사 제거 금지. 검출 품질을 유지하면서 중복 입력을 줄일 후보만 별도 실험. 이미지 읽기 범위 축소도 행렬·그림 누락 확인 전 적용하지 말 것.
