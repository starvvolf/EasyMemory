# Astrav3 구현과 실측

## 결론

- Astrav3는 기존 Claude v3·astra·astrav2를 보존하는 별도 실험 엔진이다.
- 전체 PDF 1회 읽기에서 목차와 앞 단원의 목표·근거를 먼저 받아, 자동 진행일 때 검수 문제를 순차적으로 제공하는 구조를 구현했다.
- 모델은 GPT-6.1 Sol·medium으로 고정해 첫 실측을 진행한다.
- 그래픽스 실측에서 목차 22.3초·앞 단원 목표 86.1초, 검수 후 8문항 공개를 확인했다. 정답 일부를 알려주는 1문항은 검수가 보류했다.
- 과도한 출제 응답이 수정 후에도 반복되어 12회에서 실제 호출을 중단했다. 반도체는 미실행이며, 실사용 준비 완료나 전체 목표 달성을 선언하지 않는다.

## Claude가 판단할 것

최초 그림·수식 판독이 틀리면 PDF를 다시 읽지 않는 후속 단계에서도 오류가 전파될 수 있다. 실측에서 해당 실패가 발견되면 이를 숨기거나 문제를 임의로 제외해 성공 처리하지 않는다. 독립 풀이와 검수의 일치도 원문 정확성을 대신하지 못한다.

- 최우선: 3문항 출제가 두 차례 장문 출력으로 끝나지 않았다. 단계 전용 스키마만으로 해결되지 않았다. 중단 응답 본문이 보존되지 않아 반복 문자열인지 문항 수 증가인지 확정할 수 없다. 다음 수정은 부분 응답 보존과 요청한 문항 수에 맞는 출력 경계부터 검토해야 한다.
- 공개 단답 2개는 여러 요소를 자유롭게 표현하는 답인데 문자열 일치 채점이다. 의미가 같은 답도 오답이 될 위험이 있다. 모델 검수 통과와 실제 채점 적합성은 별개다.
- 전체 순서 11개 요소를 자유 회상하는 문항은 원문에 맞지만 초회 학습 부담이 크다. 관계 보존과 적정 답 길이의 균형은 아직 개선 대상이다.
- 목적 변경·기출형 재설계는 지원 완료가 아니다. 출제만 재실행하는 경로와 구분해야 한다. 공부 화면 연결도 이번 범위가 아니다.

## 자세한 내용

### 실패에서 바꾸는 것

반도체07 기존 실행은 긴 자기확인 질문과 같은 답의 반복이 있었고, 개별 정상 문항이 같은 연습의 범위 부족 때문에 보류됐다. 그래픽스03에서는 질문의 요구와 실제 채점 범위 불일치, 근거 쪽 연결 오류, 전체 목표가 끝날 때까지의 대기가 남았다. 이 관찰을 바탕으로 복합 수행을 무조건 우선하지 않고 지식의 관계와 실제 인출 대상을 판단하게 한다.

모델에는 목적·범위·사용자 지시, 원문의 개념 관계와 조건, 현재 지원하는 질문·답 형식, 좋은 결과의 기준을 명료하게 전달한다. 과목별 예외나 강제 형식 비율은 만들지 않는다. 짧은 사실은 짧게 묻되, 관계·순서·연결된 계산의 의미를 잘라 없애지 않는다.

### 첫 실측 계획과 승인

연구용 `03_Three Dimensional Viewing.pdf`(44쪽)와 `[초급]반도체 공학의 이해_07주차.pdf`(47쪽) 전체 파일을 각각 1회 전송하고, 앞 8쪽을 출제 범위로 사용한다. 전자는 별도 지시 없이, 후자는 ‘핵심 용어와 역할을 짧게 회상’ 지시로 진행한다. 자료가 다르므로 두 결과의 차이를 지시 하나의 인과 효과로 주장하지 않는다.

사용자가 두 자료 전송과 실제 호출 합계 최대 30회를 승인했다. 3200은 다른 연구 서버가 사용 중이므로 보존하고 연구 전용 3201 서버와 `RecallerData-research/astrav3-20261019`를 사용한다. 두 실행은 각각 누적 15회로 제한한다. 사용자 공부 서버·기록에 쓰지 않는다. 호출 상한이나 로그인·사용량 오류에서 자동 반복하지 않는다.

### 결과를 보기 전에 정한 품질 기준

1. 원문을 먼저 확인해 선택 범위의 핵심과 제외 이유를 기록하고, 각각 실제 연습이 있는지 확인한다. 문제 수를 품질 점수로 대체하지 않는다.
2. 공개 문제의 정답·조건·수치·근거 쪽을 대조한다. 명백한 정답 오류나 본문의 정답 노출은 채택을 막는 결함이다.
3. 질문 하나가 요구하는 답과 허용 답·필수 채점 요소가 일치해야 한다. 여러 독립 답을 한 번에 요구하는 부담과 의미 있는 관계 회상을 구분한다.
4. 선택형의 각 오답이 왜 헷갈릴 만한지 기록한다. 무관한 보기, 문장 길이·표현으로 드러나는 정답, 복수 정답을 구별해 보고한다.
5. 같은 답을 형식만 바꿔 반복하는 문제와 학습 가치가 다른 연습을 구분한다. 빠진 핵심이 있는데 반복만 늘어난 경우를 결함으로 기록한다.
6. 첫 텍스트 도착과 실제 목차·목표·문제 노출을 구분한다. 전체 읽기가 끝나기 전에 검증된 앞 단원을 사용할 수 있는지 확인한다.

첫 소규모 실측은 구현 가설 확인이다. 전체 자료·무지시와 지시의 동일 자료 비교·추가 자료로 일반성을 확인하기 전 전체 목표 달성을 선언하지 않는다.

### 재개 후 실측 및 중단

- 실행 ID는 위와 동일하다. 누적 시작 12회, 완료 기록 10회, 강제 중단 2회(2·11번). 완료 기록 합계 입력 195,698 / 출력 14,201 / 캐시 입력 0토큰. 중단 호출 사용량은 알 수 없으므로 전체 비용·전체 토큰으로 간주하지 않는다.
- 정상 출제 3묶음은 각각 38.596초, 35.529초, 21.974초였다. 그러나 11번 출제는 180.326초 시점에도 26,495자 응답을 계속하고 있었다. 두 번째 과도한 출력으로 판단해 3201 연구 서버를 종료했다. 사용자 서버는 건드리지 않았다.
- 최초 공개는 전체 시작 563.022초 후였다. 중간 중단·코드 수정·재개 시간이 포함된다. 재개 출제 시작부터 첫 공개까지는 79.621초다. 이를 정상 무중단 전체 시간이라고 주장하지 않는다.
