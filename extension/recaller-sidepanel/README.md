# Recaller 사이드바 (크롬 확장)

웹에서 칼럼이나 강의 글을 읽으면서, 옆의 사이드 패널에서 Recaller로 공부하는 확장이에요.

- **지식 잡기**: 지금 탭의 글에서 알아야 할 지식을 뽑아 지식창에 넣어요. 예전에 배운 지식이 나오면 "예전에 배운 것"으로 따로 보여 줘요.
- **드래그해서 묻기**: 글에서 드래그한 말을 이 글의 문맥으로 설명하고, 다르게 보는 시각도 하나 보여 줘요. 물어본 말은 "몰랐음"으로 저장돼요. 오른쪽 클릭 → "Recaller에 물어보기"도 돼요.
- **잘 읽었는지 확인**: 용어 / 주장 / 고리 / 다른 글에서 알아보기, 네 가지 목표를 문제로 확인해요. 결과는 지식 기록에 남아요.

## 설치

1. 컴퓨터에서 `Recaller 시작.cmd`로 Recaller를 켜요 (http://127.0.0.1:3000).
2. 크롬 주소창에 `chrome://extensions`를 열고 오른쪽 위 **개발자 모드**를 켜요.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 폴더(`extension/recaller-sidepanel`)를 골라요.
4. 칼럼이 열린 탭에서 툴바의 Recaller 아이콘을 누르면 사이드 패널이 열려요.

## 동작 방식

- 확장은 지금 탭의 글을 읽어(`content.js`) 사이드 패널 안의 Recaller 화면(`/ext`)으로 넘겨요. AI 호출과 저장은 모두 이 컴퓨터의 Recaller가 해요.
- Recaller가 꺼져 있으면 패널에 "연결하지 못했어요"가 나와요.
- 글은 사이드 패널에서 "지식 잡기"나 "설명 듣기"를 누를 때만 보내요.
