날짜별 예상 가격

막대 하나가 하루, 색은 모델. 막대에 올리면 그날의 모델별 가격과 토큰이 나옵니다.

무엇에 썼나 (예상 가격 순)

호출 목적별. 막대 = 가격, 오른쪽 = 호출 수 · 토큰(입력/출력), 왼쪽 점 = 주로 쓴 모델 색.

갈래별 토큰 구성

입력은 새로 읽은 것 · 캐시로 읽은 것 · 캐시 쓰기, 그리고 출력. 가격의 대부분은 출력과 새 입력에서 나옵니다.

모델별

실행 기록

줄을 누르면 그 실행에서 무엇을 몇 번, 어떤 모델로 불렀는지 펼쳐집니다. 머리글을 누르면 정렬. 도우미 호출은 실행 번호가 없어 같은 갈래가 3분 안에 이어진 것을 한 실행으로 묶었습니다.
