# 문답 확정내용 기반 문제 출제 프로토타입

확정된 학습 목표와 원문 범위를 받아 제작 AI가 상황·수치·질문·보기·정답·해설·배치를 결정한다. 목표와 지식 단위는 다시 설계하지 않는다. 기본 문제 형식은 제작 AI가 고르고, 사용자가 지정하면 따른다.

문서는 자유 배치 블록으로 구성한다. 독립 문항과 공통 자료 세트를 함께 지원하며 공통 자료는 한 번 표시하고 채점은 각 문항의 응답 ID별로 기록한다. HTML·코드 생성은 입력 계약에 넣지 않는다. 제품 화면과 저장소는 연결하지 않는다.

실제 기하변환 실험은 이미 완료된 MCP Learning Design의 여섯 학습대상과 PDF 2~7쪽 근거를 패킷으로 고정한다. 새 출제는 독립 문항 2개와 공통 자료에 묶인 문항 2개를 만든다. 제작 AI가 자체 확인하고 기계 계약을 검사한 뒤 필요한 부분만 최대 한 번 수정한다. 별도 AI Critic은 실행하지 않는다.

완료 조건: 실제 MCP 산출물 해시와 학습 목표·원문 근거가 패킷에 남고, 네 문항의 안정 ID·출처·정답 계약이 검증되며, 풀이·제출·정답 공개가 로컬 화면에서 작동한다. 공통 자료는 한 번 표시되고 두 문항의 채점은 서로 독립적이어야 한다. mock 검사와 실제 모델 출제 결과를 구분해 기록한다.
