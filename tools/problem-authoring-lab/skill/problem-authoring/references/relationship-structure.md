# 관계·구조 문항 출제 가설 v1

근거가 순서, 순서 없는 집합, 부모·자식 계층, 원인·결과 연결, 대응 관계일 때 사용합니다.

1. 화면 배치를 고르기 전에 학습자가 재구성해야 할 관계를 명명합니다.
2. 단계의 방향, 부모 표시, 가지 표시, 행·열 제목, 형제 항목의 순서가 중요한지와 같은 의미적 기준점을 보존합니다.
3. 관계 자체가 답이라면 직접 배치하거나 연결하는 방식을 우선합니다. 짧은 텍스트 채점이 이미 있다는 이유만으로 구조를 임의의 문자 암호로 바꾸지 않습니다.
4. 의미 있는 관계만 채점합니다. 순서 없는 집합에서는 형제 위치를 무시하지만 순서가 목표의 일부라면 순서를 검사합니다.
5. 완성된 답을 보여주지 않으면서 유일한 구조를 결정할 만큼의 관계 맥락을 질문에 남깁니다.

실패 사례: 두 가지를 `BFC EAD`로 나타내라고 하면 계층뿐 아니라 부호화 규칙과 정확한 타이핑까지 측정합니다. 부호화 자체가 학습 대상이거나 지원되지 않는 상호작용 때문에 문서화된 제한이 있을 때만 사용합니다. 직접 계층을 재구성한 것과 동등한 근거로 제시하지 않습니다.
