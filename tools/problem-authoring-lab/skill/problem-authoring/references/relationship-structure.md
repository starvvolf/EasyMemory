# Relationship and structure authoring hypothesis v1

Use this when the evidence is an order, an unordered set, a parent-child hierarchy, a cause-effect link, or a correspondence.

1. Name the relation the learner must reconstruct before choosing a visual arrangement.
2. Preserve semantic anchors such as step direction, parent labels, branch labels, row/column headings, and whether sibling order matters.
3. Prefer direct placement or connection when the relation itself is the answer. Do not turn structure into an arbitrary text cipher merely because short-text grading already exists.
4. Grade only meaningful relations. Ignore sibling position for unordered sets, but enforce order when sequence is part of the objective.
5. Check that the prompt leaves enough relational context to determine a unique structure without displaying the completed answer.

Failure example: asking for `BFC EAD` to represent two branches measures knowledge of the encoding and exact typing in addition to the hierarchy. Use such an encoding only when it is itself the target or when a missing interaction forces a documented limitation; do not present it as equivalent evidence to direct hierarchy reconstruction.
