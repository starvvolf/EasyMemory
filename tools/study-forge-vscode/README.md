# Study Forge Coding Coach

VS Code의 왼쪽 문제 패널, 기본 코드 편집기, 오른쪽 학습 대화, 하단 예제 결과를 연결하는 로컬 확장입니다. 신규 npm 의존성이 없습니다.

## 개발 호스트에서 열기

1. 이 폴더를 VS Code에서 열고 F5로 확장 개발 창을 실행합니다.
2. 명령 팔레트에서 `Study Forge: 코딩 학습 열기`를 실행합니다.
3. 왼쪽에서 새 문제의 본문·그림·선택적 원문 링크를 입력합니다. PNG/JPEG/WebP 붙여넣기와 파일 첨부를 지원합니다(각 3MB, 최대 5개).
4. 문제에 있는 예제 입력/기대 출력을 직접 편집·확인하고 등록합니다. 자동 스크래핑이나 AI 예제 추출은 없습니다.
5. 기본 편집기에서 코드를 선택하고 학습 대화의 `선택 코드 첨부`를 누릅니다. 질문에 보낼 스냅샷을 미리 볼 수 있습니다.

문제 초안과 등록된 문제, 원문 대화, 연결한 학습 파일의 변경 스냅샷은 확장의 로컬 저장소에 보존합니다. 사용자 코드 파일에 `save`나 편집을 적용하지 않습니다. 다른 작업 파일을 자동 수집하지 않습니다. 연결 파일은 실행 파일 선택 또는 코드 첨부 때 정해집니다. 원문 대화와 AI 학습 정리는 별도입니다.

## 연결 시험 상태

실제 ChatGPT 로그인/AI 호출 시험은 **보류**이며 `studyForge.enableLiveConnection` 기본값은 false입니다. 승인된 실제 연결 시험 전에는 이 설정을 바꾸지 않습니다. 아래는 이후 사용자 시험 절차입니다.

- 사용자 설정에 `studyForge.codexExecutable`을 Codex 네이티브 실행 파일 절대 경로로 지정합니다. `.cmd/.bat/.ps1` 래퍼는 실행하지 않습니다.
- 실제 연결 시험이 승인되면 사용자 설정의 `studyForge.enableLiveConnection`을 켭니다. 작업 폴더 설정으로 이를 켤 수 없습니다.
- 학습 대화의 `ChatGPT 로그인`을 누르면 App Server의 managed ChatGPT 브라우저 로그인을 시작합니다. 확장 전용 인증 저장소이므로 기존 Codex 로그인과 별도입니다.
- `질문 보내기`를 누를 때만 문제 본문·그림과 명시적으로 첨부한 코드/실패 결과를 전달합니다. API 키 계정은 거부하며 자동 전환하지 않습니다.

ChatGPT 웹의 기존 대화·메모리는 동기화하지 않습니다. 인증 토큰은 App Server가 관리하며 학습 JSON/웹뷰로 보내지 않습니다. AI의 명령 실행·파일 수정·MCP 승인 요청은 허용하지 않습니다.

## 학습 정리

`현재 대화 정리` 또는 정확한 `정리해줘` 요청으로 현재 대화까지 정리합니다. 다룬 개념, 막힌 부분, 실제 확인된 행동, 아직 확인되지 않은 이해, 다시 볼 내용을 원문 근거와 연결합니다. 질문·열람·예제 통과를 숙달로 확정하지 않습니다.

자동 갱신은 기본 꺼짐입니다. 사용자가 켜고 첫 정리를 요청한 뒤, 열린 세션에서 새 대화가 있을 때만 10분마다 갱신합니다. 실패하면 이전 정리와 성공 cursor를 유지하고 실패를 표시합니다. 수동 요청은 타이머를 기다리지 않습니다. 정리에도 ChatGPT 구독 사용량이 발생합니다. 세션/채팅창/확장이 닫히면 타이머를 중지하며 재개 시 소급 호출하지 않습니다. OS 스케줄러나 Codex automation을 만들지 않습니다.

## 예제 실행의 미확정 범위

첫 지원 언어와 `표준입력→표준출력 파일` / `solution 함수 래퍼` 계약은 미확정입니다. **실사용 실행 어댑터와 버튼은 비활성**입니다. 임의 언어 또는 명령을 설정에서 실행하도록 우회하지 않습니다.

준비된 실행 엔진은 예제별 3초/출력 합계 64KB 제한, 중지, 결과 비교, 실패 문맥 첨부를 제공합니다. CRLF와 마지막 줄바꿈 하나만 정규화하며 나머지는 정확히 비교합니다. 숨은 테스트/원사이트 합격 판정이 아닙니다. 현재는 로컬 Node fixture로만 검증했습니다. Windows의 taskkill 실패 시 직접 자식 종료로 대체되므로, 자손 프로세스까지 강제 종료하는 실사용 언어 검증은 어댑터 연결 전 필수입니다.

## 오프라인 검증

저장소 루트에서:

```text
node --test tools/study-forge-vscode/test/*.test.cjs scripts/study-forge-vscode.test.cjs
node tools/study-forge-vscode/test/preview.cjs
```

미리보기는 `http://127.0.0.1:39127`의 합성 자료 전용 화면입니다. VS Code 호스트나 AI를 실행하지 않으며 실제 통합 성공을 입증하지 않습니다. 기존 `프로젝트 연결` / Ctrl+Alt+R 제출 명령은 유지합니다. 기존 방식은 Study Forge 웹 서버와 active 코딩 세션이 별도로 필요합니다.

상세 파일 책임·저장 계약·검증 한계: [docs/INTEGRATION.md](docs/INTEGRATION.md).
