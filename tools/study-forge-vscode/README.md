# Study Forge Coding Coach

1. Study Forge 웹 서버를 먼저 실행합니다.
2. VS Code에서 이 `tools/study-forge-vscode` 폴더를 엽니다.
3. `F5`를 누르면 Study Forge 프로젝트가 열린 확장 개발 창이 실행됩니다.
4. 명령 팔레트에서 `Study Forge: 프로젝트 연결`을 선택합니다.
5. 코드를 선택하고 `Ctrl+Alt+R`로 현재 코딩 학습 세션에 제출합니다.

기본 웹 서버 주소는 `http://127.0.0.1:3000`입니다. 다른 포트를 쓰면 VS Code 설정에서 `studyForge.serverUrl`을 변경합니다.
